# Chapter 6: AI 写作全流程实战攻略

## Core Idea
全流程=先确认规则，再按模型类型选提示策略，再分模块（综述/开题等）提效；AI 只辅助，作者审校与责任确认不可外包。

## Frameworks Introduced
- **推理模型 vs 通用模型提示策略**  
  - 推理向（如 DeepSeek-R1）：提示更简洁，聚焦目标，“要什么直接说”；强行拆碎步骤可能限能力。  
  - 通用向：需显式分步、示例、补偿性引导，“缺什么补什么”。  
  - 书中取向：学术写作以推理模型为主、通用为辅。
- **五类需求表达公式（对推理模型）**  
  决策：目标+选题+评估标准  
  分析：问题+数据/信息+分析方法  
  创造：主题+风格约束+创新方向  
  验证：结论/方案+验证方法+风险点  
  执行：任务+步骤约束+输出格式
- **提示词基本结构**：指令 · 上下文 · 期望
- **文献综述实操链（防无中生有）**  
  1) 管理主体规则确认（禁则停）  
  2) 数据库高级检索→筛摘要→导出题名/作者/关键词/摘要列表（可辅学术搜索补全）  
  3) 将真实列表/全文投喂模型做结构与语言辅助  
  4) 作者审校；禁止把一次长指令生成的综述当定稿
- **避假参考文献三法**：优化提示（强制真实/筛选标准/结构化带链接）；调低随机性参数（若工具支持）；知识库/RAG/只基于上传文献回答
- **开题报告三期**  
  - 战略准备：SWOT、金字塔文献（基础20%/核心50%/前沿30%）、文献矩阵  
  - 主体撰写：N 要素（领域+对象+方法+创新）；漏斗模型（宏观背景→痛点→缺口→方案）  
  - 质量提升：交叉验证、格式、第三方逻辑校测  
- **开题提示词应含**：主题、专业、字数、格式规范、特殊要求  
- **开题审校六项**：问题聚焦、文献批判（量质）、方法可行、创新≤3且可比对、格式、进度

## Key Concepts
- **漏斗模型（开题论述）**：与书A倒金字塔同族——由宽到窄落到方案。
- **第一责任人前提**：一切润色/辅助仍由作者背书。

## Mental Models
- Prefer **先导出真实文献表再问模型** over **先让模型列参考文献**。
- Use **五类需求公式** when 提示含糊导致空答。
- Use **Book1 倒金字塔** when 开题被驳在“问题/创新”而非格式。

## Anti-patterns
- 管理主体禁止仍“借鉴一下全文生成”。
- 一次性超长指令生成整章综述直接粘贴。
- 开题创新点堆超过可验证的 3 个。

## Worked Example
综述避假引：提示要求“不确定是否存在的文献直接删除；近五年核心库；段末输出 标题—作者—年—摘要—链接”；同时只上传已下载 PDF/导出表；人逐条打开链接。  
开题背景提示：“以［领域］为例，述近五年趋势与主要问题，并说明现有研究不足”——产出仅作梳理素材，人改写成与本人题目咬合的段落。

**提示词边界**  
- 可：基于已导出列表做归纳、语言改进并说明修改理由  
- 不可：在无文献包时“生成完整带参考文献的综述定稿”

**人工必做**  
1. 规则确认 2. 文献回源 3. 开题六项审校 4. 披露与存档（见 Ch5）

**句级质检**  
- 综述总结句是否仍保留作者原命题与理论接口？  
- 意义句是否分理论/实践且可对接目标？  
- 目标句是否可操作、可衡量（非“深入探讨”）？

## Key Takeaways
1. 模型类型决定提示繁简策略。
2. 综述提效建立在真实文献表之上。
3. 开题三期与漏斗/N 要素把合规辅助嵌进结构。
