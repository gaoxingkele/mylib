# Chapter 4: 文科生必学的 AI 操作

## Core Idea
提示词工程是结构化表达研究意图；九大场景覆盖检索到入门新领域，但“AI 会错、你不能错”。

## Frameworks Introduced
- **好提示词三策略**：说清楚具体；引导思考；多轮试错。
- **常见框架**：CLEAR / PAIR / PESTEL / ART / SCAMPER / RICE（按任务选用）。
- **验证意识**：横向阅读、权威源层级；非学术信息分可信度。
- **九大场景**：检索、文本处理、翻译、阅读分析、综述、可视化与编程、角色扮演、领域专项、进入新领域。
- **学术检索三阶段**：计划—搜索—调整，每阶段可嵌入 AI 但保留人工筛选。

## Key Concepts
- **AI 味**：提示不足导致的连贯却空心的概率拼盘（需靠具体约束与证据消除，非靠降检测）。
- **提示词工程**：不会随模型变强而消失，只会升级到更复杂任务设计。

## Mental Models
- Use **ART（受众·回应·语气）** when 段落语体不对。
- Use **PAIR** when 问题需多轮收敛。
- Prefer **关键词+布尔** 为主、自然语言检索为辅 when 查全率要求高。

## Anti-patterns
- 单一万能提示词打天下。
- 用社交平台帖子当高置信学术证据。

## Worked Example
计划阶段提示：“你是某领域专家，将主题拆为 3–5 方向并给术语列表”；搜索阶段根据过多/过少结果请 AI 建议重构式；调整阶段让 AI 总结摘要辅助初筛——人做去留决定。

**提示词边界**：可生成检索式与摘要；不可直接生成“已发表”假文献条目写入参考文献。

## Key Takeaways
1. 框架选择服从场景。
2. 验证策略与提示词同等重要。
3. 九大场景都要外挂证据。
