# Chapter 3: AIGC 工具全景化介绍

## Core Idea
按任务选工具族：通用大模型、学术专用、辅助检测/检索；选型服从合规与数据边界，而非品牌崇拜。

## Frameworks Introduced
- **工具分层**：DeepSeek 等通用模型；其他通用模型；学术专用模型；其他辅助工具。
- **选型维度**：是否联网、是否有文献库、是否可导出记录、隐私与备案、是否满足学校/期刊清单。

## Key Concepts
- **学术专用工具**：面向论文检索/证据语句，仍要人工点开文献。
- **辅助工具**：翻译、管理、检测等；检测结果≠合规结论。

## Mental Models
- Use **任务—工具匹配表** when 同时开很多 App。
- Prefer **可留痕工具** when 目标场景要求自证。

## Anti-patterns
- 把检测报告当“无作弊证明”唯一依据。
- 向不明工具上传隐私或未发表数据。

## Worked Example
文献定位：学术型检索工具出候选 → 数据库下载 → 通用模型仅基于 PDF/笔记辅助摘要；链路可审计。

## Key Takeaways
1. 全景是为了匹配，不是为了全用。
2. 合规工具优先于“更好用但黑盒”。
3. 记录能力本身是选型标准。
