# 提示词模板：如何用AI写论文

原书约有 50 段提示词示例，集中在 ch04（框架与九大场景）和 ch06（综述、开题、成稿）。本文件归并成 18 个模板。占位符用【】表示。

**agent 使用规则**（详见 `../_integration/agent-gates.md`）：
- 原书 ch06 有“请推荐关于【主题】的文献，给出标题、作者、年份、摘要”这类提示词。agent 一律改为检索工具或用户导出的文献列表（G2）；原书自己也提醒 AI 可能“无中生有”。
- 原书反复强调“AI 会错，你不能错”。agent 把核验写进输出格式：每条事实带来源，没有来源的标【待补】。
- 指令较多时，原书建议拆成若干条输入；agent 默认按分步指令执行（G4）。

## 一、提示词结构与六种框架（ch04 表 4-1）

基本结构：**指令**（任务核心）＋**上下文**（背景信息）＋**期望**（输出要求）。好提示词的三策略：说清楚具体、引导思考、多轮试错。

| 框架 | 适用 | 要素 | 模板 |
|---|---|---|---|
| CLEAR | 学术研究、数据分析 | 简洁、逻辑、明确、适应、反思 | P1 |
| PAIR | 需要多轮收敛的问题 | 问题、AI 参与、互动、反思 | P2 |
| PESTEL | 政策、行业、法律环境分析 | 政治、经济、社会、技术、环境、法律 | P3 |
| ART | 论文写作、改语体 | 受众、预期回答、语气 | P4 |
| SCAMPER | 创意与方案发散 | 替换、组合、调整、修改、他用、去除、重排 | P5 |
| RICE | 法律等专业研究 | 角色、指令、背景、期望 | P6 |

**P1 CLEAR**
```
请简要说明【主题】的关键信息，并按逻辑顺序给出其主要发展脉络与现状（不超过【N】字）。若有不确定信息，直接说明并给出可能的核实来源。
```
**P2 PAIR**
```
我要解决的问题是【问题】。请先给出初步方案，并列出你需要我补充的信息；我们再多轮沟通调整。每轮结束时总结已确定和待定的事项。
```
**P3 PESTEL**
```
请从政治、经济、社会、技术、环境、法律六个层面分析【对象】的前景。每个层面给出 1–2 条判断及其依据来源，没有来源的标注“推断”。
```
**P4 ART**
```
目标读者是【受众】。请写一篇关于【主题】的【文体】，预期回答为【长度/结构】，语气保持【正式/通俗】。
```
**P5 SCAMPER**
```
针对【现有方案】，分别从替换、组合、调整、修改、他用、去除、重排七个角度各提出 1 个改进思路，并评估可行性。
```
**P6 RICE**
```
你是【专业角色】。请根据我提供的【材料】，【任务，如：查找相关法条和类似案例】，并输出结构化分析：事实｜争点｜依据（条文/案例，须可核）｜结论。
```

## 二、九大场景（ch04）

**P7 学术检索三阶段**
```
计划：请将我的研究主题【主题】拆分为 3–5 个方向，并给出每个方向的核心术语及同义、近义、上下位词。
搜索：以下检索式结果【过多/过少】（附结果数），请建议如何调整关键词和布尔逻辑。
调整：以下是检索到的题录（附题目与摘要），请按与研究目标的相关度分为高、中、低三档，并说明理由。去留由我决定。
```
**P8 外文阅读与翻译**
```
请总结这篇【语种】论文的研究问题、方法和结论，约 200 字；另列出文中的关键术语及中文译法。
（翻译）请以【专业新闻/学术/法律】风格翻译以下文本，注意：术语前后一致；人名、机构名保留原文；不确定处加［?］标注。
```
**P9 可视化与编程**
```
我有【数据描述，含字段】。请用 Python 完成：1) 读取并查看前几行；2) 统计【指标】；3) 画【图表类型】；4) 逐段解释代码。不要虚构数据，读取不到时报错说明。
```
**P10 角色扮演审稿**
```
你是学术期刊审稿人。请审查论文《【题目】》（附正文），着重审查：1) 研究目的与意义是否明确；2) 文献综述是否充分、准确；3) 方法与数据采集是否合理；4) 分析是否严谨、结论是否有足够证据支持。逐条给出问题位置、理由和改进建议。
```
**P11 苏格拉底式追问**（打磨论点）
```
请扮演苏格拉底式提问者。针对我的论点“【论点】”，每次只问一个问题，逐步检验其前提、证据和反例；在我回答后再问下一个。
```
**P12 快速入门新领域**
```
你是【领域】专家。我想快速了解该领域，请按【维度 1–4】给出 80–100 个关键词，每个用一两句话解释；标注必须掌握的词和词间关联。
（进阶）请对比【来源 A/B/C】对“【主题】”的解释，用表格列出共同强调点和差异点。
```

## 三、全流程（ch06）

**P13 文献整理十问**（基于导出的文献列表）
```
基于以下文献列表（附题录/摘要），请完成【选一项】：
- 提取近 5 年关于【理论】的争议焦点，按支持/反对/中立分类；
- 用表格总结各文献的研究设计：样本量、变量、分析方法；
- 对比【学者 A】与【学者 B】对【现象】在方法论上的解释差异；
- 按时间线划分研究阶段，标注各阶段的标志性成果；
- 整合结论相互冲突的文献，提出可能的调和解释框架；
- 批判性分析局限性，区分普遍问题与特殊问题。
每条结论标注对应文献编号。
```
**P14 综述成文**
```
我正在写关于【研究问题】的文献综述。请仅根据以下文献列表协助完成，结构为：引言（范围与问题）｜主题一…｜主题 N｜评价（主要发现、共识、分歧与不足）。要求逻辑严谨，每段观点标注文献编号。
```
**P15 润色（带理由）**
```
【段落】请改进语言表达、逻辑结构与内容质量，给出修改后的版本，并逐条说明修改原因。不得改动数字、引文、术语和结论强度。
```
**P16 开题报告分块**
```
身份：我是【身份】，专业【专业】，课题【题目】，学校要求【字数/格式】。
背景：以【领域】为例，阐述近五年的主要发展趋势和面临的问题，并说明现有研究的不足（每条附来源）。
意义：分析本研究在理论拓展和实际应用方面的潜在贡献，分点阐述。
目标：将研究目的分解为 3–5 个可操作、可衡量的研究目标。
方法：针对【研究问题】列举适用的定量/定性方法，说明实施步骤、优势和在本研究中的用法。
创新：从方法创新、视角创新、应用场景创新三方面梳理本研究的价值。
计划：以研究目标为导向，制定【N】个月的研究计划，含各阶段起止时间、任务和预期成果。
```
每块单独输入、单独核对（原书建议）。
**P17 参考文献格式化**
```
把下列参考文献按 GB/T 7714—2015 格式化，保持原顺序；原文献缺作者的，结果不显示作者部分；缺失的字段标［缺］，不要补全。
```
**P18 披露与留痕**（ch05 自证第 5–6 步）
```
请根据以下使用记录生成 AI 使用声明草稿：工具与版本【】、使用环节【】、生成内容范围【】、人工核验方式【】。声明只陈述事实，不夸大或缩小 AI 的作用。
```
agent 门禁：声明中的“作者已审阅确认”等事实属于 H 类，必须由作者确认，agent 不得预填。
