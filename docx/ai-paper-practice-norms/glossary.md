# Glossary — ai-paper-practice-norms

**AIGC** — 生成式人工智能（内容/工具语境）（Ch1）  
**LLM** — 大语言模型；概率续写文本（Ch1）  
**图灵测试** — 拟人交流测试；不证明理解或正确（Ch1）  
**人工智能幻觉** — 流畅但虚假/无据输出（Ch1）  
**创新·严谨·负责·合规** — 论文四核要求（Ch2）  
**技术敬畏 / 规则敬畏** — 能力边界与规范边界（Ch2）  
**混合式创新** — 人机协作增量且人保持主体（Ch2）  
**文责自负** — 作者承担全部法律与名誉责任；AI 非作者（Ch2）  
**自证合规** — 写作过程中主动留痕与说明以降争议（Ch2）  
**学术信任链** — 可追索责任者的引用与来源机制（Ch2）  
**管理主体** — 学校/导师/期刊/学术团体等规则源（Ch5）  
**使用场景** — 作业/考试/学位/期刊等场合（Ch5）  
**交叉验证** — 对 AI 信息做多源核对（Ch2/Ch5）  
**恰当说明 / 披露** — 按要求声明工具与用途（Ch5）  
**提示词工程** — 结构化任务与约束设计（Ch4）  
**CLEAR / PAIR / ART / RICE…** — 常用提示词框架（Ch4）  
**AI 味** — 约束不足导致的空心流畅文本（Ch4）  
**九大应用场景** — 检索到入门新领域的任务谱（Ch4）  
**计划—搜索—调整** — 学术检索三阶段（Ch4）
