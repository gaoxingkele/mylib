# 第4.5–4.8章：题目、摘要、立项依据、研究内容（案例蒸馏）

## Core Idea
题目=中心词逻辑组合；摘要=申请书缩写且偏重新见解内容；立项依据与研究内容的败笔高度可模式化——用句式改造比堆形容词更有效。

## Frameworks Introduced
- **题目三大要素**：研究对象 × 条件/特色修饰 × 目标中心词（规律/机理/模型/方法…）
- **摘要三段配额（约400字）**：背景+问题≈100；方法对应创新内容≥200；目标/前景≤100
- **摘要参考句链**：背景→科学问题→采用…方法做…→达到…→前景/意义
- **研究内容“具体化四问”**：假设？变量/测点？方程或判据？如何归题？

## Key Concepts
- **中心词 vs 修饰词**：中心词=主干科学任务；修饰词=特色与范围
- **富于信息命题**：题目尽量覆盖核心关键词，忌松散堆砌
- **点题**：摘要必须回扣题目中心词
- **第三人称**：摘要禁用“本课题/我们”

## Mental Models
- Draft **3–5 个题目**再按申请书实际内容回选。
- In abstracts, cut background first if over length—never cut the concrete content block.
- When a reviewer underlines a phrase, it usually asks：**具体是什么？**

## Anti-patterns（来自书中案例点评族）
- 题目：过大空洞、概念重复/覆盖、层次混淆、动宾口号、设计/评价类超范围
- 摘要：背景离题、第一人称、内容不具体、“首先然后最后”、与目标雷同、含公式
- 依据：远景政策段、科学问题不突出、意义只谈工程经济社会
- 内容：不具体、不归题、用目标代替内容

## 1. 题目拟定：栏目指令

**何时用**：定题与改题。  
**怎么写**：`【修饰：条件/对象特殊性】+【中心词：机理/模型/规律/方法…】`；慎用“基于…的…研究”除非方法本身有创新。

**推荐骨架**：
- `【环境/扰动条件】下【结构对象】【演化现象】【机理/规律】`
- `【对象】【过程】的【结构/本构/统计】模型与【判据】`
- `面向【科学问题】的【新方法名称】及其【可验证性质】`

**少用/慎用**：
- 动宾口号：`研究……机理`（可改为名词化中心词组）
- 单独介词：`……对……的影响` → 改为 `……条件下……响应/作用机制`
- 分割符号堆并列、过多“的”、自我评价词（新一代/首创）
- `……基础研究/若干问题/体系/关键技术` 等宽词收尾

**改写对照**：
| 病句倾向 | 操作 | 更可审方向 |
|---|---|---|
| 概念覆盖（强度规律与力学特性） | 删包含项，留一层 | 只留“强度规律”或“力学特性” |
| 隐含重复（地下巷道） | 删隐含修饰 | “巷道围岩…” |
| 设计/仪研制为主 | 升维到原理/方法 | 检测原理、反演方法、误差机制 |
| 基于XX方法+新问题大作业 | 证明方法创新点 | 方法槽必须有新假设/新算子/新稳定条件 |

**自检**：
- [ ] ≤约25字（书中建议；以可读清晰为准）？
- [ ] 是科学问题而非工程任务？
- [ ] 中心词唯一清晰？修饰词可在依据中定义？
- [ ] 无歧义或多解概念未解释？

## 2. 摘要：栏目指令

**职能**：第三者视角的缩写；决定专家是否深读。  

**句式骨架（可直接填槽）**：
```
【1句】典型背景事实（不展开产业史）→ 其科学实质为【…】，科学问题是【与题目同构的问题句】。
【2–4句】项目采用【方法1】，测定/识别【量】；采用【方法2】，建立【模型/判据】；采用【方法3】，求解/验证【…】；据此阐明【具体机制/关系】。
【1句】旨在达到【科学目的】，为【领域】提供【理论/方法】基础，具有【可陈述】的应用前景或科学意义。
```

**硬规则**：
- 第三人称；不举例证、不写过程故事、不自我评价
- 不用生僻缩写、图表、化学式、数学公式
- 重点在“方法↔创新内容”块（≥约一半篇幅）
- 不要与“研究目标”栏目全文雷同

**反例→改写操作**：
- “能源短缺/经济快速发展……” → 删除，改为一句与题目变量相关的事实
- “不同体系/关键参数/相互作用关系” → 替换为可点名的体系、参数、关系式对象
- “首先…然后…最后…” → 改为并列“采用…；采用…；采用…”
- “本课题” → “项目”或直述动作主语（项目采用…）

**自检**：
- [ ] 读摘要能否还原题目中心词？
- [ ] 有无具体方法与具体产出？
- [ ] 背景是否 ≤1–2 句？
- [ ] 有无第一人称与公式？

## 3. 立项依据：案例级句式

**开篇（靶向）**：
- 正：`【具体工况/现象】中反复出现【可观测事实】，其实质是【科学问题】。`
- 反：`随着我国……《规划》指出……产量由…增加到…`（书中点名的离题族）

**现状评述分类标签（选用）**：概念定理 / 科学方法 / 模型 / 数值模拟 / 演化机理 / 实验手段 / 规律结论  
每类两句：`已解决【…】；未解决【…】。`

**拟解决收束**：
- `综合评述，本申请拟解决：①…；②…（含关键问题…）。`

## 4. 研究内容：案例级句式

**总起帽段**：
- `各项内容的逻辑是：由【结构/环境认知】→【模型或机理表述】→【实验/数值验证】→【归题到关键问题】。`

**条目具体化检查清单（写作时逐条勾）**：
1. 对象与条件是否比题目更可操作？  
2. 是否出现假设、变量、判据、初边值之一组？  
3. 实验是否写清测什么、与理论何关系？  
4. 求解用什么解析/数值法？  
5. 该条如何服务关键问题？  
6. 有无泄密与深度的平衡（具体但不暴露不当细节）？

**句式**：
- `针对【子问题】，完成【可交付的知识物】，而不是完成【工程任务清单】。`

## Worked Example（摘要压缩）
病：大段煤层气产业背景 + “不同体系”不定义 + “传热机理”空转。  
改：1句抽采/储运中水合物分解受热控制的事实 → 问题落到分解—传热耦合机制 → 装置测温度场与分解速率 → 建立耦合传热分解模型 → 确定热控制条件 → 科学目标与有限前景。

## Key Takeaways
1. 题目靠中心词+修饰词，不靠形容词。
2. 摘要篇幅分配向“具体研究内容”倾斜。
3. 凡被问“具体是什么”的词，都要在定稿前消灭。
