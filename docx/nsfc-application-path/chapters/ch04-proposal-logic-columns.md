# 第4.3–4.4章：申请书逻辑关系与栏目写法

## Core Idea
申请书是“科学问题主线”上的有机整体：题目定逻辑起点，关键科学问题定主要矛盾；各栏目分别回答为什么做、做什么、做成什么、怎么做、能否做、新在何处——禁止串台。

## Frameworks Introduced
- **科学问题主线法**：全篇沿同一科学问题展开，首尾呼应
- **四大部分结构**：简表 | 立项依据与研究内容 | 研究基础与工作条件 | 经费预算
- **栏目职能分离**：
  - 立项依据＝提出问题（尤其关键问题）
  - 研究内容＝具体、深入、创新地**做什么**
  - 研究目标＝做完达到的**科学目的**
  - 研究方案＝**怎么做**（方法/路线/手段/关键技术）
  - 可行性＝主客观 + **学术可行性**
  - 特色创新＝特殊性 + 可指认的新点
- **对应表思维（表4.1）**：每个拟解决子问题 ↔ 内容 ↔ 目标 ↔ 关键问题 ↔ 创新 ↔ 方法 ↔ 学术可行

## Key Concepts
- **限制性定语**：题目修饰词；往往是特色，必须在依据中定义、在内容/方案中兑现
- **归题**：各分项最终回到拟解决科学问题，尤其关键问题
- **学术可行性**：按科技水平与团队能力论证关键问题可攻克（常被漏写）
- **第三人称科学语言**：摘要与正文少用“我们/本课题”

## Mental Models
- Write as if telling **one scientific story** with one plotline.
- If a sentence fits two columns, it is probably misplaced—**split by职能**.
- Use **关键问题** as the hinge：内容、方案、可行、创新都要回扣它。

## Anti-patterns
- 用目标段复述内容；用内容段写操作步骤（串入方案）
- 创新写“交叉/热点/填补空白”
- 可行性只写仪器与经费，不写学术可行
- 前后概念偷换、理论与实验主张矛盾

## 栏目级写作指令（句子尺度）

### 1) 立项依据
**职能**：为什么选该科学问题。  
**推荐六问递进**（越写越聚焦）：
1. 工程/管理/科学现象是什么  
2. 对应科学实质与科学问题是什么  
3. 前人已解决什么  
4. 仍存在什么未解决问题  
5. 本申请拟解决哪一部分  
6. 其中关键科学/技术问题是什么  

**也可按四块写**：背景与问题 → 现状评述与拟解决 → 科学意义 → 设想与应用前景。

**句式骨架**：
- 背景：`【典型事实/争议/损失】表明，【现象】的科学实质是【学科问题类型】，可凝练为【科学问题句】。`
- 评述：`在【概念/方法/模型/实验/机理】方面，已有工作解决了【…】；但在【…】上仍存在【争议/缺失/不适用】，构成本项目拟解决的【子问题】。`
- 意义：`解决【关键问题】将在【概念/模型/判据/规律】层面形成【可陈述的学术推进】，并支撑【非等同于交付工程】的应用前景。`
- 设想：`总体思路是：先【假说/模型】，再【实验/数值验证】，最后【归题到关键问题】。`

**自检**：
- [ ] 背景是否靶向小背景（非政策开篇）？
- [ ] 评述是否按**科学角度**分类（非按国内外/单位）？
- [ ] 歧义概念是否已定义？
- [ ] 科学意义是否压过纯经济社会口号？

**反模式**：超长产业背景；文献按“国外—国内—本团队”叙事；只谈工程意义。

---

### 2) 研究内容
**职能**：对拟解决（关键）科学问题具体、深入、创新地**做什么**。  
**原则**：小题深做/精做/新做；理论·实验·模型须有侧重；最终归题。

**句式骨架**：
- 总起：`围绕【关键科学问题】，本项目设置相互支撑的【N】项内容：【逻辑一句话】。`
- 条目：`（i）建立【结构/环境/演化】描述，明确【假设】与【变量集】；（ii）通过【可指认工作】获得【可检验产出：方程/判据/参数范围/机制表述】；（iii）该项产出服务于【关键问题的哪一瓶颈】。`
- 数学/实验具体化：`数学模型采用【方程类型】，包含【本构/判据】及【初边值】；实验测定【物理量】，用于约束/验证【理论量】。`

**自检**：
- [ ] 每条是否回答“做什么”而非“怎么做步骤”？
- [ ] 是否具体到假设/变量/测点/方程类型？
- [ ] 是否反对大题小做、避免面面俱到？
- [ ] 与题目限制性定语是否兑现？

**反模式**：用目标代替内容；重复现状综述；清单式“开展理论、实验、模拟”无深度。

---

### 3) 研究目标
**职能**：内容完成后的科学目的（可分具体/总体）。  

**句式骨架**：
- `揭示【对象】在【条件】下的【规律/机理】；建立【模型/判据】；阐明【原理】；形成【可验证结论】，从而回答【科学问题句】。`

**自检**：与内容一一匹配；无非学术目标（产业化、平台建设当主目标）；不与摘要全文雷同。

**反模式**：目标过大空；用“发表论文/软件”代替科学目的。

---

### 4) 拟解决关键科学问题
**职能**：瓶颈、难点、主要矛盾；宜条目化并论证“何以关键”。  

**句式骨架**：
- `关键问题1：【问题句】。其关键性在于：若不解决，则【后续内容/目标】无法成立；难点在于【理论/实验/耦合】障碍【…】。`

**自检**：是否比总科学问题更窄？是否在内容/方案/创新中多次回扣？有无解释“为什么关键”？

---

### 5) 研究方案（方法·技术路线·实验手段·关键技术）
**职能**：怎么做；与内容匹配，细节充分但不暗示“已经做完”。  

**句式骨架**：
- 方法：`针对内容（i），采用【具体理论工具】完成【推导/约化】；针对内容（ii），采用【实验原理+装置能力】获取【数据】。`
- 路线：`按【顺序】推进：【A】→【B】→【C】；其中【反馈修正点】设在【…】。（配合框图）`
- 实验手段：`实验目的【…】；仪器【…】；步骤【…】；材料/试剂【…】；主要测点【…】。`
- 关键技术：`为达到【目标】，必须突破【技术瓶颈】，拟采取【可执行对策】。`

**自检**：方法是否逐一展开？路线是否有序衔接？实验要素是否齐全？有无与内容错位？

**反模式**：方法名录；过时/争议方法无辩护；多方法相互矛盾；路线无图无逻辑。

---

### 6) 可行性
**句式骨架**：
- 主观：`负责人与团队在【知识结构】上覆盖【内容所需能力】，已有【相关积累】。`
- 客观：`具备【平台/数据/现场】；缺口【…】的补齐路径为【…】。`
- 学术：`关键问题【…】在当前【理论/实验】条件下可推进，依据是【已有引理/预实验/可比工作】；关键技术【…】可通过【…】实现。`

---

### 7) 特色与创新之处
**句式骨架**：
- 特色：`相对一般【对象】，本项目聚焦【题目修饰词所限定的特殊结构/环境/过程】，其差异体现在【…】。`
- 创新：`提出/建立【新概念或新模型或新判据或新实验】，用于解决【关键问题】；相较于【最接近工作】，可检验差异是【…】。`

**自检**：条目化；解释“为什么算创新”；禁止“交叉即创新”“填补空白即创新”。

---

### 8) 年度计划与预期结果 / 预算接口
**句式骨架**：
- `第N年完成【内容条目】并形成【可检查产出】；预算科目【设备/材料/测试/差旅…】分别支撑【方案中的具体活动】。`

**自检**：期限符合当年指南（书中示例：青年3年、面上4年，起止常为次年1月1日至末年12月31日，**以当年指南为准**）；预算与内容/方案条款可逐条勾连。

## Worked Example（职能分离对照）
- 内容：`建立含水软岩边坡蠕变本构及屈服—加速转换判据`（做什么）  
- 方案：`采用分级加载蠕变试验测定…；用…方法识别拐点；以…算法拟合参数`（怎么做）  
- 目标：`阐明含水条件下蠕变加速启动机制并给出工程可移植的判据形式`（科学目的）

## Key Takeaways
1. 先锁关键问题，再展开各栏目。
2. 做什么≠怎么做≠做成什么。
3. 限制性定语贯穿：定义→内容→方案→创新。
