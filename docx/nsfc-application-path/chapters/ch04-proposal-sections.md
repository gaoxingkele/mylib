# 申请书栏目：逻辑与句级

## 栏目逻辑（必须同向）
题目 ⊃ 摘要 ⊃ 立项依据主线 ⊃ 关键科学问题 ⊃ 目标 ⊃ 内容 ⊃ 方案/路线 ⊃ 基础证据。任一断链即高风险。

## 机理类
贡献=揭示机制/路径/控制步骤。内容动词：阐明、揭示、解析。

## 模型类
贡献=建立并验证模型（含边界）。内容动词：建立、标定、验证、预测。

## 题目句级
`{系统/对象}的{特征结构/过程}{机理|演化|模型}研究`
或 `基于{方法}的{对象}{科学问题关键词}`
忌：纯工程任务名、空泛“关键技术研究”。

## 摘要句级（顺序）
1. 现象与矛盾（1–2句）
2. 科学问题陈述（1句）
3. 总体思路/假说（1–2句）
4. 主要内容要点（2–3句）
5. 方法与验证（1–2句）
6. 预期科学贡献（1句，非产品指标墙）

## 立项依据
与 `nsfc-tech-to-science-problem` 灵魂五问合并使用：本技能管系统分类与机理/模型定位，五问管段落节奏。

## 研究内容
每条：科学问题子句 + 方法 + 可交付认识；禁止纯进度计划语气。

## 常见问题（审计清单）
- [ ] 题目看不出科学问题
- [ ] 摘要像工作汇报
- [ ] 立项依据人名单位流水账
- [ ] 内容与关键科学问题不对齐
- [ ] 创新点不可证伪
- [ ] 把统计相关写成因果
- [ ] 基础与本申请脱节
