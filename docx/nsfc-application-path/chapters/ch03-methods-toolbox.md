# 研究方法工具箱（申请书中要显式声明）

| 方法 | 何时用 | 句子落点 |
|---|---|---|
| 组合概念与概念拓展 | 对象跨域、需新逻辑起点 | 定义{组合概念}=…，作为假说节点 |
| 特征结构法 | 系统复杂，需抓住决定性结构 | 以{特征结构}表征系统状态 |
| 非线性问题 | 线性叠加失效 | 区分结构非线性/环境非线性/响应非线性 |
| 假说族 | 任何机理/模型类 | 结构假说 / 环境假说 / 响应假说 / 综合假说 |
| 反问题 | 由结果反推原因/参数 | 由{观测}反演{结构参量}并给不适定处理 |
| 因果 vs 统计 | 数据驱动段落 | 相关证据不得写成因果；因果需机制或干预 |
| 思想实验 | 极限条件澄清概念 | 在{理想化设定}下预期{推论} |

## 自检
方法名出现在研究方案，且每条内容能指到一个方法；禁止“采用多种先进方法”空句。
