# 第1章：科学研究心智与申请预备

## Core Idea
国自然申请不是“找个题目填表”，而是用系统哲学把对象拆成结构（内因）—环境（外因）—相互作用演化，再落到可检验的科学问题上；申请书质量决定函评命运。

## Frameworks Introduced
- **系统三要素**：组成部分、时空秩序、联系规则
  - When：把任何工程/现象对象写成“可研究系统”时
  - How：先列组分 → 再写时空排布与连接规则 → 再谈边界与环境作用
- **内因—外因—演化**：结构 × 环境 → 孕育/潜伏/发生/爆发/持续/衰减/终止
  - When：选题、机理类项目、研究内容分层
  - How：每个阶段问“控制变量是什么、判据是什么”
- **科学问题三型**：是什么(what) / 怎么样(how) / 为什么(why)
  - When：题目与关键科学问题定稿
  - How：一句问题句只承载一种主导型，避免三者混写

## Key Concepts
- **基础研究/应用基础研究**：认识现象、探索规律、获取新知识/新原理/新方法；非工艺改造、产品设计、效果评价本身
- **关键学术问题**：主要矛盾或矛盾主要方面；解决后可“一通百通”
- **知其所以然**：不止知其然；要交代来龙去脉与控制原理
- **预备能力**：概念清晰、假说意识、实验—理论互证、逻辑自洽

## Mental Models
- Use **系统镜头** when 工程现象纷杂：先定边界，再定内外因，再定阶段。
- Prefer **小题深做** over 大题小做：范围越小越容易具体、深入、创新。
- Think of **申请书评审≈对申请书评审**：函评几乎只看文本，文本必须可审核。

## Anti-patterns
- **技术问题冒充科学问题**：工艺参数优化、产品设计、规范制订当题目主词
- **背景口号开篇**：经济形势、能源占比、热点词堆砌，不落到科学实质
- **研究积累与选题脱节**：基础部分写“广而炫”，与拟解决关键问题无关
- **口语化叙事**：“我们/本文/首先其次然后最后/大概可能若干”

## 栏目级写作指令（预备与基础呈现）

### A. 申请人/团队基础（研究基础与工作条件）
**何时用**：写“工作基础、工作条件、简历、在研项目”时。  
**怎么写**：每条成绩必须绑定“与本题科学问题的相关性/典型性/时效性”。  
**句式骨架**：
- `申请人前期在【对象/结构】方面已完成【可核验成果类型：模型/实验/判据】，获得【可点名的关键结论或参数范围】，为本项目拟解决的【关键科学问题】提供了【直接可复用的方法/数据/设备】。`
- `已具备【仪器/平台/现场】条件，可完成【测试量A、B】；尚缺【条件X】，拟通过【合作实验室/补充购置/共享平台】在【时间节点】落实。`

**自检**：
- [ ] 每条基础都能指回题目中心词或限制性定语？
- [ ] 有无“与本题无关的荣誉清单”？
- [ ] 缺条件是否写了补齐路径（非空喊“条件优越”）？

**反模式**：堆 SCI 数量、堆奖项、不写与关键问题的映射；青年项目写成“资深团队依赖”。

### B. 青年方向选择（对应书中青年建议）
**句式骨架**：
- `本研究方向落在【学科交叉边界/工程现象族】，申请人可在【三年/四年】内独立完成从【假说】到【验证】的闭环，而非依赖尚未落实的外部条件。`

**自检**：方向是否“特色鲜明、优势明显、适宜自身情境”？是否绕开不可控的大工程依赖？

## Worked Example（结构三要素落句）
**对象**：某边坡失稳。  
- 组成部分：岩层、结构面、含水带……  
- 时空秩序：层序、倾向、季节水位……  
- 联系规则：接触、贯通、渗流通道……  
落句：`将【边坡】视为系统，其结构由【组分】按【时空秩序】以【联系规则】组成；在【外因环境】作用下进入【演化阶段】，本项目聚焦该阶段的【机理/模型】问题。`

## Key Takeaways
1. 先系统化对象，再凝练科学问题，再写栏目。
2. 申请人基础要“可审核映射”，不是履历展览。
3. 语言用第三人称科学表述，删除量词含糊词。
