# 第4.9章 + 附录：初筛、函评雷区、预算附件与评议视角

## Core Idea
申请书先过**初筛（形式/资格/代码/限项）**，再过**函评（科学质量）**。初筛失败是硬伤；函评失败多来自“非科学问题、不具体、逻辑不闭合、创新不可指认”。用清单自查，不靠运气。

## Frameworks Introduced
- **评审漏斗**：初筛 → 函审 → 会审
- **初筛口诀（书中归纳）**：**二违反**（违反项目管理规定/办法）、**三不**（不具备资格、不属于学科资助范围、预算不合理）、**四无**（无签字、无盖章、无推荐信、无合作协议）
- **函评栏目病句表**：选题→题目→摘要→依据→内容→目标→关键问题→方案→可行→创新→整体→基础→预算
- **类别评议重心**：青年重创新潜力；面上重创新与完成情况；地区重稳定培养；优青/杰青重申请人成就与构思

## Key Concepts
- **申请代码错配**：不属于所选代码学科指南资助范畴（初筛高频）
- **版本一致性**：纸质与电子版本号一致（以当年提交方式为准）
- **研究期限**：须符合当年指南（书中示例：青年3年、面上4年；起止常为次年1/1—末年12/31）
- **预算匹配**：科目与研究内容/方案活动可追溯
- **附件要件**：公章原件一致性、签名一致性、推荐信/导师同意函/合作协议（按身份触发）

## Mental Models
- Before polishing prose, clear **formality blockers**.
- Read your proposal as a **函评专家**：只相信写在纸上的机制与证据。
- Match **project type** peer-review emphasis (青年≠面上≠杰青).

## Anti-patterns
- 以为“内容好就能过”而忽视签字盖章限项代码
- 预算拍脑袋，与实验次数/设备/差旅无勾连
- 青年本子过度堆团队大佬，掩盖申请人独立性
- 用过时的资助额度/评议细则（附录数据为书出版时口径）

## 1. 申请流程与时间线（书内可提取部分）

**可知节点**：
1. 按当年《项目指南》确认资格、限项、代码、期限、预算编报规则  
2. 撰写申请书（科学问题主线闭合）  
3. 依托单位审核 → 提交（电子/纸质要求以当年为准）  
4. 自然科学基金委初筛  
5. 函审 →（通过后）会审  
6. 获批后：按计划书执行；把握年度节点；经费遵循真实、合理、合规、相关  

**书中执行期提醒（获批后）**：实验可先行；内容—人员—进度协调；年度报告与成果节奏；不同类型项目执行年限不同。

**缺口声明**：书中**无**完整“申报日历（几月下载系统/几月截止）”；须用当年指南与 ISIS 系统通知补齐。

## 2. 形式审查 / 初筛自检清单

**何时用**：提交前 48 小时。  

| # | 检查项 | 失败形态 |
|---|---|---|
| 1 | 申请代码与资助范畴 | 内容不属于该学科指南 |
| 2 | 研究领域选择 | 领域与问题错配 |
| 3 | 公章 | 无章/非原件/名称不一致；合作单位同理 |
| 4 | 缺页缺项 | 缺参与者简历等 |
| 5 | 研究期限 | 年限或起止不合指南 |
| 6 | 电子-纸质一致 | 版本号不一致 |
| 7 | 打印装订份数 | 有无合作单位导致份数要求不同（以当年为准） |
| 8 | 身份信息 | 身份证、职称、年龄、学位、单位信息错误 |
| 9 | 签名 | 未签或与基本信息姓名不一致 |
| 10 | 职称信息一致 | 多处填写冲突 |
| 11 | 推荐信 | 无高称且无博士未附或不符合要求 |
| 12 | 在职研究生 | 缺导师同意函 |
| 13 | 限项 | 申请超项 |
| 14 | 诚信与合规 | 二违反 |
| 15 | 资格/范畴/预算 | 三不 |
| 16 | 签字盖章推荐合作 | 四无 |

**句式（单位审核沟通，非正文）**：
- `请核对：代码【】是否在指南资助范围；参与者限项；合作协议与公章名称；推荐信触发条件【是/否】。`

## 3. 学科代码（再次强调）
- 选择与**科学问题**相关性最大的代码  
- 自检：用指南关键词检索，确认本项目中心词落在资助叙述内  
- 错配后果：初筛直接出局，与文笔无关

## 4. 函评雷区：栏目级反模式 → 改写动作

### 选题
- 反：技术开发/工艺/产品设计/效果评价/规范/施工  
- 改：升维到机理、模型、规律、方法、判据

### 题目
- 反：皮大馅小、拔高、重复、过长过空、歧义  
- 改：见 Ch05 中心词法

### 摘要
- 反：第一人称、背景过长、无方法、内容空、目标不清、与目标雷同、含公式  
- 改：摘要句链 + 具体化

### 立项依据
- 反：背景错层；问题不重要/纯个案；歧义未解释；评述非科学分类；意义只谈工程经济社会；无设想；文献不新不经典或自吹  
- 改：六问递进 + 科学角度分类

### 研究内容
- 反：不具体不深入无创新；重复已有；分散求全；用目标代替；不归题；与方案错位  
- 改：具体化四问 + 归题句

### 研究目标
- 反：非学术目标；过大过小；用成果代替目标；与内容不匹配  
- 改：科学目的句式

### 关键科学问题
- 反：无实质；未凝练瓶颈；无条目；无“何以关键”  
- 改：条目 + 关键性论证

### 研究方案
- 反：方法不具体/过时/互斥；路线无序无图；实验要素缺失；关键技术空；与内容不匹配  
- 改：方法逐条展开 + 路线图

### 可行性
- 反：只谈软硬件，不谈关键问题的学术可行  
- 改：主观/客观/学术三块

### 特色创新
- 反：不结合修饰词特殊性；不条目化；交叉/空白/热点当创新  
- 改：特色←修饰词；创新←关键问题的新知识物

### 整体结构
- 反：前后概念偷换、理论实验矛盾、逻辑不闭合  
- 改：对应表逐行打勾

### 研究基础与条件
- 反：无关积累；团队搭配不合理；缺条件无路径；不写重点实验室使用计划  
- 改：相关性/典型性/时效性三性

### 经费预算
- 反：不合管理办法；与内容方案不匹配  
- 改：活动—科目映射表（书中无细科目模板，须按当年预算编报说明）

## 5. 申请人基础呈现（函评视角）

**青年（附录A）**：突出创新潜力与思维；不必过度强调队伍与积累。  
**句式**：
- `申请人已独立完成【预研究】，显示出提出【假说】并设计【验证】的能力；本项目是该能力的延伸而非依附【导师大项目】的分包。`

**面上（附录B）**：强调创新；若有在研/完成基金，交代完成质量及与本申请相关性（防重复）。  

**地区（附录C）**：稳定培养导向；不必硬绑“本地特色”标签。  

**优青/杰青**：评议重心转向申请人成就、潜力与未来构思（本技能以面上/青年写作为主，人才类另开专档）。

---

## 6. 预算与附件（可执行最小集）

**预算匹配句式（预算说明书/测算依据）**：
- `【实验/测试/差旅/劳务…】费用对应方案中【活动名称】，测算依据为【次数×单价/标准】，支撑研究内容（【编号】）。`

**附件触发**：
- 合作单位 → 协议 + 公章要求  
- 无高称且无博士 → 推荐信  
- 在职研究生 → 导师同意函  
- 所有人 → 签名与信息一致  

**缺口声明**：书中无差旅标准、设备阈值模板、附件格式样例；以当年指南与财务规定为准。

---

## 7. 提交前总检（10 分钟版）
1. 代码与指南范畴  
2. 限项与签名盖章推荐合作  
3. 题目中心词 = 摘要点题 = 关键问题  
4. 内容做什么 ≠ 方案怎么做  
5. 创新可指认且回扣关键问题  
6. 预算行能指回方案活动  
7. 删除 AI/口语套话与含糊量词  

## Key Takeaways
1. 先灭初筛，再拼函评。  
2. 函评雷区按栏目改，不按“写得更华丽”改。  
3. 规则以**当年指南**覆盖本书2019口径。
