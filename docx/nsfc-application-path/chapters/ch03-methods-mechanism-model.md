# 第3–4.2章：方法、假说、机理类与模型类

## Core Idea
国自然常见可资助形态是“机理类”与“模型类”：前者揭示结构—环境相互作用规律与控制变量；后者在相似简化上建立可求解、可验证的描述。二者都要有假说、判据与验证闭环。

## Frameworks Introduced
- **演化七阶段**：孕育→潜伏→发生→爆发→持续→衰减→终止
  - When：机理类内容分层、阶段模型
  - How：每阶段独立机理 + 阶段转换判据；勿把全生命周期糊成一句“全过程机理”
- **演化机理 vs 防治/调控机理**：病理 vs 药理
  - When：题目含“防治/调控/整治”
  - How：先写清形成机理与控制变量，再写调控该变量的原理；二者不可混称为同一个“机理”
- **三类假说**：结构假说 / 环境假说 / 结构—环境相互作用（演化）假说（可综合）
  - When：研究内容与研究设想
  - How：假说可检验；写清将被什么实验/数据证伪或支持
- **模型七步**：科学问题与基本假设 → 拐点/突变判据 → 状态(控制)方程 → 定解条件 → 求解 → 检验修正 → 应用
  - When：模型类研究内容条目
  - How：申请书常缺第2、4、6步，优先补齐
- **特征结构法**：从特征单元/特征结构切入再扩展
  - When：复杂系统难以下手
  - How：先简单结构+简单环境 → 因果关系清晰 → 再升维耦合

## Key Concepts
- **原型 vs 模型**：原型是实体；模型抽取本质因素并保持结构/环境/功能相似性
- **控制变量**：支配演化方向与进程的变量（结构信息或环境信息，或耦合量）
- **组合概念与概念拓展**：定义跨域逻辑起点与假说节点
- **反问题**：由响应反演结构/参数/源项；须声明适定性与验证策略
- **因果关系 vs 统计规律**：机制解释优先；相关不得写成因果；统计需样本与条件声明
- **思想实验**：逻辑推演边界与极端情形，服务假说，不能替代实证
- **方法落点自检**：研究方案中的方法名须能指回某条研究内容；禁止“采用多种先进方法”空句

## Mental Models
- Use **阶段切开** when “机理”过大：先声明研究落在哪一阶段。
- Prefer **实验—理论互证**：实验供事实与检验；理论供解释与预见。
- When writing **模型**, insist on：假设、判据、定解、验证四件套。

## Anti-patterns
- **机理口号化**：“揭示相互作用机理”无变量、无阶段、无判据
- **模型有方程无边界**：缺初始/边界条件与适用范围
- **数值模拟=全部创新**：无新假设/新判据/新耦合机制，只是商业软件算例
- **防治机理跳步**：未弄清形成机理直接写治理技术
- **假说不可检验**：无法指出何种观测会削弱假说

## 栏目级写作指令

### A. 机理类研究内容条目
**句式骨架**：
- `针对【对象】在【阶段】的演化，解析其【结构三要素】在【环境作用类型：力/热/化/生/耦合】下的响应，识别控制变量【V】，建立【阶段】机理表述，并给出由【状态A】转入【状态B】的判据【C】。`
- `通过【实验可测信息：声/光/电/变形/组分…】捕捉【阶段】特征信号，建立信号—机制映射，用于检验【假说H】。`

**自检**：
- [ ] 是否写明阶段？控制变量？判据？
- [ ] 实验测什么量，如何对应理论量？
- [ ] 演化机理与防治机理有无混写？

### B. 模型类研究内容条目
**句式骨架**：
- `在假设【H1…Hk】下，建立描述【原型特性】的【结构/环境/演化】模型；给出状态方程【形式：ODE/PDE/能量泛函…】、初始条件【…】与边界条件【…】；定义【拐点/屈服/失稳】判据；采用【解析/数值方法】求解，并以【实验/现场/历史事件反演】验证并修正。`

**自检**：
- [ ] 七步中缺哪一步？
- [ ] 相似性声明了结构相似、环境相似还是功能相似？
- [ ] 验证量是否与模型内涵相关（非随便贴一条曲线）？

### C. 假说段（可放立项依据“研究设想”或内容总起）
**句式骨架**：
- `提出【结构/环境/演化】假说：若【条件】成立，则【可观测推论】；该假说将由【实验设计E】与【对比分析】加以检验，若出现【反例情形】则修正假设【Hi】。`

## Worked Example（岩石受压四阶段 → 分机理）
密实 → 线弹性 → 塑性强化 → 塑性软化：各阶段本构、可逆性、叠加原理适用性不同。  
**写作启示**：禁止一句“研究全过程破坏机理”；应写清本项目覆盖哪几段、段间判据、是否考虑试验机—试件相互作用。

## Key Takeaways
1. 机理要落到阶段、变量、判据；模型要落到假设、定解、验证。
2. 假说必须可检验。
3. 方法服务于科学问题，不是方法名录展览。
