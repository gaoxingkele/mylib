# 第2章：选题、科学问题与学科代码

## Core Idea
选题成功=从工程/技术需求中抽出可普遍化的科学问题；申请代码必须落在该科学问题所属学科资助范畴，而不是“单位习惯代码”或“热点学部”。

## Frameworks Introduced
- **工程需求→科学问题升维**：现象/损失/争议 → 科学实质 → what/how/why 问题句
  - When：立项依据开篇与题目定稿
  - How：同一现象可对应不同实质；只选与题目匹配的那一层背景
- **选题七类**：结构类 / 环境类 / 演化机理类 / 模型类 / 方法类 / 控制原理类 / 调控机理类
  - When：定中心词与研究内容侧重
  - How：题目中心词标明类型；全文栏目保持该类型侧重点
- **背景三层靶向**：大背景→中背景→小背景，只保留与选题最贴的一层
  - When：立项依据与摘要背景段
  - How：删掉“随着……发展”类远景句，直击典型事实

## Key Concepts
- **科学问题**：主体与客体、已知与未知的矛盾；规定方向、途径与价值
- **拟解决科学问题**：大问题中“未解决但可能解决”的子集
- **关键科学问题**：更小、更聚焦的瓶颈；主要矛盾
- **申请代码**：与凝练科学问题相关性最大的学科代码；决定指南资助范畴与函评专家池
- **关键词**：主题词组合=主线；常用于分派函评专家

## Mental Models
- Use **升维检验** when 题目像工程任务：能否改写成“机理/规律/模型/判据/方法”中心词？
- Prefer **本质相同的多案例** over 单个工程故事：保证普适性。
- When choosing **申请代码**, ask：科学问题的学科归属 vs 应用场景归属——以前者为准。

## Anti-patterns
- **工程题、工艺题、评价题、设计题**直接当国自然题目
- **代码就近原则**：按学院传统代码投，与科学问题错配 → 初筛“不属于资助范畴”
- **热点词选题**：大数据/AI/交叉口号无机制
- **问题不可普遍化**：纯个案、无可迁移规律

## 栏目级写作指令

### A. 科学问题句（选题核心产出）
**何时用**：题目、摘要首段、立项依据凝练处、关键问题条目。  
**怎么写**：一句问题句=对象+条件/限制性定语+中心科学动词/名词（机理/模型/规律/判据…）。  

**句式骨架**：
- `在【特殊环境/极端条件】下，【特定结构对象】的【演化现象】由何种【内因结构特征】与【外因作用】耦合所支配，其【阶段判据/控制变量】是什么？`（why/how 主导）
- `如何建立可描述【对象】在【阶段】响应的【结构/环境/演化】模型，并给出【拐点/突变】判据与【定解条件】？`（模型类）
- `【现象族】的共同科学实质是【力学/物理/化学/…问题】，可抽象为【科学问题一句话】。`

**正例倾向**：`动力扰动下断层活化诱发煤与瓦斯突出机理`（中心词清晰+限制性条件）。  
**反例倾向**：`……关键技术研究` / `……体系研究` / `……评价与应用`。

**自检**：
- [ ] 去掉工程专名后，是否仍是可迁移的科学问题？
- [ ] 是否能指认属于七类选题中的哪一类？
- [ ] 是否可被证伪或至少可被实验/理论检验？

### B. 申请代码与关键词
**何时用**：简表。  
**怎么写**：代码对准科学问题学科；关键词覆盖中心词+限制性定语+方法词，避免一级学科空词。  

**句式骨架（自述核对，不写进正文）**：
- `科学问题归属【二级学科概念】；申请代码选择【代码】，因为其指南关键词/资助方向覆盖【中心词】；备选代码【X】因偏【应用场景】而放弃。`

**关键词槽位**：`[对象结构] [环境/条件] [机理或模型] [方法] [关键变量]`（5个左右，可检索、可派专家）

**自检**：
- [ ] 关键词拼起来能否复述题目主线？
- [ ] 有无“安全/保护/工程/背景”等过宽词？
- [ ] 代码所属指南是否明确排除本类工作？

### C. 从工程案例凝练（对应书中案例分析思路）
**步骤**：
1. 列 2–3 个本质相同的典型现象/事故/争议  
2. 写“科学实质一句话”（力学？输运？反应？信息？）  
3. 写“前人已解决 / 未解决”  
4. 收束到拟解决子集与关键瓶颈  

**句式骨架**：
- `以【案例1】与【案例2】为代表的现象，表面差异为【…】，共同实质为【…】；现有研究在【概念/模型/实验】上已解决【…】，但在【瓶颈】上仍缺乏【可检验表述】。`

## Worked Example（限制性定语=特色）
- 原概念：`边坡稳定性`  
- 限制性定语：`强震作用下`  
- 题目落点：`强震作用下边坡……机理/响应…`  
- 全文义务：立项依据解释“强震作用”内涵；研究内容写对此限制做什么；方案写怎么做；创新点回扣该限制。

## Key Takeaways
1. 选题类型决定中心词，中心词决定全文逻辑。
2. 申请代码跟科学问题走，不跟单位习惯走。
3. 背景只保留与问题匹配的那一层。
