# 科学研究与基金预备

## 科学问题从哪来（五源）
1. 实践与实践矛盾
2. 实践与理论矛盾
3. 理论与理论矛盾
4. 理论自身逻辑矛盾
5. 新观测/新工具打开的问题空间

形式：是什么 / 怎么样 / 为什么。科学研究始于提出问题，以解决问题为阶段任务。

## 写作用指令
- 先定义你在做基础还是应用基础；创新点必须落在认识规律或方法原理，而非仅工程交付。
- 青年选题：特色鲜明、优势明显、适宜情境；围绕关键学术问题而非热点词云。
- 预备能力：会读领域脉络、会抽象、会假说、会设计可重复验证，而不是只会堆工作量。

## 句式
> 本项目要回答的不是“如何把{工程指标}做上去”，而是“{现象}在{条件}下由何种{结构/机制}所支配”。
