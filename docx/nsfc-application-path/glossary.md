# 术语表 — 《国家自然科学基金项目申请之路》

**申请代码** — 简表中选择的学科代码；须与科学问题所属指南资助范畴一致，并影响函评专家分派。(Ch4.3, 4.9)

**限制性定语** — 题目中限定中心词时空/条件/对象特殊性的修饰成分；常构成特色，须在立项依据定义并在内容/方案兑现。(Ch4.3–4.5)

**中心词（组）** — 题目中标志科学任务主干的词，如机理、模型、规律、判据、方法。(Ch4.5)

**科学问题** — 研究中已知与未知的矛盾；主导形式为是什么/怎么样/为什么。(Ch1–2)

**拟解决科学问题** — 所凝练大问题中“未解决但可能解决”、由本申请承担的子集。(Ch4.3)

**关键科学问题** — 更窄的瓶颈/主要矛盾；解决后牵动全局；宜条目化并论证关键性。(Ch4.3–4.4)

**系统三要素** — 组成部分、时空秩序、联系规则；描述系统结构（内因）。(Ch1–2)

**演化七阶段** — 孕育、潜伏、发生、爆发、持续、衰减、终止。(Ch2, 4.1)

**演化机理** — 结构与环境相互作用并随时间演化的原理与规律。(Ch4.1)

**防治/调控机理** — 调节控制变量以阻止或引导演化的原理；不同于形成/演化机理。(Ch4.1)

**控制变量** — 支配演化方向与进程的关键量（结构侧、环境侧或耦合）。(Ch4.1)

**结构/环境/演化假说** — 对内因、外因或相互作用的可检验假定。(Ch3, 4.3)

**原型** — 研究对象实体；模型是其本质因素的简化模仿。(Ch4.2)

**模型七步** — 问题与假设→判据→状态方程→定解条件→求解→检验优化→应用。(Ch4.2)

**定解条件** — 初始条件与边界条件等使模型可解的条件。(Ch4.2)

**特征结构法** — 从特征单元/特征结构切入再扩展到复杂系统的方法。(Ch3)

**反问题** — 由观测响应反演结构、参数或源项的问题类型。(Ch3)

**小题深做** — 反对大题小做；主张范围聚焦后做深、做精、做新。(Ch4.4)

**归题** — 分项内容/目标最终回到拟解决（关键）科学问题。(Ch4.3–4.4)

**学术可行性** — 从学科发展水平与队伍能力论证关键问题/关键技术可推进。(Ch4.3–4.4)

**简表** — 申请书基本信息区：题目、代码、摘要、关键词等。(Ch4.3)

**初筛** — 基金委在函审前的形式/资格/范畴等检查。(Ch4.9)

**二违反** — 违反项目管理规定、违反项目管理办法。(Ch4.9)

**三不** — 不具备申请资格；不属于申请学科资助范围；经费预算不合理。(Ch4.9)

**四无** — 无签字、无盖章、无推荐信、无合作协议。(Ch4.9)

**函审/函评** — 同行专家通讯评议；申请书文本几乎是唯一依据。(Ch4.9, 附录)

**会审** — 初筛与函审后的会议评审环节。(Ch4.9)

**基础研究 / 应用基础研究** — 认识现象、探索规律、获取新知识/新原理/新方法；国自然主资助类型。(Ch1, 序)

**关键词** — 反映主题的词组组合；用于检索与专家分派；忌过宽一级学科词。(Ch4.3–4.4)
