# Cheatsheet — 决策与判据（申请之路）

## 1. 一分钟总流程
科学问题句 → 选题类型/中心词 → 申请代码 → 栏目对应表 → 摘要句链 → 初筛清单 → 函评栏目自检

## 2. 选题类型 → 中心词 → 内容侧重

| 类型 | 中心词信号 | 内容应出现 | 警惕 |
|---|---|---|---|
| 结构类 | 特征/组成/结构 | 三要素刻画 | 写成地质描述流水账 |
| 环境类 | 荷载/场/介质作用 | 环境模型与作用方式 | 只列环境不谈响应 |
| 演化机理类 | 机理/机制/原理 | 阶段+变量+判据 | 全过程空机理 |
| 模型类 | 模型/建模/本构 | 七步尤其定解与验证 | 纯软件算例 |
| 方法类 | 算法/实验方法 | 方法创新点可指认 | 套用旧方法做大作业 |
| 控制/调控类 | 防治/调控/控制 | 先形成机理再调控原理 | 直接写工法参数 |

## 3. 栏目决策：写什么 / 不写什么

| 栏目 | 写 | 不写 |
|---|---|---|
| 题目 | 中心词+必要修饰 | 自我评价、过宽词、设计评价 |
| 摘要 | 问题+具体内容块 | 长背景、第一人称、公式 |
| 立项依据 | 六问递进、科学分类评述 | 政策开篇、只谈经济社会意义 |
| 研究内容 | 做什么+知识物 | 操作步骤详解 |
| 研究目标 | 科学目的 | 论文数/产业化 KPI |
| 关键问题 | 窄瓶颈+何以关键 | 重复标题、技术堆砌 |
| 研究方案 | 怎么做+路线 | 与内容相同的“建立…”空话 |
| 可行性 | 主观/客观/**学术** | 只夸条件 |
| 创新 | 可指认差异 | 交叉/空白/热点 |
| 基础 | 映射到本题 | 无关荣誉墙 |
| 预算 | 匹配活动 | 拍脑袋整数 |

## 4. 科学问题 vs 技术问题（快判）

| 信号 | 更像技术问题 | 更像科学问题 |
|---|---|---|
| 动词 | 研制/优化工艺/评价效果 | 阐明/建立判据/揭示机制 |
| 产出 | 装置、参数表、规程 | 模型、规律、原理、方法 |
| 失败 | 指标不达标 | 机制说不清、假说不成立 |
| 迁移 | 换现场即失效 | 可迁移到同类系统 |

**决策**：技术信号为主 → 升维或换题；科学信号为主 → 进入栏目写作。

## 5. 摘要篇幅决策
- 超长：先砍背景，再砍前景，最后才压缩内容句（内容句优先保留具体名词）  
- 过空：把“相互作用/关键参数/体系”全部替换为可点名实体

## 6. 初筛口诀
- **二违反** · **三不** · **四无**  
- 额外高频：代码范畴、限项、期限、信息一致、版本一致

## 7. 函评“致命组合”
1. 非科学问题 + 应用口吻  
2. 内容不具体 + 创新口号  
3. 关键问题空 + 方案方法名录  
4. 前后逻辑不闭合 + 预算不匹配  

任一组合出现 → 优先结构性返工，不优先润色。

## 8. 项目类型评议重心（附录）

| 类型 | 更看重 | 相对淡化 |
|---|---|---|
| 青年 | 创新潜力与思维 | 大团队积累 |
| 面上 | 创新性、方案、基础与完成情况 | — |
| 地区 | 稳定培养与价值 | 硬绑本地题材 |
| 优青/杰青 | 申请人成就与未来构思 | 普通栏目细节（仍需可行） |

## 9. 语言红线（书中）
少用：我们/本文/本课题/首先其次然后/大概可能/若干/一定的  
慎用：基于、针对  
删除多余“的了其本”；统一标点全半角；物理量与正斜体规范
