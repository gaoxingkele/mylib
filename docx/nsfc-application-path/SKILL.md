# 国家自然科学基金项目申请之路（句子级技能）
**作者**：王来贵、朱旺喜 | **出版**：科学出版社，2019 | **章节**：4 章 + 评议附录 | **蒸馏**：2026-11-02

## 何时使用
- 写或改国自然（青年/面上/地区等）申请书栏目
- 把工程/技术表述升维为可资助科学问题
- 提交前做形式审查与函评视角自检
- 需要**栏目级句式骨架 + 自检 + 反模式**，而非空泛经验谈

## 硬规则（先读）
1. **提取结构而不是复述书**：优先用命名框架与判据写作。  
2. **科学问题主线**：题目、摘要、依据、内容、目标、关键问题、方案、创新必须闭合。  
3. **做什么 ≠ 怎么做 ≠ 做成什么**。  
4. **可审核**：每个主张旁有对象、变量、判据、方法或证据槽；禁止“重要/深入/首次系统”空转。  
5. **去 AI 套话**：禁交叉口号、填补空白、广阔前景无指认、关键参数不点名。  
6. **规则时效**：资格、限项、期限、预算、纸质要求以**当年项目指南**覆盖本书口径。  
7. **边界**：本技能管“申请之路”方法论与栏目写法；技术问题升维亦可参考姊妹技能 `nsfc-tech-to-science-problem`；凝练案例程序见 `nsfc-science-problem-cases`。

## Core Frameworks & Mental Models

### 1. 科学问题主线法
Use when 搭整本申请书。  
**How**：先写科学问题句与关键问题 → 建“子问题↔内容↔目标↔方法↔创新↔学术可行”对应表 → 各栏目只从不同角度回答同一主线。  
**判据**：任意段落删掉后，主线仍应可被题目+关键问题复述。

### 2. 系统三要素 × 内外因演化
Use when 选题与机理/模型内容设计。  
- 结构（内因）= 组成部分 + 时空秩序 + 联系规则  
- 环境（外因）= 力/热/化/生等作用  
- 演化 = 七阶段（孕育→…→终止），阶段间要有判据  
**Prefer** 切开阶段写机理，**over** “全过程机理”一句空转。

### 3. 立项依据六问递进
现象 → 科学实质/问题 → 已解决 → 未解决 → 拟解决 → 关键问题。  
越往后越窄；背景只保留与问题匹配的小背景。

### 4. 机理类 vs 模型类
- **机理类**：阶段 + 控制变量 + 转换判据；区分演化机理与防治/调控机理（病理≠药理）。  
- **模型类**：问题与假设 → 判据 → 状态方程 → 定解条件 → 求解 → 验证修正 → 应用（申请书常缺判据/定解/验证）。

### 5. 限制性定语 = 特色锚点
题目修饰词界定特殊性；依据中定义，内容写对此做什么，方案写怎么做，创新回扣它。

### 6. 小题深做
反对大题小做；范围聚焦后才能具体、深入、创新。

### 7. 初筛门禁：二违反 · 三不 · 四无
形式/资格/代码范畴/预算/签字盖章推荐合作等硬伤优先于文笔。  
申请代码选与**科学问题**相关性最大者，防“不属于资助范畴”。

### 8. 摘要句链（约400字）
背景+问题≈100｜方法对应的具体内容≥200｜目标与前景≤100；第三人称；点题；不与目标栏雷同。

### 栏目速查句式（详情见 chapters）
- **题目**：`【修饰条件/对象】+【中心词：机理/模型/规律/方法…】`  
- **摘要**：`…实质为…问题是…。项目采用…，…；采用…，…。旨在…，为…提供…。`  
- **内容**：`围绕关键问题，完成【知识物】（假设/变量/判据/测点须现身）。`  
- **方案**：`针对内容（i），采用【工具/步骤】获取/求解【…】。`  
- **关键问题**：`【窄问题句】。关键性在于若不解决则【…】无法成立。`  
- **创新**：`相对【最接近工作】，本项目的可检验差异是【…】。`

## 缺口（蒸馏时标注）
1. **申报日历**不完整（几月开放/截止等须查当年通知）。  
2. **预算细目与附件格式**仅有原则与匹配要求，无科目模板。  
3. **学科代码**仅有“跟科学问题最大相关”原则，无代码表。  
4. 书偏**工程科学/力学**案例，迁移到数理化生医时保留框架、替换例子。  
5. 附录评议经费与部分形式要求为**2019口径**，可能过时。  
6. “四类科学问题属性”在序中提及，本书未展开为栏目写作程序。
