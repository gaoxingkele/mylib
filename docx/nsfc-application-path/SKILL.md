# 国家自然科学基金项目申请之路

## 核心框架
1. **认识现象·探索规律**：从生产/社会实践凝练科学问题，返回指导实践。
2. **系统视角**：结构/边界/环境/演化动力/演化阶段/响应；问题可归为结构类、环境类、演化机理类、模型类、方法类、调控原理类。
3. **四类科学问题属性**（申请时单选主属性）：鼓励探索突出原创；聚焦前沿独辟蹊径；需求牵引突破瓶颈；共性导向交叉融通。
4. **科学问题三问型**：是什么 / 怎么样 / 为什么。
5. **方法工具箱**：组合概念与拓展、特征结构法、非线性、结构/环境/响应/综合假说、反问题、因果与统计、思想实验。
6. **本子类型**：**机理类**与**模型类**是常见主类型；逻辑关系贯穿各栏目。

## 工作流
属性归类 → 系统要素表 → 机理或模型定位 → 题目/摘要句级 → 立项依据逻辑 → 内容条目 → 常见问题清单审计 → 挂接 tech-to-science 的灵魂五问深化。
