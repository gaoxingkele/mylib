# Chapter 5: 注入创新的四种方法

## Core Idea
创新对准理论四要素（概念/命题/逻辑/边界），用四法可操作地找缝隙，而非堆“首次/填补空白”。

## Frameworks Introduced
- **维度转换法（概念重塑）**  
  1) 建立多维界定 2) 溯源主流维度 3) 换到相对/互补维度重塑概念  
  - 约束：优先转换到与主流相对的维度，避免随意贴标签。
- **负面启发法（命题突破）**——盯三类矛盾：  
  现实 vs 理论；学科间冲突；同科流派冲突。
- **应用拓展法（边界重构）**：改情境/人群/制度边界，检验理论外推。
- **逻辑调优法（逻辑验证）**：数据可靠性与交叉验证、对照与交互控制、多维动态分析、结论一致性。

## Key Concepts
- **研究缝隙**：可操作、可检验、与创新点一一对应的缺口。
- **命题**：概念间关系声明；有矛盾处才有突破口。

## Mental Models
- Use **负面启发** when “题目好听但说不清新在哪”。
- Use **维度转换** when 概念被单一视角锁死。

## Anti-patterns
- “本文首次研究某某”而无矛盾定位。
- 转换维度后不改测量与设计，只改标题形容词。

## Worked Example
选题《远程办公女性职业倦怠机制与干预》：  
- 维度转换：补环境维度（光照、隔离度）进概念体系。  
- 负面启发：线下倦怠模型未解释家庭照料+数字化加班 → 新命题变量。  
- 流派冲突：资源保存 vs JD-R → 提出灵活性调节假说。

**句级模板（论证）**  
“既有理论 T 在情境 S 下预期 R；观测到 O 与 R 冲突；故引入构念 C 作为调节/中介，并设计测量 M 检验。”

**人工必做**：每条“矛盾”至少锚定 2 篇对立或缺口文献。

## Key Takeaways
1. 四法分别提升抽象力、组织力、解释力、应用力。
2. 创新句必须指向可检验关系，而非态度。
3. AI 可按四步提示找矛盾草稿，作者负责命题签字。
