# 提示词模板：论文不是写出来的

原书正文约有 86 段提示词示例，本文件按方法归并成 22 个模板。占位符用【】表示。
模板保留原书的结构和要求，例子换成通用写法。

**agent 使用规则**（详见 `../_integration/agent-gates.md`）：
- 原书多处写“请推荐 N 篇文献，要求真实可靠”。agent 执行时**一律改为检索工具或用户文献库**（G2），不得凭记忆列条目。
- 原书在每个提示词后都安排了人的验收。agent 执行时把验收写成可检查的输出格式（表格列、字数、锚点），并把不能自验的部分列入“待作者确认”。
- 输出要求以表格为主，方便逐行核对和下一步引用。

## 一、四法提示词（ch02）

**T1 要素组合五件套**（选题、大纲、方案草稿）
```
【角色扮演】假设你是【学科】的论文指导老师。
【基础指令】我是【身份】，需要【任务，如：推荐 3 个选题】。
【问题描述】研究方向是【方向】；选题必须包含研究对象、研究方向和研究主题。
【细化要求】满足价值性、聚焦性、创新性、完整性、清晰性、简洁性；以表格呈现，列为：题目｜研究对象｜研究问题｜创新点｜可行性。
【相关资料】【热点清单/政策文件/已读文献摘要】
```
agent 门禁：【相关资料】为空时先索取或检索资料，不用常识补齐。

**T2 资料投喂对照**（综述段落）
```
仅依据下列【N】篇文献撰写【小节名】，每个观点后用［作者, 年份］标注出处；文献未涉及的内容写“现有材料未覆盖”，不要补充。
文献：【粘贴摘要或全文片段】
```
原书对照实验：同一提示词，无投喂时引文空泛，投喂 6 篇文献后观点和引文都能落地。

**T3 分步指令**（复杂设计）
```
我们分步完成【任务】。本轮只做第【k】步：【步骤名】。输出【格式】后停下，等我确认再进入下一步。
上一步已确认的结论：【粘贴】
```

**T4 多轮优化反馈**（首稿空泛时）
```
上一版存在以下问题：1) 【概念混淆，如：把数据采集方法当成数据分析方法】；2) 【缺少某维度】。
请据此重新给出，并按【“是什么/为什么/将来怎样/怎么办”】归类，以表格输出，列为：角度｜方法｜适用问题｜示例文献。
```
禁止使用“写得更学术一点”这类无法执行的反馈。

## 二、三项标准（ch03）

**T5 题目规范性体检**
```
按以下标准检查题目《【题目】》：
1. 完整性：包含研究对象、研究方向、研究主题；
2. 清晰性：无歧义，关键词边界明确；
3. 简洁性：无冗余修饰。
逐项给出“是否满足—问题—改写建议”，再给出 3 个改写版本。
```

**T6 学科层次定位**
```
我是【专业】研究生。请从“一级学科—二级学科—研究方向—研究主题”四个层次，梳理可选的研究方向和主题，用 Markdown 层级列表输出（可直接转思维导图）。
```

**T7 评审专家视角审题**
```
【角色扮演】假设你是【博士论文/期刊】评审专家。
【问题描述】我的题目是《【题目】》，摘要如下：【摘要】。
请从规范性、学科性、学术性三项标准指出最可能被质疑的 3 处，并说明每处需要补什么证据。
```

## 三、知识储备与深入问题（ch04、ch06 STEP07–09）

**T8 综述框架三法**
```
请对选题《【题目】》构建文献综述框架，并说明采用哪种方法：
1. 概念拆离法：选题研究多个独立概念之间的关系，按概念分节；
2. 层次分解法：概念有上下位或层级结构，按层级分节；
3. 拆分组合法：先拆概念再按关系组合。
框架必须覆盖题目全部关键词，理清层级关系，并在最后一节落到研究空白和本文切入点。
```

**T9 综述表述方法匹配**
```
综述各小节可用的写法有：历史脉络法、观点比较法、主题归纳法、问题导向法。请为【章节目录】的每个小节选定主写法和辅写法，说明理由，并改写目录（最小改动）。
```

**T10 字数分配与分窗起草**（防黑箱）
```
第【2】章文献综述共【5000】字。请给出各小节字数分配和理由（表格）。
（确认后）请按分配撰写【2.1】节，约【1100】字，仅使用下列文献：【文献包】。小节内按“主张—证据—反证—小结”推进，结尾落到下一节的问题。
```
agent 门禁：每个窗口的术语写入跨窗术语表；合并后统一核对。

## 四、注入创新四法（ch05）

**T11 维度转换（概念重塑）**，三步：
```
1) 假设你是【领域】专家，请从【学科】角度界定【概念】，用最常见的 5 个维度列表。
2) 基于【已核实的文献清单】，判断每篇文献从哪个维度界定【概念】，统计各维度的文献数量和占比。
3) 如果改从【相对/少用维度】界定，可以研究哪些问题？列表并指出最优问题及理由；说明测量和设计要怎么跟着改。
```

**T12 负面启发（命题突破）**，四步：
```
1) 现实中出现了哪些新现象、新环境，可能冲击【传统理论】对【问题】的解释？表格列：新现象｜冲击点｜证据来源。
2) 以拉卡托斯负面启发法回答：传统情境下最常用的理论及其基本思想；新情境提出了哪些新需求；现有理论在概念、命题、逻辑、边界条件四方面的研究缝隙（表格）。
3) 为弥补缝隙需要引入哪些理论？列：理论｜提出者｜引入目的｜修正方法｜预期效果。
4) 结合引入的理论修正原理论，重新生成命题和概念。表格第 1 行为原理论，其后每行为一个引入理论带来的新命题。
```

**T13 流派冲突**
```
1) 【学科】领域的主要对立流派有哪些？列：流派 A｜流派 B｜代表人物｜核心分歧。
2) 哪组分歧对【现实问题】最有理论和现实价值？为什么？
3) 两派各自的实证模型是什么（变量与函数形式）？
4) 若统一核心变量，能否用非线性项、交互项或中介变量构建一个同时容纳两派观点的模型？写出模型和可检验的预测。
```
agent 门禁：第 3 步的模型设定需要锚定原文献，否则标【待补】。

**T14 应用拓展（边界重构）**
```
1) 【理论】在研究条件和应用场景上有哪些边界？每条用一句话概括。（附理论简介作为资料）
2) 这些边界中，哪一个对拓展应用影响最大？为什么？
3) 若把【理论】从【情境 A】拓展到【情境 B】，框架应如何调整？如何保证调整后的普适性和科学性？
```

**T15 逻辑调优：学—比—挑—改—重建**
```
1) 学习：给出【研究主题】的 3 篇高被引文献（来自检索结果），重点展示其【样本设计与实施】做法。
2) 分析：比较这些文献在【该方面】的差异和优缺点（表格）。
3) 聚焦：哪篇最优？详细描述过程并指出优缺点。
4) 批判：对照标杆，分析【我的方案】的问题，用“问题—分析—建议”三列表格。
5) 重构：按建议重新设计，分为【设计】和【实施】两个环节。
```

**T16 推理逻辑体检**
```
下面是【数据表】和对应的分析结论。请指出结论中逻辑不清的地方（如口径不一、以偏概全、因果倒置），并列出判断“推理顺畅”的具体指标。
```

## 五、价值与选题收敛（ch06）

**T17 选题九步收敛（STEP01–09）**
```
STEP01 概念同频：从学术视角界定【核心概念】。
STEP02 批判创新：【领域】中还有哪些尚未解决的问题？
STEP03 学科聚焦：我是【学科】方向，上述哪个问题适合我？
STEP04 确定题目：给出 3 个题目并按 T5 体检。
STEP05 研究设计：为《【题目】》生成研究设计，包括研究目的、内容、方法。
STEP06 生成目录：给出对应的论文目录。
STEP07 框架优化：按 T8 检查综述框架是否覆盖关键词并落到研究缝隙。
STEP08 表述逻辑：按 T9 为各节匹配写法。
STEP09 字数分配：按 T10 分配并分窗起草。
```
每一步都等确认后再进入下一步。

**T18 价值论证四视角**
```
【角色扮演】假设你是【学科】研究生。
【基础指令】请从【分层级/讲历程/谈作用/找问题】视角，论证《【题目】》的【理论贡献/实践价值】。
【问题描述】结合【背景事实，需附来源】。
【细化要求】理论贡献写清“推进了哪个理论的哪条命题”；实践价值写清“谁、在什么场景、改变了什么”。
```

## 六、倒金字塔工作流（ch08）

**T19 三类研究缝隙**
```
基于前面讨论，对研究问题“【问题】”回答：
1. 主流流派、代表人物、基本思想；
2. 流派之间的分歧点；
3. 研究缝隙，分三类：混淆类（文献互相矛盾，或现象与文献不一致）、忽略类（研究不足或缺乏实证）、应用类（在特定领域适用性不足）。
三问均用表格输出，每条缝隙附 ≥2 篇文献锚点。
```

**T20 假设生成**
```
基于【理论】设计研究假设，探究【变量 X】在【Y】与【Z】关系中的【中介/调节】作用。要求：基于该理论、可操作、可验证；每条假设一句话；附预期方向和所需数据。
```

**T21 数据收集方案与量表**
```
针对以上【N】个假设列出数据收集方案，表格列：假设｜数据内容｜来源｜收集方法｜样本量｜时间。
（如需量表）基于【成熟量表名】设计题目，保留原维度，注明改编之处。
```
agent 门禁：成熟量表的题项与授权以原量表文献为准，不得自行编造“标准题项”。

**T22 研究路线图与智能体五要素（ch08、ch09）**
```
角色：你是【领域】资深研究者，擅长【方法】。
目标：把【研究兴趣】转化为可执行的研究方案，完成标准是【交付物清单】。
技能：热点凝练、问题聚焦、创新挖掘、可行性评估。
工作流：①热点挖掘 → ②题目生成 → ③问题聚焦 → ④创新设计 → ⑤评估优化 → ⑥研究路线（表格 + Mermaid 路线图）。
限定：每阶段只给 3–5 个选项；进入下一阶段前必须等待确认；文献只用检索或用户提供的条目。
```
原书判断标准：步骤少于 10 个、无外部工具、路径线性的任务，用一个结构化提示词即可；复杂任务再拆成工作流或多智能体。
