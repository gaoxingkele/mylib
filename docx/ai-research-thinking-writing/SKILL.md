# AI 科研思维与协同写作

## 主线
科研能力 → 学术目标 → 写作工作流；AI 是放大器不是代笔者。

## 核心框架
1. 倒金字塔：兴趣 → 领域 → 问题 → 可验证选题
2. 三项标准：规范性、适切学科性、符合学术性
3. 四大目标：知识与问题；创新；理论与现实贡献；可校验产出
4. 提示词四法：资料投喂；要素组合；分步指令；多轮优化
5. 幻觉治理：预测下一词；无投喂=高风险编造
6. 工作流分拆：事前引导 + 事后校验

## 强制工作流
倒金字塔 → 三项标准门禁 → 投喂真实文献/数据 → 四法生成片段 → 人工校验 → humanizer。

## 边界
不替代期刊政策与 Paper_CCF；基金栏目转 nsfc-*。
