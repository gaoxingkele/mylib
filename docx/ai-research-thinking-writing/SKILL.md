# 论文不是写出来的：AI 科研思维训练与智能协同写作实战
**作者**：陈哲，李一方 | **ISBN**：978-7-121-52953-5 | **章数**：9 | **生成**：2026-11-02

## 如何使用

Information 论文修订可加读[十篇范文与两稿的项目复盘](../../Paper_CCF/journals/mdpi-information/references/evidence-led-story-revision.md)。这是2026-11-03的案例扩展，不是本书原文：用问题组织论证、用证据限制结论；审计记录不自动构成贡献，不强制跨数据层同向或恰好一个实验。

- 无参数：加载下方核心框架做科研—AI 协同判断
- 指定主题：如 `倒金字塔`、`资料投喂`、`负面启发` → 打开对应章节
- 指定章节：`ch05` → 读 `chapters/ch05-*.md`
- 句级写作/质检：同时打开 `cheatsheet.md` + `patterns.md`

## 核心框架与心智模型

### 1. 点—线—面—体（全书骨架）
- **点**：提示词系统——把科研判断写成 AI 可执行约束
- **线**：倒金字塔——兴趣→题目→问题→难题→数据
- **面**：论文设计流程——选题 / 文献综述 / 研究设计
- **体**：能力演进——大模型 → 工作流 → 智能体

**决策规则**：先有标准与目标，再谈生成；禁止“先一键成文再补问题”。

### 2. 放大器原则
AI 放大你已有的问题意识、学术素养与逻辑；标准不清时放大“快而空/顺而假”。  
**人机分工**：AI 提供广度；人类决定深度与签字责任。

### 3. 三项标准（质量底线）
1. **规范性**：形·意·引·格；题目须完整性（对象+方向+主题）+清晰性+简洁性
2. **学科性**：题目适切 + 研究过程适切（理论/方法与领域惯例匹配）
3. **学术性**：学术思维（解释“为什么”而非价值口号）+ 批判思维（指出缝隙并推进）

### 4. 四大目标（纵深）
知识储备 → 深入问题 → 注入创新 → 提升价值（理论“综评”+现实贡献）

### 5. 三能力 → 三原则 → 四法提示词
| 科研能力 | AI 写作原则 | 提示词方法 |
|---|---|---|
| 学习知识 | 输入文本精准化 | **资料投喂法** |
| 问题导向 | 输入需求清晰化 | **要素组合法** / **分步指令法** |
| 批判创新 | 输出结果迭代化 | **多轮优化法** |

**要素组合五件套**：角色扮演 → 基础指令 → 问题描述 → 细化要求 → 相关资料  
（对应：身份背景→任务→问题→标准→证据）

### 6. 创新四法（理论四要素）
| 理论要素 | 方法 | 批判动力 |
|---|---|---|
| 概念 | 维度转换法 | 换维度 |
| 命题 | 负面启发法（三类矛盾） | 找矛盾 |
| 逻辑 | 逻辑调优法 | 纠方法 |
| 边界 | 应用拓展法 | 破边界 |

### 7. 防黑箱工作流
拆分任务；每步 **事前引导（提示词约束）+ 事后校验（人工验收）**；AI=实习生，作者=课题负责人（回源核对、能证即留）。

### 8. 句级硬约束（本包通用）
成品句必须可答：
1. 研究对象/变量是什么？
2. 主张与证据是否同句或邻句绑定？
3. 引用是否回源可核？
4. 是否学科主语（非“优化/完善/意义重大”空转）？
5. AI 产出是否已经过人工必做步骤？

禁止默认：无投喂综述、不可追溯“研究表明”、把 AI 列为作者、承诺过 AIGC 检测。
