# Cheatsheet · 决策表

## STE 快速判别

| 文本信号 | 更可能是 | 基金写法 |
|---|---|---|
| 制备、工艺窗口、收率优化、装置开发 | 技术/工程 | 降为载体；上提机制/结构句 |
| 机理、构效、传递、演化、模型、可证伪预测 | 科学 | 保留为主语 |
| 完善/优化/研制高频 | 技术活（书称“59–60 分象限”） | 替换为揭示/阐明/建立关系 |

## 选题收窄

| 层次 | 问题 | 通过条件 |
|---|---|---|
| 国家/行业 | 是否四个面向之一的真痛点 | 有可指认瓶颈，非口号 |
| 单位 | 平台能否支撑 | 与单位特色同向 |
| 个人 | 是否长期积累 | 有预研/代表作锚点 |
| 科学 | 能否落到主导尺度结构或传递瓶颈 | 一句可写清 |
| 范围 | 是否小而深 | 3 年可做完，不做“全家桶” |

## 能量类 vs 物质类

| | 能量类 | 物质类 |
|---|---|---|
| 核心 | 传递/转化/强化 | 结构演化/调控 + 构效 |
| 典型词 | 传热传质、通量、驱动力 | 多尺度结构、界面、缺陷、织构 |
| 假说落点 | 改变哪一传递步骤 | 调到何种目标结构 |

## 栏目互锁

| 栏目 | 必须能指回 |
|---|---|
| 关键科学问题 | 五问第 1–2 层结论 |
| 研究目标 | 假说被证实/证伪后的可陈述状态 |
| 研究内容 | 逐条对应子问题，非任务清单 |
| 技术路线 | 五问 1/2/3/5；显示一招鲜 |
| 创新点 | = 一招鲜 × 机制缺口，可检验 |

## 摘要（约 400 字）扫描顺序

拟解决问题 → 本质分析 → 总体思路 → 具体方法 → 预期结构/结果 → 对学科的赋能（非抢经费姿态）
