# Cheatsheet — 决策表

## 1. 技术问题 vs 科学问题（快判）

| 信号 | 偏技术/工程 | 偏科学（基金要） |
|---|---|---|
| 主语 | 效率/转化率/脱硫率/强度 | 界面结构/电子结构/传质/构效 |
| 动词 | 优化、开发、研制、完善 | 揭示、阐明、解析、建立关联 |
| 成功标准 | 指标达标 | 机制可陈述、可检验 |
| 方法角色 | 配方试错 | 干预科学本质的一招鲜 |
| 输出 | 工艺/产品 | 理论基础、科学依据、可迁移认识 |
| 59→60 vs 0→1 | 完善型词汇密集 | 机理/机制/关联/协调规律 |

**决策**: 若一段删光数字指标后无余义 → 技术句，须升维。

## 2. 能量类 vs 物质类选型

| 若痛点主要是… | 选 | 双问题模板 |
|---|---|---|
| 传不过去/不均匀/接触差 | 能量类 | 传递强化机制 + 与反应/分离耦合 |
| 不知道做成啥结构/结构—性能乱 | 物质类 | 结构调控机制 + 构效关系 |
| 存储像物质、传输像能量（信息等） | 分阶段写 | 存储→结构；传输→传递 |
| 界面「性质」字样很多 | 校正 | 改写为界面**结构**及构效 |

## 3. 选题决策

| 条件 | 行动 |
|---|---|
| 单位平台撑不住博题对象 | 换对象，保留方法思维（三位一体） |
| 想做领域总瓶颈 | 切到主导环节「小而深」 |
| 太难/形象工程 | 降到「推进一点可见」 |
| 太易重复 | 换一招鲜或换主导尺度 |
| 选口 | 问：是赋能还是抢经费？摘要是否大同行可读？ |

## 4. 创新点判据

| 类型 | 何时用 | 及格线 |
|---|---|---|
| 新理论 | 多年积累 | 可定义+可检验+有适用范围 |
| 新结构 | 材料/界面题 | 新热力学环境可辩护，且接构效 |
| 新方法（一招鲜） | 最常用 | 四判据全过：干预/可操作/新颖/(0→1) |
| 新应用 | 交叉迁移 | 有契合点，非硬贴 |

**一招鲜一票否决**: 不能改写科学问题走向 → 只是换料。

## 5. 研究内容 / 目标 / 方案

| 栏 | 一句话职责 | 合格动词 | 不合格 |
|---|---|---|---|
| 内容 | 做什么才够回答问题 | 阐明/揭示/解析 | 正交优化清单 |
| 目标 | 做完怎样（升华） | 建立/形成/提供科学依据 | 指标手册 |
| 方案 | 怎么做并推论 | 调控/表征/计算/对比 | 与内容逐字同 |

**条数**: 青基~3，面上~4；关键科学问题=2。

## 6. 立项依据灵魂五问速查

| 问 | 评审疑虑 | 篇幅感 | 必须出现 |
|---|---|---|---|
| 1 为何做 | 不重要 | 短 | 科学本质瓶颈 |
| 2 脉络缺口 | 不专业 | 最长 | 科学词汇主语+归纳 |
| 3 思路假说 | 没想法 | 中 | 干预后预判 |
| 4 难点 | 太天真 | 中短 | 科学层挑战 |
| 5 对策 | 不可行 | 中短+图 | 一招鲜 |

## 7. 题目 / 摘要闸门

| 检查项 | 过 | 不过 |
|---|---|---|
| 题目三要素 | 方法+问题+机制目标 | 只有对象或只有「研究」 |
| 摘要第1句 | 本质问题 | 宏观政策/行业赞美 |
| 摘要内容句 | 落机制/构效 | 落研制/优化 |
| 摘要收束 | 科学依据 | 产品交付 |
| 关键词序 | 问题→内容→方法→意义 | 乱炖 |

## 8. 可行性 / 基础

| 写 | 不写 |
|---|---|
| 理论/热力学允许边界 | 杰青长江院士作可行性 |
| 材料结构为何匹配 | 无关论文清单 |
| 一招鲜跨域依据 | 「知名教授学生」 |
| 未发表预实验 | 空头「条件完备」 |

## 9. 函评症状 → 动作

| 症状 | 先改 |
|---|---|
| 太技术 | 升维+禁词 |
| 不凝练 | 拆解+定语+主导尺度 |
| 无假说 | 假说公式 |
| 创新不足 | 一招鲜四判据 |
| 逻辑乱 | 五问+编号呼应 |
| AI味 | 机制·边界·证据三绑定 |
| 区别不明 | 增加「显差」密度不换题 |

## 10. 底层构效是否够深？

```
操作 ↔ 性能                    → 太浅
操作 ↔ 热点物理量 ↔ 性能       → 不够
底层结构 ↔ 热点量/本质过程     → 达标（基金/高分文）
```

## 11. 提交前 60 秒

1. 假说句能否证伪？  
2. 一招鲜是否在题/摘/依据/路线/创新五处同构？  
3. 关键科学问题是否两条且非工艺？  
4. 内容与方案是否可区分？  
5. 删掉所有「重要/深入/系统」后是否仍有信息？
