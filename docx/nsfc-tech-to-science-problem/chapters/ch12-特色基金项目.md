# Chapter 12: 特色基金项目

## Core Idea
重点/人才类仍服从「科学问题主线」，但叙事升级为**体系化贡献**与**可延续的突破口**；形式完整不能淹没硬通货亮点。

## Frameworks Introduced
- **一树三果（个人贡献凝练）**：围绕一个中心问题 → ①构建基础新体系/新理论；②形成技术共性方法；③建立关键技术/装备应用（注意：基金仍要科学表述，应用是延伸）。
- **人才材料三段（学术成绩）**：症结与突破口 → 突破了什么/提出什么新原理方法/意义 → 验证与评价（实验/引用/评价）。
- **工作方向聚焦**：多年如一日针对核心科学问题；避免做散。
- **未来工作**：代表性工作的延续中发现的新问题；让人留下「专注」印象；与成绩呼应又有跨越，非简单重复。
- **名称策略**：人才项目名称概括研究方向领域，而非过窄课题名。

## Key Concepts
- **评价维度**：第三方使用、引用、评论、获奖；学科引领贡献；共性特征凝练。
- **差异化**：摘要字数内输出关键创新点与特色，避免同质化「三条成绩模板」淹没亮点。

## Anti-patterns
- 为凑数塞低层次成果。
- 成绩三条完全平行无故事。
- 拟开展工作另起炉灶无继承。
- 形式烦琐削弱「硬通货」。

## Sentence Skeletons
- `围绕 [中心科学问题]，构建了 [理论要点]，形成了 [共性方法]，并在 [边界] 验证了 [可迁移性]。`
- `拟开展工作针对研究中新显现的 [科学缺口]，以 [新一招鲜/新概念] 推进，形成对 [原理论] 的边界拓展。`

## Key Takeaways
1. 体系化、可验证、可延续。
2. 科学问题中心不变，果实分理论/方法/应用层。
3. 亮点优先于形式堆叠。
