# Chapter 11: 插图与代表作

## Core Idea
图把晦涩科学逻辑视觉化；代表作要织成故事链。基金与 SCI 共用科学问题内核，但基金图服务**假说路径**，SCI 图服务**已证结论**。

## Frameworks Introduced
- **插图原则**：突出科学本质与问题主线、科学逻辑；不强求表征手段写全。
- **立项依据≥5图**：前期实验/文献关键图/自绘逻辑流；突出一招鲜与跨尺度；图最好承载观点结论。
- **方案图**：实验逻辑、流程、科学问题；结构—性能关联；一招鲜关键步骤。
- **终图（依据末图）**：常答第5问；箭头=宏观创新方法；块=操作后结构/结果；画主导尺度关键结构演化路径（功能材料可从分子；结构材料从纳微）。
- **画图四围绕**：逻辑、结构、科学、方法。
- **五篇代表作**：第一作者与通讯兼顾；重期刊水平；形成完整逻辑链条（不是五篇散点）。
- **基金↔SCI**：高水平 SCI 是本子「撒手锏」——用数据说话证假说可信与延续性；不夸张炫耀；SCI 弘扬思想与底层构效，非纯技术说明书。

## Key Concepts
- **图注即论点**：避免「示意图」无信息。
- **视觉强调**：路线中新颖方法用色/形突出；创新一般则弱化。

## Anti-patterns
- 图堆满所有仪器缩写。
- 代表作五篇互不相关「凑数」。
- 老专家拒图导致纯文字墙（作者主张与时俱进）。
- 基金图抄 SCI 结果展览，无假说路径。

## Sentence Skeletons
- 图题：`[一招鲜] 干预下 [主导结构] 演化与 [科学问题] 对应关系`
- 图说：`箭头表示 [方法]；节点表示 [结构状态]；右侧汇总 [待检验构效命题]`
- 代表作串词：`代表作1奠定 [方法]；2解析 [机制片段]；3建立 [构效雏形]；本项目延伸至 [新干预边界]`

## Key Takeaways
1. 图是科学美学与逻辑的证明，不是美化。
2. 末图尽量让人看出「你要调控哪条结构路径」。
3. 代表作讲「专注一件事」的证据链。
4. 用 SCI 服务基金假说，而非用基金重写 SCI。
