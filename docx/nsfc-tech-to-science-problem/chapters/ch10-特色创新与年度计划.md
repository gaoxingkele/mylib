# Chapter 10: 特色创新与年度计划

## Core Idea
特色比「自称重大创新」好写：从一招鲜、结构新颖、科学问题的共性拓展凝练 **2–3 条**；年度计划按内容推进科学认知，预期结果先科学后论文人头。

## Frameworks Introduced
- **特色三入口**：方法特色（一招鲜）| 材料/结构新颖 | 科学问题共性拓展（可迁移认识）。
- **年度计划=内容时间化**：每年对准一条内容或一个重点对象+对应科学问题；会议/论文为辅证而非主目标。
- **预期结果层级**：先「获得可控制备方法/揭示科学联系/建立构效」；再 SCI/专利/人才培养的数量（书中给经费粗算经验：论文与研究生成本量级，作规划感而非承诺术）。

## Key Concepts
- **创新难、特色可找**：不会写成长创新论文；短而硬。
- **原位+计算句式**可作为特色表达习惯：`通过原位手段研究动态结构，结合理论计算揭示原理`。

## Anti-patterns
- 特色创新写五六条空对空「国内领先」。
- 年度计划按月份排仪器测试，无科学问题节点。
- 预期只写论文篇数，不写将澄清什么科学认知。
- **AI 败笔**：`在理论、方法、应用方面均有创新` 无指称对象。

## Sentence Skeletons

### 特色条目
- `特色1：以 [一招鲜] 实现 [主导结构] 定向干预，区别于 [常规路径]。`
- `特色2：面向 [构效命题]，打通 [表征/原位/计算] 证据链。`
- `特色3：形成的 [机制认识] 可迁移至 [同类过程]，具共性方法意义。`

### 年度节点
- `第N年：完成内容(n)，阐明 [机制节点]；参加学术交流；形成阶段论文草稿。`

### 预期科学结果
- `获得 [调控方法]；揭示 [结构—性能科学联系]；为 [应用场景] 提供可检验的设计原则。`

## Key Takeaways
1. 2–3 条特色，每条能指回正文证据。
2. 计划服务科学问题里程碑。
3. 预期先科学认知，后计数字。
