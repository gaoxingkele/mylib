# Chapter 6: 研究内容、研究目标、关键科学问题

## Core Idea
三者是「科学探案」的动机—线索—谜面：内容是科学问题的**代言人/备胎细化**；目标是做完后的升华效果；关键科学问题是可检验的谜面（宜两条）。

## Frameworks Introduced
- **探案三分**：目标=为何查；内容=查哪些线索；方案=怎么查（方案见 ch07）。
- **内容条数经验**：青基约3条，面上约4条；先总述必要性≤200字，每条约200字，最后写条目间逻辑。
- **内容典型类型（生/化/环/材）**：结构调控机制、构效关系、科学规律；亦可热力学/动力学角度——须从科学角度设条。
- **构效 ⊃ 机制**：构效需先结构、后性能、再关联；机制需解析而非直接宣称。
- **关键科学问题四段式**：①必要性与总括；②③两条如何实现/获得；④观点与自信收束（「只有解决以上…才能…奠定理论基础」）。
- **目标句式簇**：通过…研究，建立…规律，解析…机理，形成…方法 → 落到为某技术提供理论基础/科学依据。

## Key Concepts
- **研究内容不是怎么做**：思想内容=干什么才能认识科学问题。
- **建议约25%模拟计算**：嵌入各条，不单独臃肿成条。
- **分子机制用语边界**：医学生物可加「分子机制」显精准；化工本就分子过程，勿空贴。

## Mental Models
- Align **每条内容 ↔ 某半个关键科学问题**。
- Prefer **逻辑链**：构筑/调控（基础）→ 深入机制 → 协同/耦合 → 整合构效。
- Think of 目标 as **浓缩内容+意义**，一段≤500字，不堆观察指标手册。

## Anti-patterns
- 内容=制备条件正交试验清单。
- 关键科学问题写成3条工艺影响因素。
- 目标/内容/方案三者文字几乎相同。
- 理论问题偷换成「关键技术问题」后只写工程解决方案（作者提醒：关键科学问题栏应围绕假说）。
- **AI 败笔**：`系统开展…深入研究…揭示相关机制` 无结构实体、无边界。

## Sentence Skeletons

### 研究内容单条（何时用：2.x 条目）
- 骨架：`（n）[科学短标题]。[必要性一句]。通过 [调控因子集合]，实现 [主导结构S] 的定向演化；结合 [表征/计算]，阐明 [S] 对 [本质过程R] 的作用规律，揭示 [调控机制]。`
- 正例关键词：揭示…机制 / 阐明…构效 / 解析…耦合  
- 反例关键词：优化温度时间配比以提高转化率

### 内容逻辑收束
- 骨架：`内容(1)是基础，解决 [准入结构]；内容(2)从理论上揭示 [构效]；内容(3)是(2)的深入；内容(4)整合(1)–(3)形成 [协同机制]。`

### 研究目标段
- 骨架：`围绕 [假说]，通过 [内容压缩表述]，建立 [规律/方法]，解析 [机制]，阐明 [关联]；预期为 [技术名] 提供 [可迁移的科学依据]，而非完成指标达标。`

### 关键科学问题两条
- 骨架：  
  `（1）[定语+]结构/传递调控机制。…`  
  `（2）[结构]与[行为]构效关系。…`  
  `只有解决以上两个关键科学问题，才能 [宏观效果]，为 [技术] 奠定理论基础。`
- 自检：每条能否用一句话说明「可被哪类证据支持/反驳」？

## Worked Example（模式，非抄袭对象）
电石渣—兰炭共成型：关键问题①颗粒界面及表面结构调控机制；②活性与热强度、电阻率协同调控规律——先承认矛盾对，再写协同结构变量。

## Key Takeaways
1. 内容条目标题尽量已是科学问题短语。
2. 关键科学问题具体化到选题干预，忌学科口号。
3. 目标禁「观察指标展览」，要意义升华。
4. 与立项依据、方案编号呼应。
