# 灵魂五问 / 灵魂八问（立项依据句级）

## 五问原式（保留）

1. 为什么做这个事？问题是什么（**科学问题**）？
2. 前人如何解决？未解决的本质是什么（**机理/机制**）？
3. 你的创新解决思路比前人好在哪？**假说**是什么？
4. 新方法难点在哪？创新方法的挑战是什么？
5. 如何应对难点？（落到**宏观一招鲜**/可执行对策）

灵魂八问：后三问循环嵌套追问，直到干预手段与机制闭合。

## 篇幅与图（默认）

| 层次 | 字数量级 | 图 | 功能 |
|---|---|---|---|
| 1 | ~500 | 1 | 意义 + **本质问题**开门见山 |
| 2 | 1200–1500 | 1–2 | 科学问题发展脉络（灵魂层） |
| 3 | ~600–800 | 1 | 提出假说/创新思路（“知”） |
| 4 | ~500–600 | 可选 | 新思路科学难点 |
| 5 | ~500–600 | 1 逻辑图 | 对策与宏观一招鲜（“行”） |

合计立项依据（不含文献）约 3500 字量级；可合并段落，但五问必须答完。文献宜精（常控 ~30 篇内、近 3 年、权威刊优先——以当年指南为准核对）。

## 句级铁律

- 每层**最后一句 = 本层结论 = 下层第一句**；结论句是评委扫读锚点。
- 第 2 层主语必须是**科学词汇**（结构、界面、传递、构效…），禁止人名单位流水账。
- 破题用“未解本质”，禁用“研究较少/罕见报道/尚未见报道”式无病呻吟。
- 第 3 层假说 = 用新方法**干预底层过程**后的可检验预期，不是口号。
- 技术路线图应能标出第 1/2/3/5 问；第 4 问可主要在文字。

## 标题骨架（槽位）

```
1.1  {应用/行业痛点}的必要性及{科学本质瓶颈}
1.2  {科学主线：如多尺度结构调控/界面传质…}方向与难点
1.3  {干预手段}调控{对象结构/过程}思路的提出
1.4  {协同/耦合机制}的难点与挑战
1.5  {宏观一招鲜关键词}强化{目标过程}的策略
```

可合并为 1.1–1.4，但评委仍应扫出五问闭环。

## 正例逻辑（压缩）

- 先写清“需要什么目标结构/目标过程”，再亮方法 → 方法才不突兀。
- 第 2 层末句必须把“缺什么机制认识”说死，第 3 层才有资格提出假说。

## 反模式

| 败笔 | 改写动作 |
|---|---|
| 第 1 层只写双碳/效率/性能 | 追问：效率背后的控制步骤/结构是什么 |
| 第 2 层文献综述体 | 按科学问题脉络重排；每段给可加粗结论句 |
| 第 3 层突然甩出新方法 | 回补第 2 层：目标结构/缺失机制未论证 |
| 五问写成五个独立故事 | 强制末句→首句衔接；统一一条科学主线 |
| AI 套话：具有重要意义/亟待解决 | 换成可核对事实 + 本质矛盾句 |
