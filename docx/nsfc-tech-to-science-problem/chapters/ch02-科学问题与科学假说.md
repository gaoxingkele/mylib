# Chapter 2: 科学问题与科学假说

## Core Idea
基金写的是技术/工程**背后**的基础、关键、共性逻辑；科学假说是「新干预作用在科学本质上之后」的可检验预判。

## Frameworks Introduced
- **STE 三分法**：科学=发现；技术=发明（科学集合）；工程=组织化技术集成；工程科学问题含「技术—技术底层逻辑」。
- **载体论**：效率、选择性、转化率、节能、性能、制备条件等是**载体**，不是主语。
- **能量类 vs 物质类**：
  - 能量类：传递强化 → 「三传一反」+ 界面结构
  - 物质类：结构调控机制 + 构效关系
- **主导尺度关键结构**：对特征起决定作用的那一尺度上的关键结构；宏观一招鲜=调控它的核心方法。（「外形像老鼠不够，气味还得像」）
- **双本质目标**：以科学词汇为主语，以新方法为抓手，目标是「解决本质问题之方法的本质」。
- **纯科学—纯技术—纯工程向下兼容**：写本子时选侧重量化你的认知深度。
- **科学家机制 vs 律师机制**：先证据路径 vs 先结论找证据——假说要前者。

## Key Concepts
- **科学问题**：学科中关键、共性、基础的理论问题；技术与工艺背后的灵魂。
- **科学假说**：科学问题发展脉络上，干预后的假设结论/发展预判。
- **界面结构 vs 界面性质**：性质是功能表现；结构是本征问题。
- **介尺度/介科学**：极大与极小之间难认清却决定宏观成败的尺度。
- **格物**：分类—求共性规律（作者文化类比，用于强调「共性/基础」）。

## Mental Models
- Use **透过工程看技术、透过技术看科学** when 本子满篇工艺指标。
- Prefer **结构+定语** over 裸写「结构调控」：无定语=无专属、无深度。
- Think of 信息类：存储时偏物质/结构，传输时偏能量/传递。

## Anti-patterns
- 满篇完善/开发/优化/研制（「59到60分」语言）。
- 材料题只写性能，不写「何种结构→何种性能→如何调控结构」。
- 把界面「润湿性/活性」当科学问题终点。
- 关键科学问题写成领域总瓶颈（青年/面上不可承载）。
- **AI 败笔**：询问模型「本学科科学问题是什么」→ 得到无定语的「三传一反/构效关系」口号。

## Sentence Skeletons

### 技术→科学升维（何时用：立项依据破题、摘要问题句）
- 骨架：`[宏观/技术表述] 可归结为 [传递过程 / 主导尺度结构] 的失控；其本征问题是 [界面结构 / 电子结构 / 成核—生长…] 如何决定 [载体指标]，而非继续试错式优化 [工艺参数]。`
- 正例：电解氧化脱硫率低 → 氧化介质与底物接触/传质差（科学）+ 双向传质强化机制。
- 反例：`提高脱硫率并优化电流密度与电解液配方。`
- 自检：主语是否已换成科学词汇？

### 假说句（何时用：五问第3问、关键科学问题段）
- 骨架：`若以 [宏观一招鲜] 干预 [科学本质环节]，则预期 [主导结构/传递路径] 将沿 [可观测变化] 演化，从而使 [理化本质过程] 按 [可证伪命题] 发生；将通过 [原位/计算/探针] 检验。`
- 自检：能否指出「若假说错，哪类数据会打脸」？

### 物质类双问题模板
1. `[对象]在[尺度]的结构调控机制`
2. `[该结构]与[性能/行为]的构效关系`

### 能量类双问题模板
1. `[界面/场]强化[传质/传热/动量]机制`
2. `[传递强化]与[反应/分离目标]的耦合规律`

## Worked Example
**材料题停在性能** → 升到：筛选主导尺度（如电子结构）→ 宏观一招鲜如何得到该结构 → 结构如何改变氧吸附中间体（Sabatier 边界）→ 假说可被谱学+DFT 证伪。

## Key Takeaways
1. 基金探究模式：宏观方法揭示机理/机制/关联/协调规律。
2. 结构问题是多数学科公约数；个性靠定语与干预后走向。
3. 假说=创新的语言形态；无假说常被函评为「做做看」。
4. 1000万以下项目：关键科学问题宜两条、四段书写。
