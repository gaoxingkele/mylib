# Chapter 7: 研究方案与技术路线

## Core Idea
方案讲清「如何把混乱整理成可推论的科学故事」；技术路线同时是实验流程**与**科学问题获得路径，并与灵魂五问扣题。

## Frameworks Introduced
- **目标 / 内容 / 方案三分**：
  | | 回答 | 写什么 | 不写什么 |
  |---|---|---|---|
  | 目标 | 做完怎样 | 效果、意义、科学依据 | 技术细节堆砌 |
  | 内容 | 做什么 | 思想任务、科学对象 | 操作手册 |
  | 方案 | 怎么做 | 操作逻辑、手段、流程 | 与内容逐字重复 |
- **方案↔内容**：逐条展开；每条可附流程图；常规表征点到为止，重点是思路逻辑。
- **技术路线五问映射**：
  - 第1问必要性：可用背景箭头弱化表达
  - 第2问脉络/机制：路线中部科学问题层
  - 第3问假说：干预后走向
  - 第4问难点：路线上常不展开
  - 第5问对策：核心方法与流程=一招鲜
- **两类经典路线语法**：
  1. **能量/传递类**：技术痛点→科学（接触/传质差）→分端强化→耦合机制→回到宏观指标
  2. **物质/界面类**：方法行（新颖则视觉强调）→整体科学问题（如界面结构）→分解子界面→各自主导功能→协同调控

## Key Concepts
- **实验验证 + 计算验证 + 结构表征 + 原位/在线**：服务推论，非炫技清单。
- **成熟方法简写 + 新方法详写原理与适用依据**：禁止简单移植口吻。
- **多对一**：多条方案手段可支撑同一内容，但逻辑要声明。

## Mental Models
- Draw 路线 as **科学问题获得路径图**，不是仪器连接图。
- Prefer **双向传质**一类「思想可见」的结构，而非步骤瀑布。
- Weight 界面时只强调**权重最大**的功能耦合，次要干扰可省略描述。

## Anti-patterns
- 路线太简单/太技术/太复杂，看不到科学问题逻辑。
- 方案变成试剂浓度大全。
- 目标、内容、方案三栏复制粘贴。
- **AI 败笔**：`采用SEM、TEM、XPS、DFT相结合`——有用什么，无为何用、如何用、对应哪条假说。

## Sentence Skeletons

### 方案单条起笔
- 骨架：`针对研究内容(n)，通过 [核心操作序列]，获取 [结构/过程观测量]；经 [对比/原位/计算] 归纳，形成对 [机制命题] 的支持或修正。可能的关键风险是 [..]，预案为 [..]。`

### 新方法论证句
- 骨架：`[方法] 的原理是 [..]；其适用于本体系的依据是 [理论点+预实验点]；与简单移植不同之处在于 [边界条件重设]。`

### 路线图注文字
- 骨架：`[技术痛点] → 科学表述:[传递/结构问题] → [一招鲜分支] → [机制解析节点] → [构效/耦合] → 为[技术]提供科学依据`

## Worked Example（传递类思想）
电解氧化脱硫率低（技术）→ 氧化介质与被氧化物接触/传质差（科学）→ 转动电极强化介质端传质 + 电解液侧强化底物端 → 双向耦合机制 → 效率提升回指原痛点。

## Key Takeaways
1. 先分清三栏职责再动笔，重复即逻辑溃败信号。
2. 路线必须让大同行看出「问题如何被变成可研究的科学对象」。
3. 一招鲜在路线上要视觉/位置突出。
4. 每条方案服务一条内容的科学推论。
