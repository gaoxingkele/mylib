# Chapter 1: 选题

## Core Idea
选题占成败权重过半：在「国家—单位—自身」交汇处，选一块能严丝合缝补上的**科学拼图**，而非整盘技术。

## Frameworks Introduced
- **三位一体选题**：国家/行业需求 × 单位平台 × 个人积累同时满足。
  - When：换单位、海归延续博课题、跨平台就业时必检。
  - How：用博期间的**方法/思维**，改做单位优势方向上的**对象**。
- **选题三层次**：方向方法 → 科学问题角度 → 内容拼图（缺哪块补哪块）。
- **难易适中原则**：太难（形象工程）/太易（要经费）都否；「给经费就能看到前人看不到的一点」为佳。
- **四面向→四关键**：世界前沿/经济主战场/国家重大需求/人民生命健康 → 再找其中的原始创新、基础前沿、学科交叉、共性方法。
- **投口赋能**：给所选学科「注入新方法」，而非抢经费；摘要先服务大同行可读。

## Key Concepts
- **拼图模型**：只做咬合缺口的那一块；创新=移动/变换这块使严丝合缝。
- **问题导向降维**：宏观问题 → 科学问题 → 关键科学问题。
- **口子**：二级申请代码对应的大同行语境。
- **小而深**：忌求大求全；有限时间有限目标。

## Mental Models
- Use **破乳四视角** when 同一技术多学科竞争：化学=氢键反应；材料=新结构强化氢键；化工=反应+结构强化传质；催化=电子结构演变——基金写到本学科深度。
- Think of 选题 as **赋能单位标签**：特色高校服务双一流主航道。
- Prefer **国家选风口、行业选共性、单位选主流、自身选积累**。

## Anti-patterns
- **平台错位续博题**：航天阻燃博士去煤炭院校仍写航天——单位支撑与定位崩塌。
- **把行业痛点当科学问题**：停在脱硫率/破乳率>90%。
- **论文顶刊幻觉**：有高水平论文≠本子逻辑自动成立。
- **AI 选题口号**：「聚焦四个面向开展创新研究」无对象无机制。

## Sentence Skeletons（句子尺度）

### 选题必要性（何时用：立项依据第1层 / 摘要第1句）
- 骨架：`[行业宏观瓶颈] 的本质并非 [指标优化]，而在于 [底层过程/主导结构] 尚不清楚，限制了 [技术路径] 的可预测调控。`
- 正例：破乳率再高仍可能「不科学」——应写氢键/界面传质本质。
- 反例：`本项目优化破乳剂配方，使破乳率超过90%。`
- 自检：删掉所有%指标后，句子是否仍成立？

### 拼图定位（何时用：说明「为何是你做这一块」）
- 骨架：`既有工作已覆盖 [A/B块]，缺口在于 [C块：某主导尺度结构/传递环节]；本项目以 [宏观一招鲜] 专攻该缺口，并阐明其与 [相邻块] 的关联机制。`
- 自检：能否画出与前后拼图的接口？接口=科学问题边界。

## Worked Example
**场景**：985 阻燃博士 → 矿业特色高校。  
**错写**：继续航空级阻燃材料性能优化。  
**升维**：井下/矿山场景阻燃 → 多尺度结构与阻燃行为构效 → 单位矿业标签赋能。  
**自检**：评审是否觉得「这人给矿业注入方法」而非「人在矿业却写航空」？

## Key Takeaways
1. 先定平台与口子，再定科学问题角度。
2. 只写能做、想做、与科学问题相关的最小闭环。
3. 摘要400字是投口与科学定位的「头等大事」。
4. 基金写作本身是把书「读厚再读薄」——方向错则全过程空转。
