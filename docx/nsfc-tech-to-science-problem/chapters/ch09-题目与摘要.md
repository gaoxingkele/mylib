# Chapter 9: 题目与摘要

## Core Idea
题目是一行编码的「方法×科学问题×目标」；摘要是预告片——短、全、紧，用有限句完成问题→思路→内容→科学依据闭环。

## Frameworks Introduced
- **题目三要素**：核心方法（学术标签）+ 关键科学问题（深度）+ 科学目标（多为…机制/原理）。
- **命名三模式**：①直接抛科学问题；②强调发现/结论机制；③宏观一招鲜干预科学问题并指向机制目标（作者最推的基金味）。
- **项目类别粒度**：重大偏宽、重点加约束、面上再加分辨要素、青年更聚焦（书中环境毒理示例）。
- **摘要四部曲**：背景/问题 → 解决思路 → 研究内容 → 意义（科学依据）。
- **七个通过 / 多句分工**：背景1 + 现状1 + 科学问题1–2 + 内容方法2–3 + 结果意义1；每句有任务，勿抢戏。
- **字数节奏（经验）**：问题句50–80字写到本质；思路约100字；解释约150字；内容约180字；收束到科学依据。
- **关键词逻辑链**：约2个科学问题 +1内容 +1方法 +1结果意义；忌「东北乱炖」。

## Key Concepts
- **400字脸面**：宁满勿空到300；所有评审先看。
- **摘要禁词**：研制、工艺、技术开发、完善、优化等；可写「为××技术提供理论基础和科学依据」。
- **少连词、解释新词**：关系纽带词少用；新术语随文定义。
- **题目尽量不出现「研究」**；控制一行/约30字内；忌小题大做。

## Mental Models
- Write 摘要 as **预告片** not 说明书。
- Encode 题目 like：`[方法]调控/干预[结构或过程]及[性能协同]机制`
- Prefer 落点 **科学依据** over 产品交付。

## Anti-patterns
- 背景小说化；方法手册化；意义缺失。
- 题目刷模型物种/仪器存在感。
- 摘要口号：`理论与实验相结合，突破超高指标` 无路径。
- 关键词无序堆砌。
- **AI 败笔**：句句正确空洞；不写领域、不写新发现、不写关键实验设计。

## Sentence Skeletons

### 题目
- 骨架A：`[一招鲜]调控[对象][主导结构]及[行为]机制`
- 骨架B：`[一招鲜]强化[过程]的[传递/界面]机制`
- 自检：三要素是否各出现一次？删「研究」「浅析」「初探」了吗？

### 摘要问题句
- 骨架：`[技术/场景]受制于[本质瓶颈]；[结构/传递]是[载体性能]的关键，但[关联]不清，限制了[可预测调控]。`

### 摘要思路句
- 骨架：`本项目提出[一招鲜]，通过[协同调控要素]，改写[主导结构走向]，以解析[机制命题]。`

### 摘要内容「通过」簇
- 骨架：`通过[手段]，研究[对象行为]，揭示[机制]；通过[手段]，探究[结构演化]，解析[原理]；建立[构效/关联]，为[技术]提供科学依据。`
- 经典收束：`建立×构效关系或关联机制，为×技术提供理论基础和科学依据。`

### 关键词序
`科学问题词1, 科学问题词2, 研究内容词, 方法词, 意义/目标词`

## Worked Example（句功能，压缩示意）
问题：活性氧数量限制电催化脱硫脱硝；掺杂结构关键。  
思路：调质煤沥青实现自掺杂—几何—石墨化协同。  
内容：三位一体调控机制；低温石墨化耦合；探针解析活性氧；加压/离子液体+模拟解析脱硫脱硝机理。  
意义：为电催化烟气脱硫脱硝提供科学依据。

## Key Takeaways
1. 题目=标签；摘要=可独立判决的浓缩本子。
2. 每句话岗位清晰，背景只能一句量级。
3. 内容句落点必须是机制/原理/构效，不是指标。
4. 关键词是微型故事线。
