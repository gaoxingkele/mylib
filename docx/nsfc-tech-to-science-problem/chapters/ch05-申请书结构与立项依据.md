# Chapter 5: 申请书结构与立项依据

## Core Idea
本子不是八股重复，而是探究框架下「同一科学问题的多角度成像」；立项依据用**科学问题发展脉络**做主线，以**灵魂五问**自问自答打消评审疑虑。

## Frameworks Introduced
- **十部模板意识**：题目→摘要→立项依据→内容与目标→科学问题→方案→路线→创新→预期→队伍经费——层层换角度说清探究。
- **横看成岭侧成峰**：内容/方案/可行性/基础等同号呼应；翻到哪页都见科学问题。
- **移花接木式支撑**：用相近前期工作证明实力，按基础/方法/机理/模拟分条。
- **科学词汇主语 + 问题脉络主线**：打乱文献按故事重排；文献服务观点。
- **灵魂五问（立项依据五层次）**：
  1. 为何做？存在问题的科学本质？（约一标题层）
  2. 宏观问题底层科学脉络；前人缺口（约1200–1500字+图；段末灵魂句导出第3层）
  3. 自己的解决思路/假说（约600–800字+图；思想层「知」）
  4. 新思路难点（科学层面挑战）
  5. 对策=宏观一招鲜（约500字+逻辑图；知行合一）
- **灵魂五问→八问**：嵌套追问，模块可学可复用；约3500字量级答完五问（不含参考文献）。
- **技术问题科学化表述**：用基础/一级学科语言写交叉与工科问题；「讲故事」但火候自控。
- **大片隐喻**：立项依据=核心剧情；背景为主角（科学问题）服务，勿散。

## Key Concepts
- **立项依据最大的问题是没有问题**：无科学本质、政策堆砌、现象结果多、科学性不足。
- **强行凝练**：同实验数据，用更高科学语言读出文献未写出的问题（需真功底）。
- **小而深**：第二层只写你能解决的结构调控方向与难点。
- **图解灵魂五问**：把自己想法画成图，与文献对策对照。

## Mental Models
- Prefer **轮子演化史写法**：形状不重要，形状带来的问题走向与构效才重要——对人名单位同理。
- Use **侦探观众视角**：为何查案/查什么/怎么查在后文展开，依据先立「案情本质」。
- Writing order 建议：依据→内容→目标→特色创新→关键科学问题→方案→路线→摘要（可循环嵌套，见 ch13）。

## Anti-patterns
- 按单位/作者/工作罗列文献综述。
- 宏大叙事+政策文件代替底层过程。
- 五问缺第2层归纳或第3层假说「想当然」。
- 技术路线与立项依据故事脱节。
- **AI 败笔**：每段通顺但段末无观点句；「国内外学者开展了大量研究」空转。

## Sentence Skeletons

### 五问标题级（何时用：立项依据小标题，建议写成观点/结论）
1. `[对象]中[过程]的必要性及科学本质瓶颈`
2. `[科学词汇]调控方向及存在问题（发展脉络）`
3. `[一招鲜思想] 的提出与假说`
4. `[一招鲜] 的科学难点与挑战`
5. `[具体对策/限域/外场…] 策略与逻辑`

### 第2层收束句（何时用：导出假说前最后一句）
- 骨架：`综上，既有路径在 [主导结构/传递环节] 上仍缺少 [可检验认知]；若不阐明 [底层关联]，[宏观指标] 只能停留在经验优化。`
- 自检：下一自然段是否自然接出你的干预？

### 第3层假说段
- 骨架：`基于上述缺口，本项目提出 [干预]。预期其将使 [本质过程] 出现 [可观测转向]，从而形成 [假说命题]。该命题的科学性在于 [与学科基础知识的相容点]，必要性在于 [与缺口一一对应]。`

## Worked Example（书中立项小标题范式）
中低温煤焦油酚分离类：必要性及瓶颈 → 油酚界面调控方向及问题 → 官能团化双季铵盐思路提出 → 氢键萃取-酚醛缩合协同强化的难点与策略。  
**学的是出场顺序与五问齐全，不是复制化工对象。**

## Key Takeaways
1. 依据重点写科学问题被解决的演化，不写参数优化史。
2. 重要结论加粗下划线，但勿滥用。
3. 建议≥5图；最后一图常承担第5问+一招鲜+结构演化路径。
4. 五问可合并段落，不可合并到「缺答」。
