# Chapter 3: 科学问题凝练

## Core Idea
凝练=把二级学科「行话」拆到数理化天地生不可再分，锁定卡脖子环节；科学问题是**干预底层构效关系之后**的演化规律。

## Frameworks Introduced
- **底层构效关系三层塔**：表面（操作↔性能）→ 次深（热点物理量↔性能）→ 底层（分子/电子结构↔热点量/本质过程）。
- **二级术语拆解法**：基因表达→转录/剪接/翻译/修饰…；选你干预的那一环写假说。
- **结构终极论**：热力学/动力学分裂的鸿沟正是「瞬态结构难表征」；结构是动态的，故重原位。
- **结构工程视角**：催化=电子结构工程；生命=基因/蛋白结构工程；管理=组织意识形态结构——尺度不同，结构同构。
- **共性+定语个性化**：学科公约数前必须加体系/环境/干预限定。
- **科学问题漂移**：跨学科选题时，科学问题跟**目标对象**走，不跟学院牌子走。
- **文献灵魂五问精读**：①解决什么 ②不足 ③洞见 ④难点 ⑤对策；问题引导文献。
- **新概念四步**：列事实→推论联系→定义假设/概念→大样本/仪器检验；演绎与归纳并用。

## Key Concepts
- **表面构效关系**：宏观对宏观，空对空。
- **主导尺度关键结构**：主次矛盾的「主要矛盾」。
- **硬结构/软结构**：本征几何—化学结构 vs 机制性/组织性结构。
- **化学力—牛顿力关联**：用电磁/化学作用解决宏观力学问题是一类前沿破题角度。
- **亮剑精神**：敢用自己的语言给文献下科学结论（侧重结论深度，不批技术「不好」）。

## Mental Models
- Use **烙饼抹油** analogy when 工艺很好却发不出高分文：写气-油-饼界面三传，不写抹油量优化。
- Use **漂移检测** when 环境/矿业/能源题实际在做结晶/催化：按目标重定科学母语。
- Prefer **少样本俯视文献** finding 共性关键问题，而非堆文献。

## Anti-patterns
- 把领域总瓶颈当自己的关键科学问题。
- 停在内建电场/d带中心等「热点词」与性能连线，无底层结构独特性。
- 工科语言纯技术：不会「分解/集成」找科学单元。
- **轻易让 AI 凝练科学问题**（作者明确反对：提问者问题不准→输出更空）。
- 批判文献「方法过时」代替「科学认知不足」。

## Sentence Skeletons

### 拆解二级术语（何时用：从技术题找假说锚点）
- 骨架：`[二级术语] 可分解为 [步骤1|2|3]；本项目的宏观一招鲜作用于 [步骤k]，故科学问题收敛为 [步骤k 的结构/传递本质] 如何被调控，以及其如何改变 [宏观性能对应的理化过程]。`
- 自检：步骤k是否真是你能干预且能量化的一环？

### 三层构效自检句
- 骨架：`不仅建立 [操作] 与 [性能] 的相关，更阐明 [操作] 所塑造的 [底层结构S] 如何改变 [参数P/过程R]，从而解释性能；S 的独特性在于 [边界条件]。`
- 反例：`调控异质结提升催化性能。`（缺 S 与可证伪路径）

### 漂移改写
- 骨架：`虽依托 [原学院标签]，因目标转为 [产品纯度/晶型/粒度…]，科学问题漂移为 [成核—生长 / 电场诱导结晶…]；学院词汇让位于过程本质词汇。`

### 共性+定语
- 骨架：`在 [特定热力学环境/外场/限域] 下，[界面/电子/颗粒界面] 结构调控机制及其与 [行为] 的构效关系`

## Worked Example（学科共性示例，须加定语）
| 学科 | 共性科学问题（书中归纳） |
|---|---|
| 分析化学 | 检测原理 + 传感器多尺度结构 |
| 摩擦 | 界面**共有反应结构**（A-M-B），非 A 或 B 本身 |
| 食品 | 反应 + 传质（味道/营养分子形成与扩散） |
| 中药 | 悬浊液多尺度结构 ↔ 疗效构效 |
| 机械 | 机械结构↔力；结构件设计调控 |
| 微生物 | 基因表达分子机制；酶/蛋白种群结构与协同 |
| 免疫 | 刺激→抗体机制；免疫微环境结构↔治疗构效 |
| 精准医学 | 分子尺度给药/治病机制；病变结构↔疗效构效 |

## Key Takeaways
1. 科学问题=剔骨尖刀：骨肉分离靠拆解与主导尺度。
2. 工科申请者的出路是科学集成/关联，不是放弃「科学性」。
3. 预实验证明可操作性；大问题切成可检验的 1–2 个具体问题。
4. 新概念来自对基础概念的追问定义+限制词，而非贴标签。
