# Chapter 8: 可行性分析与研究基础

## Core Idea
可行性证明「思路与方案在客观世界上走得通」；研究基础证明「你对学科做过可迁移的科学贡献」——二者都按内容/方案条目重排，预实验是最高权重证据。

## Frameworks Introduced
- **可行性多角度分条**（约5–6条）：理论/热力学、材料、设备、方法、宏观一招鲜交叉借鉴、预实验验证等——与内容方案呼应。
- **禁头衔可行性**：不写杰青/长江/院士/「知名教授学生」作可行性（易反感）；人的资历可谨慎放基础，但基础也忌项目化头衔化。
- **研究基础重排法**：打乱论文列表，按「建立新理论 / 形成方法 / 解析机理 / 构筑计算或表征能力」等4–5条，对齐本子内容。
- **青基 vs 面上**：青基侧重具备基础科研能力与科学问题认知；面上更看领域积累厚度。
- **未发表预实验 > 已发表数据堆砌**（可行性栏）：用新鲜验证支持「正要做」的路径。

## Key Concepts
- **材料可行性**：特定结构材料为何满足方案边界。
- **一招鲜可行性**：邻域成功+理论迁移+本体系预实验。
- **贡献式基础**：推动学科的认识/方法，而非「承担过××项目」。

## Mental Models
- Map `可行性4.n ↔ 方案3.n ↔ 内容2.n ↔ 问题1.n`。
- Prefer **热力学—动力学—结构表征**三角证明「做得成且做得科学」。
- Use 已发表 SCI 时：抽其**创新点与关键数据**服务本假说可信度，忌炫耀清单。

## Anti-patterns
- 可行性=平台仪器名单 + 团队头衔。
- 基础=论文题目年份列表。
- 把与本子无关的精彩工作硬塞。
- 可行性写「人员可行」占主篇幅。
- **AI 败笔**：`申请人长期从事相关研究，具有良好基础`——无贡献实体。

## Sentence Skeletons

### 理论可行性
- 骨架：`由 [公式/共识机理]，在 [边界条件] 下 [目标过程] 热力学允许；关键不确定在 [动力学/结构瞬态]，将由 [表征] 约束。`

### 预实验可行性
- 骨架：`预实验已观察到 [与假说同方向的结构/信号变化]（未发表），表明 [一招鲜] 可操作；完整机制解析构成本项目主体。`

### 研究基础单条
- 骨架：`（n）在 [方向] 解析了 [结构调控机制/构效]，建立了 [方法]，相关认识可迁移至本项目的 [对应内容编号]，区别与延伸在于 [新干预/新对象]。`

## Worked Example
基础条目对准「梯度电解质」本子：不写「发了N篇电池论文」，而写「已建立组分—结构—电导关联，能为梯度演变与电导调控提供方法与依据」+图示关键关联。

## Key Takeaways
1. 可行性是客观世界约束，不是身份证明。
2. 基础是科学贡献叙事，服务「为何你能做这个假说」。
3. 预实验连接「假说可信」与「方案可启动」。
4. 条目化呼应制造系统感，降低函评「脱节」风险。
