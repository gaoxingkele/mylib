# Patterns — 可执行方法 / 句式 / 审查清单

## Pattern: 技术问题升维术
**When to use**: 本子被批太技术、摘要/依据主语是指标。  
**How**:
1. 写出技术句（含指标）。
2. 问：该指标由哪一**传递过程**或**主导结构**决定？
3. 改主语为科学词汇；指标降为载体与验证终点。
4. 补：干预点、可观测、可证伪。  
**Trade-offs**: 升维过度会空心——必须保留可操作一招鲜。  
**句式**: 见 SKILL / ch02「技术→科学升维」。

## Pattern: 灵魂五问立项包
**When to use**: 写/重写立项依据。  
**How**: 五答齐→可合并段落→第2层最长→第3层假说可见→第5层一招鲜+图。  
**自检清单**:
- [ ] 小标题是观点不是「国内外研究现状」
- [ ] 第2层有归纳句，非文献流水
- [ ] 假说含干预后演化
- [ ] 难点是科学层不是经费层
- [ ] 末图能看出结构路径  
**Trade-offs**: 五问机械分段会僵；合并可以，缺答不行。

## Pattern: 宏观一招鲜设计
**When to use**: 创新点虚、路线看不出新意。  
**How**: 选形态（方法/材料/环境/思想）→过四判据→写清干预的科学环节→难点→对策=内容。  
**句式槽位**: `以【干预】作用于【环节】，预期【结构变量】→【过程变量】；区别于【旧套路】在于【】。`

## Pattern: 底层构效三跳
**When to use**: 停留在热点词贴标签。  
**How**: 操作↔性能（弃）→ 操作↔热点参量（不够）→ **底层结构↔参量/本质过程**（要）。  
**自检**: 底层结构是否有独特性定语？能否指导他领域？

## Pattern: 内容—目标—方案分栏术
**When to use**: 三栏重复。  
**How**: 内容用「揭示/阐明/解析」思想动词；方案用操作动词+证据；目标用「建立/形成/为…提供科学依据」。  
**审查**: 任意抽一句，遮挡栏名，应仍能判断属于哪栏。

## Pattern: 关键科学问题四段
**When to use**: 填写「拟解决的关键科学问题」。  
**How**: 2条；段①总括；②③展开；④「只有解决…才能…理论基础」。  
**禁**: 第三条「优化工艺参数影响因素」。

## Pattern: 摘要预告片
**When to use**: 400字摘要。  
**How**: 问题本质→一招鲜思路→2–3个通过句（落机制）→科学依据。  
**禁词表**: 研制、开发、完善、优化、工艺攻关（作主语时）。  
**句簇**: `通过【】，研究【】，揭示【机制】；…建立【构效】，为【技术】提供科学依据。`

## Pattern: 题目三槽编码
**When to use**: 起名/改名。  
**How**: 槽1方法 槽2结构/过程问题 槽3机制目标；删「研究」；一行。  
**例型**: `【热冲击】调控【硅碳复合结构】增强【储锂】机制`

## Pattern: 文献俯视精读（文献灵魂五问）
**When to use**: 写脉络、怕被文献带着走。  
**How**: 每篇答五问；抽共性；问题引导检索；段末亮剑结论；少写人名单位。  
**Trade-offs**: 「强行凝练」无功底会变成曲解——需顶刊精读支撑。

## Pattern: 漂移校准
**When to use**: 学院标签与目标对象冲突。  
**How**: 以产品/过程目标定母学科科学问题（如结晶成核）→ 学院只作平台定语。  
**自检**: 关键科学问题词是否来自目标过程教科书？

## Pattern: 可行性—基础条目对齐
**When to use**: 函评脱节、基础像简历。  
**How**: 按内容编号重排；理论/材料/设备/一招鲜/预实验分条；基础写贡献迁移。  
**禁**: 头衔可行性。

## Pattern: 循环嵌套发布检查
**When to use**: 临提交。  
**How**: 走 ch13 修改序至少两轮；最后关摘要与题目。  
**总清单**:
- [ ] 全篇科学词汇主语占比目测过半
- [ ] 假说可证伪句存在
- [ ] 一招鲜在题目/摘要/五问5/路线/创新重复一致
- [ ] 内容条数与年限匹配且有逻辑收束
- [ ] 关键科学问题=2
- [ ] 方案≠内容复制
- [ ] 可行性无头衔炫
- [ ] 基础按贡献条目化
- [ ] 图≥依据5、路线可读
- [ ] 无 AI 空洞段（见下）

## Pattern: 去 AI 味消毒
**When to use**: 行文通顺但评审可能标「空」。  
**How**: 每段强制绑定 {机制变量, 边界条件, 证据类型}；删除纯连接词段落；科学问题禁止「问模型生成」。  
**AI 败笔对照**:
| 空句 | 实句要素 |
|---|---|
| 深入揭示内在机制 | 指明结构变量S与过程R的关系命题 |
| 理论与实验相结合 | 计算回答哪一假设；实验测哪一量 |
| 具有重要科学意义 | 意义=可迁移的设计原则/科学依据指向 |
| 系统优化关键参数 | 改为调控主导结构的因子集 |

## Pattern: 函评意见翻译
**When to use**: 拿到意见翻修。  
| 意见 | 动作 |
|---|---|
| 科学问题不凝练 | 拆二级术语+加定语+缩到主导环节 |
| 创新性不足 | 补一招鲜四判据与四类创新归位 |
| 太技术 | 升维术+禁词清洗 |
| 无假说 | 假说公式补全 |
| 逻辑不清 | 五问重排+岭侧峰编号 |
| 与现有区别不明 | 处处显差，不换题只换「可见性」 |
