# Patterns · 可执行方法与句式

## P1 技术→科学升维（破乳测试）

**何时用**：用户只写制备/性能/工艺优化。

**操作**：固定同一载体，强制四视角各写一句，只保留本学科最深的一句进本子。

| 视角 | 句式槽位 |
|---|---|
| 纯技术 | 制备{材料}并优化{性能指标}至{值} |
| 化学 | {过程}的本质是{键/反应}如何{改变} |
| 材料 | 通过{新结构}强化{氢键/界面/缺陷…}调控 |
| 化工 | {反应–结构}如何强化{传质/传热} |
| 催化 | {电子结构/活性位}如何演变并决定{选择性} |

**自检**：若删掉性能数字后句子仍成立且可证伪 → 更像科学问题。

## P2 物质类标准三段

```
性能现象（载体）→ 主导尺度关键结构是什么 → 该结构如何被调控出来（机制）
```

句式：

> 现有工作多停留在提升{性能}；其控制步骤在于{尺度}下{结构单元}的{状态}；本项目假说：通过{宏观一招鲜}调控{结构参量}，从而改变{过程}并检验{可观测响应}。

## P3 能量类标准三段

```
宏观能耗/通量问题 → 传递/转化瓶颈环节 → 强化传递的机制与可测通量
```

## P4 假说生成

**定义（书意）**：分析科学本质后，用新方法干预该本质，得到的**假设结论**即假说。

句式：

> 若{干预}改变{结构/边界条件/通量}，则应观测到{可区分预测 A 而非 B}；该预测与前人{路径}的差异在于{机制点}。

## P5 宏观一招鲜绑定

一招鲜必须同时回答：

1. 干预哪个底层过程？
2. 为什么这一招比现有路径更贴机制缺口？
3. 技术路线哪一步实现它？
4. 哪张图一眼能看见它？

## P6 研究内容条目句

每条研究内容建议形态：

> 针对{科学问题子问题}，阐明/揭示{机制}，建立{关系/模型}，形成{可检验输出}。

禁用单独成条：优化工艺、提高性能、开发装置（除非明确作为机制验证载体且不占科学主语）。

## P7 AI 常见败笔 → 修复

| AI 味 | 修复 |
|---|---|
| “具有重要理论意义和应用价值”空段 | 删；或改成 1 个可核对事实 + 1 个机制缺口 |
| 并列四大属性口号 | 只选一类属性，其余不作标题墙 |
| 无投喂综述 | 强制文献清单与“结论句”绑定后再生成 |
| 创新点=“首次结合 A 与 B” | 改为干预点 + 可区分预测 |
| 技术路线只画实验流程 | 叠加科学问题获得路径与五问标注 |
