# 从技术问题到科学问题（基金本子写作）
**作者**：公旭中 | **ISBN**：978-7-03-084903-8 | **章节**：13 | **Generated**：2026-11-02

## 服务边界（硬规则）

| 本技能服务 | 本技能不服务 |
|---|---|
| 国自然青基/面上/重点等**申请书**结构、措辞、逻辑自检 | 论文 Methods/Results 正文写法、投稿策略 |
| 把技术/工程痛点**升维**为可函评的科学问题与假说 | 代替申请人做实验设计细节或伪造预实验 |
| 立项依据、摘要、题目、研究内容、技术路线、创新点对齐 | 经费预算表格填写、单位行政管理流程 |
| 去 AI 味：机制—边界—可证伪—证据绑定 | 空洞“创新性/重要性”口号堆砌 |

**与论文技能边界**：基金与 SCI「本质都是回答科学问题」，但基金写的是**拟探究的路径与假说**（大胆假设+可检验设计），SCI 写的是**已获得证据后的结论**。基金忌「研制/优化/开发」主导；SCI 可用性能数据作主线，但仍应以底层构效关系为思想主线（见 ch03、ch11）。

## 何时触发

- 用户要写/改**国自然或同类基金本子**任一栏目
- 用户稿件被批「太技术/像工程/科学问题不凝练/没有假说」
- 用户需要把行业痛点改写成**可检验科学问题**
- 用户摘要/题目/创新点「像 AI」或口号化
- 用户研究内容、目标、方案、可行性**互相重复或脱节**

## 核心心智模型（先加载）

### 1. STE 三分法 → 基金写什么
- **科学**：发现规律（公式/定理/逻辑）
- **技术**：发明方法与装备（科学的集合体）
- **工程**：有组织集成技术（技术之间的底层逻辑也是科学问题）
- **判据**：基金不以「开发产品/优化工艺」为主导；技术问题是**载体**，要呈现关键、共性、基础内涵。禁用高频：完善、开发、优化、研制（作者称其为「59→60 分」而非「0→1」用语）。

### 2. 升维链（全书主轴）
`行业宏观痛点 → 技术瓶颈 → 底层物理/化学/生物过程 → 主导尺度关键结构 → 宏观一招鲜干预 → 干预后演化假说 → 可检验研究内容`

### 3. 两大类科学问题
| 类 | 核心 | 典型落点 |
|---|---|---|
| **能量类（化工型）** | 传递 | 「三传一反」+ **界面结构**（界面性质是功能，不是本征问题） |
| **物质类（材料型）** | 结构 | **结构调控机制** + **构效关系**；先找主导尺度关键结构 |

### 4. 底层构效关系（三层，勿停在表层）
1. 表面：宏观操作 ↔ 宏观性能（不够）
2. 次深：热点物理参数（能带、异质结、d带中心…）↔ 性能（仍不够）
3. **底层**：宏观操作所得**分子/电子等底层结构** ↔ 热点参数/理化本质过程（基金与高分 SCI 要写到这一层）

### 5. 宏观一招鲜（创新的可操作抓手）
新方法/新材料/新环境（体系）/新思想，须同时：**能干预科学问题走向**、**可操作**、**新颖独特**；最好自设问题从 0→1。干预后底层逻辑演化 = **科学假说**。

### 6. 灵魂五问（立项依据骨架）
1. 为何做？宏观必要性与科学本质是什么？
2. 前人如何推进？未解决的**科学本质**缺口是什么？（主线；约 1200–1500 字量级）
3. 你的创新思路/假说是什么？（思想层）
4. 新方法难点/科学层面挑战是什么？
5. 用什么宏观一招鲜应对难点？（知行合一）

五问可合并段落，但**五个答案必须齐**；顺序体现强调重点。

### 7. 横看成岭侧成峰（系统对齐）
题目/摘要/立项依据/内容/目标/关键科学问题/方案/路线/创新/基础——**同一科学问题的不同层次表达**，条目编号宜一一呼应（如 2.1↔3.1↔4.1↔5.1）。

### 8. 科学假说公式
`假说 = 对新方法干预科学本质之后演化趋势的可检验预判`  
（非「先结论再凑证据」的律师机制；要科学家机制：证据路径清晰。）

## 与基金本子写作的硬规则（句子级入口）

1. **主语用科学词汇**：多尺度结构、界面结构、构效关系、传质、成核—生长…；不以效率/转化率/脱硫率为主语。
2. **关键科学问题写 2 条**（四段式：必要性总括 → 问题1如何研究 → 问题2如何研究 → 解决后影响）；勿写成三条工艺优化。
3. **研究内容 = 科学问题的细化**（做什么才能回答问题），**不是**怎么做；**方案 = 怎么做**；**目标 = 做完怎样（升华到理论基础/科学依据）**。
4. **摘要禁词**：研制、工艺、技术开发、完善、优化（可写「为××技术提供科学依据」作落点）。
5. **题目三要素**：核心方法 + 关键科学问题 + 科学目标；尽量不出现「研究」二字；约一行/≤30 字量级。
6. **文献服务于故事**：问题引导文献；忌人名单位流水账；段末亮自己结论。
7. **预实验 > 头衔**：可行性禁堆杰青/院士；基础按内容条目重排，勿论文清单化。
8. **AI 败笔零容忍**：空洞通顺、无机制边界、科学问题「问 AI 得共性口号」、方案只列仪器不写为何用/如何用。
