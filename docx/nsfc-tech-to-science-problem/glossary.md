# Glossary

| 术语 | 工作定义（写作用） |
|---|---|
| 科学问题 | 技术/工程背后关键、共性、基础的理论问题；基金主写对象 |
| 关键科学问题 | 本项目三年内要回答的、可检验的核心科学问题 |
| 科学假说 | 对新方法干预底层过程后预期结论的可检验陈述 |
| 宏观一招鲜 | 可辨识的宏观干预手段，作用在底层科学过程以体现创新 |
| 主导尺度关键结构 | 决定性能/过程的那一尺度上的关键结构单元及其状态 |
| 构效关系 | 结构特征与功能/性能响应之间的可论证映射 |
| 灵魂五问 | 立项依据五层自问自答章法 |
| 投口 | 申请代码/学科入口；决定大同行可读性与小同行深度 |
| 科学问题发展脉络 | 以科学问题为主线重排文献思想史，非单位人名综述 |
| STE | Science / Technology / Engineering 三分 |
