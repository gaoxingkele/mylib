# Glossary

**STE（科学·技术·工程）** — 科学=发现规律；技术=发明方法装备；工程=有组织技术集成。基金写背后科学，技术/工程为载体。(Ch2)

**一树三果** — 人才/体系叙事：一中心问题下结出理论、共性方法、集成应用三果。(Ch12)

**七个通过** — 摘要多句分工写法：背景/现状/问题/内容方法/意义各司其职；「通过…研究…揭示…」句簇。(Ch9)

**三传一反** — 传质、传热、动量传递 + 反应工程；过程工业能量类科学问题公约数，须加体系定语。(Ch2)

**上层/表面构效关系** — 宏观操作直接连宏观性能；基金与高分文不够用。(Ch3)

**主导尺度关键结构** — 对事物特征起决定作用的尺度上的关键结构；找它难于空喊结构调控。(Ch2, Ch3)

**二级术语拆解** — 把二级学科词拆到一级理化生过程至不可再分，定位干预环节。(Ch3)

**介尺度 / 介科学** — 体系极大与极小之间难认清却决定宏观成败的尺度/中间相问题。(Ch2)

**双本质** — 以科学问题为主线、科学词汇为主语、新方法为抓手，追求「解决本质的方法之本质」。(Ch2)

**四类创新点** — 新理论、新结构、新方法、新应用。(Ch4)

**四面向→四关键** — 面向前沿/主战场/重大需求/生命健康后，再取原始创新、基础前沿、交叉、共性方法。(Ch1)

**底层构效关系** — 宏观操作所得底层结构（分子/电子等）与热点物理参数或性能本质过程之间的关联；真·基础问题。(Ch3)

**律师机制 vs 科学家机制** — 先结论找证据 vs 先证据路径再结论；假说要后者。(Ch2)

**拼图选题** — 只补严丝合缝的缺口块，不揽全图技术。(Ch1)

**投口赋能** — 申请代码选择应让大同行感到新人注入方法，而非抢资源。(Ch1)

**宏观一招鲜** — 新颖可操作、能改写科学问题走向的宏观干预（方法/材料/环境/思想）。(Ch4)

**关键科学问题四段式** — 总括必要性→问题1→问题2→影响收束；宜两条问题。(Ch2, Ch6)

**移花接木 / 借花献佛 / 举一反三** — 邻域迁移写可行性/方案/基础时的合法策略，须论证必要性。(Ch5, Ch8)

**科学假说** — 对科学本质施加新干预后的发展预判/假设结论；本子灵魂。(Ch2)

**科学问题** — 关键、共性、基础的理论问题；技术工艺背后的灵魂。(Ch2)

**科学问题漂移** — 跨学院选题时，问题跟目标对象本质走，不跟单位牌子走。(Ch3)

**科学问题发展脉络** — 立项依据主线：问题被推进的演化，而非文献人名史。(Ch5)

**纯科学—纯技术—纯工程** — 向下兼容光谱；工程科学问题侧重技术间集成逻辑。(Ch2)

**结构终极论 / 结构工程** — 多学科公约数是结构；各学科是不同尺度的结构工程。(Ch3)

**结构调控机制** — 如何通过理化生方法获得目标结构。(Ch2)

**构效关系** — 结构与性能（或行为）的关联机制；内涵通常不小于「机制」一词。(Ch2, Ch6)

**格物** — 分类以求共性规律；喻基金要写共性基础。(Ch2)

**横看成岭侧成峰** — 本子各栏是同一科学问题不同层次表达，宜编号呼应。(Ch5)

**灵魂五问** — 立项依据五层自问自答：为何做；脉络缺口；思路假说；难点；一招鲜对策。(Ch5)

**界面结构 vs 界面性质** — 结构本征，性质为功能表现；勿把性质当终点科学问题。(Ch2)

**循环嵌套修改** — 内容目标↔依据↔问题↔方案↔可行性基础↔摘要的系统反复。(Ch13)

**亮剑精神** — 用自己的科学语言给文献下结论，服务故事主线。(Ch3)

**题目三要素** — 核心方法、关键科学问题、科学目标。(Ch9)
