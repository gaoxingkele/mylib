# 术语表（凝练科学问题案例）

**四类科学问题属性** — 鼓励探索·突出原创；聚焦前沿·独辟蹊径；需求牵引·突破瓶颈；共性导向·交叉融通。选题坐标系，非装饰标签。(Ch01)

**六路凝练法** — 好奇引导、无穷追问、反常深挖、范式变革、同行收敛、需求抽象。(Ch02)

**案例陈述四段式** — 探索过程 → 面临困难 → 创新点 → 意义。(Ch01)

**科学问题** — 以未知与可检验为核心的设问；非工程任务书，非价值宣示。

**认知局限** — 学界可点名的错误断言或边界（如“某尺度不可能”）。(Ch03)

**突破口** — 大谜题上当下可实验/可计算的最关键一环。(Ch02, Ch03)

**需求抽象 / 抽提** — 从卡脖子或应用痛点升维到底层原理、模型或算法未知。(Ch02, Ch05)

**独辟蹊径** — 相对主流路径的分叉点（困境→新表征/新路径/新检验场）。(Ch04)

**交叉接口** — 两域可同时解释的变量、结构或约束；无接口则非交叉。(Ch06)

**知识体系增量** — 对理论、观测疆域、概念定义或方法能力边界的可指名扩展。(Ch01, Ch08)

**可证伪 / 可检验** — 存在能使问题失败的观测、计算或实验判据。(Ch07)

**技术堆砌** — 方法名词密集、未知量缺席的病句类型 P1。(Ch07)

**口号化** — 战略修辞密集、机制词缺席的病句类型 P2。(Ch07)

**工程冒充科学** — 以研制/开发/实现为问题谓语的病句类型 P4。(Ch05, Ch07)

**三栏对齐** — 科学问题、研究内容、创新点同构映射。(Ch08)

**检验场** — 能严格测试方法/理论的场景（如相图计算）。(Ch04)

**原位 / 保真** — 在真实赋存条件下保持并测量对象状态的一类瓶颈问题。(Ch05)

**追问迭代** — 用连环问号逼近可观测最弱环，终稿收敛为单主问。(Ch02, Ch03)

**无人区** — 原创属性下可辩护的新问题空间；须有认知局限证据，禁止口号空喊。(Ch03)
