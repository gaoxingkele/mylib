# 第4章：聚焦前沿·独辟蹊径 — 案例族程序

## Core Idea
前沿类默认热点已拥挤；胜负手是**分叉点**（新路径/新检验场/新约束下的老问题），问题句要显式写出“相对主流路径，你岔在哪”。

## Frameworks Introduced
- **独辟蹊径三件套**：主流做法 → 其结构性困境（精度/效率/可解释/可观测）→ 你的分叉（新表征、新融合、新几何量……）

## 案例族

### 族F 精度-效率两难分叉（数据与机理融合型）
| 环节 | 模板 |
|------|------|
| 病句 | 利用人工智能研究复杂分子体系 |
| 病型 | 技术堆砌；AI 作主语；无科学未知 |
| 改写操作 | 写清两难；指定融合对象；给出最严检验场 |
| 可检验句 | 在必须兼顾〔第一性原理级精度〕与〔大体系长时间采样效率〕时，如何用〔数据-机理融合表示〕构造满足〔对称性/广延性等物理约束〕的高维势能，并以〔相图等〕严苛测试验证？ |
| 内容映射 | 约束描述子；同步学习数据生成；误差可控热力学量 |
| 创新映射 | 融合范式本身 + 使物理约束在数据模型中可执行的结构 |

### 族G 新观测窗口/新探针（活体测量、阿秒、外泌体芯片等）
| 环节 | 模板 |
|------|------|
| 病句 | 发展高时空分辨成像技术并应用于…… |
| 病型 | 仪器研发清单；科学问题缺席 |
| 改写操作 | 技术降为窗口；问题=窗口打开后首次可问的机制 |
| 可检验句 | 在〔生物相容/损伤阈值〕约束下，能否对〔动态过程〕实现〔时空分辨率〕观测，从而判定〔机制假说A vs B〕？ |
| 内容映射 | 探针/源/探测链路；标定；机制解析实验 |
| 创新映射 | 使不可见变为可见的测量原理；或由此推翻的旧图像 |

### 族H 前沿对象+独有几何/不变量（宇宙学距离、拓扑磁、FRB 等）
| 环节 | 模板 |
|------|------|
| 病句 | 开展〔热门天体/材料〕多波段观测与物性研究 |
| 病型 | 过宽领域标签 |
| 改写操作 | 收束到一个可判决的几何量/不变量/深度观测策略 |
| 可检验句 | 〔对象〕的〔快速变化/相界/距离〕由何种物理主导？提出的〔几何测量/场调控〕能否在〔误差预算〕内区分竞争模型？ |
| 内容映射 | 模型竞争列表；观测量设计；系统误差控制 |
| 创新映射 | 新测量原理或新调控自由度 |

### 族I 交叉前沿的“点”收敛（细菌耐药、细胞异质性等）
| 环节 | 模板 |
|------|------|
| 病句 | 多学科交叉系统研究细菌耐药性 |
| 病型 | 不可证伪；交叉空壳 |
| 改写操作 | 定位交叉点/盲点/难点各一；主问唯一 |
| 可检验句 | 耐药形成的速率限制步骤是〔遗传/代谢/生态位〕哪一类？在〔交叉接口〕上可干预的控制原理是什么？ |
| 内容映射 | 机制分层实验；控制策略验证 |
| 创新映射 | 在交叉点提出的可迁移控制原理（非堆学科名称） |

## Mental Models
- Use **族F** when 用户把深度学习当万能词：逼问物理约束与检验场
- Use **“最严苛测试”** when 新方法宣称通杀：必须自选能证伪自己的场景（如相图）
- Think of **独辟蹊径** as 相对坐标：没有“相对谁”，就没有蹊径

## Anti-patterns
- **热点名词云**：拓扑+量子+智能+精准并列
- **方法创新冒充科学问题**却不说要判决什么科学断言
- **为交叉而交叉**：无接口变量

## Worked Example
**病句**：基于大数据和深度学习的水分子高精度模拟。  
**改写**：传统第一性原理准而不快、经验力场快而不准；关键问题是带物理约束的高维势能可学习表示，并以水相图为严苛检验。  
**内容↔创新**：深度势能+同步学习 ↔ 融合范式与可扩展到亿原子的能力边界外推。

## Key Takeaways
1. 前沿本子要写出“岔路”，不是“也做前沿”。
2. 工具必须服务可判决命题。
3. 自选能打死自己方法的检验场，是独辟蹊径的可信信号。
