# 第1章：四类科学问题属性与案例陈述四段式

## Core Idea
先定**属性锚点**（四类导向之一），再用固定四段式把“故事”压成可审核的科学问题陈述；属性选错，后面句式再漂亮也难过函评对口审查。

## Frameworks Introduced
- **四类科学问题属性框架**（基金资助导向原词）
  - When to use: 选题立项、申请书“科学问题属性”勾选与全文自洽检查
  - How:
    1. **鼓励探索，突出原创**：未知区/新概念/反“不可能”，主产出是知识增量或范式起点
    2. **聚焦前沿，独辟蹊径**：热点已在，但切入角、路径或检验场与主流分叉
    3. **需求牵引，突破瓶颈**：卡脖子/重大需求先在，再抽提可检验的底层未知
    4. **共性导向，交叉融通**：跨学科共性问题或统一描述，主轴是“接口/同构/可迁移规律”

- **案例陈述四段式**（全书 81 案统一骨架）
  - When to use: 写“拟解决的关键科学问题”、答辩口述、组内凝练会
  - How:
    1. **探索过程**：现象/矛盾 → 既有认知局限 → **凝练出的问题句**
    2. **面临的困难**：理论空白 / 测量不能 / 尺度不可达 / 计算不可承受（写成可检验障碍，不写情绪）
    3. **创新点**：针对困难的新概念、新路径、新观测或新算法（与问题一一对应）
    4. **意义**：知识体系增量（必写）+ 应用潜力（可写，不可替代增量）

## Key Concepts
- **属性自洽**：勾选属性、问题句、研究内容、创新点必须同一叙事轴
- **认知局限**：学界“认为……不可能/已解决/只需工程优化”的可证伪断言
- **知识体系增量**：相对既有理论/观测/方法边界的可指名扩展

## Mental Models
- Use **属性优先** when 题目很大：先问“这是原创破无、前沿岔路、需求抽提，还是交叉共性？”再写句
- Think of **四段式** as 函评读本：评委 2 分钟内应能复述“问什么—难在哪—你怎么破—增什么”

## Anti-patterns
- **属性口号贴标**：正文全是技术路线，仅在表格勾“突出原创”
- **意义淹没问题**：先写国家战略长段，问题句仍是“开展……研究”
- **困难=工作量**：把“工作量大、经费不足”写成科学困难

## Worked Example
**输入（病句）**：面向高端制造开展超滑涂层研发与应用示范。  
**属性判定**：若真未知在机制/尺度可行性 → 偏“鼓励探索”；若仅为工艺优化 → 不构成该类。  
**四段压缩**：
1. 探索：纳米非公度界面可超滑，但微米以上曾被论证“不可能” → 问：材料变形下微米级结构超滑是否可实现及其耗散机制？
2. 困难：动摩擦声子/电子通道不明；大面积原子级表面与组装缺失
3. 创新：各向异性力学切入 + 异质/异维体系 + 耗散抑制
4. 意义：建立结构超滑理论框架；器件长寿命接口设计新维度

## Key Takeaways
1. 属性是选题坐标系，不是装饰标签。
2. 四段式强制“问题—困难—创新—增量”对齐，专治技术堆砌。
3. 困难必须可被实验/理论/计算击穿，否则创新点无处落点。
4. 意义段先写知识增量，再写应用，顺序不可反。
