# 第3章：鼓励探索·突出原创 — 案例族程序

## Core Idea
原创类不是“第一次做某技术”，而是**挑战既有断言/提出新概念/打开不可达观测**；问题句要让反对意见可被点名。

## Frameworks Introduced
- **原创三判据**：①挑战“不可能/已足够”的既有断言；②提出可操作的新概念或新观测窗口；③知识增量可指名（理论/核素图/活性中心定义等）

## 案例族（病句 → 改写 → 可检验句式 → 映射）

### 族A 尺度/条件突破（结构超滑型）
| 环节 | 模板 |
|------|------|
| 病句 | 开展先进超滑材料制备与器件应用研究 |
| 病型 | 技术堆砌 + 不可证伪“开展研究” |
| 改写操作 | 钉死被挑战断言 + 尺度/条件边界 + 机制未知量 |
| 可检验句 | 在〔材料变形不可忽略的尺度〕，〔非公度范德华界面〕能否实现近零摩擦无磨损？耗散通道是〔声子/电子/其他〕？ |
| 内容映射 | 跨尺度力学表征；耗散抑制；异质/异维体系扩展 |
| 创新映射 | 思路翻转（损伤→可设计零耗散界面）；体系维度迁移 |

### 族B 无穷追问链（正反核物质型）
| 环节 | 模板 |
|------|------|
| 病句 | 深入研究宇宙正反物质不对称之谜 |
| 病型 | 口号化大谜题、无突破口 |
| 改写操作 | 总谜→可实验室制造/探测的最弱环；问号链收敛为 1 主问 |
| 可检验句 | 高能重离子碰撞中能否产生并精准捕捉〔反物质原子核〕？其截面/质量/寿命/相互作用可否作为检验〔对称性断言〕的输入？ |
| 内容映射 | 产生条件；触发与鉴别；关联量测量 |
| 创新映射 | 探测极限拓展；传统核方法迁移到反物质；电子学/算法使信号可提取 |

### 族C 新概念范式（单原子催化型）
| 环节 | 模板 |
|------|------|
| 病句 | 开发高效贵金属催化剂提升原子利用率 |
| 病型 | 工程目标冒充科学问题 |
| 改写操作 | 从性能指标回退到**概念定义**与可表征活性中心 |
| 可检验句 | 活性金属以〔单原子分散〕负载时，活性中心结构与反应机理能否被〔球差电镜/XAFS/探针红外+计算〕唯一确定？稳定性与选择性的微观起源是什么？ |
| 内容映射 | 精准制备；静态+原位动态表征；理论闭环 |
| 创新映射 | 新概念（单原子催化）及由其引发的研究范式 |

### 族D 反常深挖（铜表面抗氧化型）
| 环节 | 模板 |
|------|------|
| 病句 | 偶然发现抗氧化铜纳米片并开展应用 |
| 病型 | 轶事化；缺机制与可重复边界 |
| 改写操作 | 意外→机制确认→可推广钝化策略 |
| 可检验句 | 〔还原剂/水热〕条件下铜表面重构形成的〔配位超结构〕是否为抗氧化主因？引入〔配体〕钝化缺陷后性能提升是否可重复定量？ |
| 内容映射 | 制备-表征-计算闭环；缺陷位点钝化 |
| 创新映射 | 表面配位钝化新策略（机制层，非产品层） |

### 族E 范式对话（病证结合型）
| 环节 | 模板 |
|------|------|
| 病句 | 推动中西医结合实现精准诊疗 |
| 病型 | 口号化；两套概念未定义交集 |
| 改写操作 | 选中介表征（如生物网络）+ 典型病/证对象 |
| 可检验句 | 以〔生物分子网络〕为中介，〔证候表型〕与〔疾病微观指标〕如何系统关联？能否发现具诊疗意义的病证标志物？ |
| 内容映射 | 网络构建；宏微整合算法；临床/实验验证 |
| 创新映射 | 还原论与系统论可对话的方法学 |

## Mental Models
- Use **族A** when 文献有“尺度不可行”铁律可打
- Use **族C** when 真正贡献是命名与可操作定义，而非多测几组数据
- Prefer **知识增量句** in 意义段：拓展了哪张图、填了哪块空白

## Anti-patterns
- **把首次国产/首次集成叫原创科学问题**
- **概念未定义就宣称范式革命**
- **追问链写进摘要却无主问题**

## Key Takeaways
1. 原创问题句应使“反对者的断言”可见。
2. 新概念必须带表征与判据，否则是口号。
3. 反常必须机制化；需求应用是下游，不是问题本身。
