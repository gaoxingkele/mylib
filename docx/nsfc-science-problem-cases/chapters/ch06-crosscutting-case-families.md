# 第6章：共性导向·交叉融通 — 案例族程序

## Core Idea
交叉类失败几乎总因**只有并置没有接口**；成功程序是找到跨域**同构量/中介结构/统一约束**，问题句必须点名该接口。

## Frameworks Introduced
- **交叉接口法则**：两个领域名词并列 ≠ 交叉；必须出现可在两边同时解释的变量、结构或守恒/局部性等共性
- **共性可迁移测试**：结论换一个应用域是否仍可陈述为同一科学问题

## 案例族

### 族N 统一建模/同构（局部性统一建模型）
| 环节 | 模板 |
|------|------|
| 病句 | 开展高性能计算与领域应用交叉研究 |
| 病型 | 交叉空壳；技术堆砌 |
| 改写操作 | 指出分层模型错位；定义两边共享的局部性/分治结构 |
| 可检验句 | 领域〔物理/数学〕模型的本质局部性与计算模型局部性如何建立对应，使资源优化不破坏问题结构？该对应可否形式化并自动调优？ |
| 内容映射 | 对应映射；渗透/保持局部性的模型；自动调优器 |
| 创新映射 | 跨抽象层的统一局部性建模（共性），而非单域加速技巧 |

### 族O 系统动力学共性（肿瘤耐药、交通韧性等）
| 环节 | 模板 |
|------|------|
| 病句 | 多组学揭示肿瘤耐药机制并开发逆转策略 |
| 病型 | 过宽；不可证伪 |
| 改写操作 | 升到系统动力学层：状态、反馈、时间尺度、可观测模态 |
| 可检验句 | 耐药/失稳是否由〔跨尺度反馈结构〕主导？在多模态数据下，系统动力学模型对〔表型转换〕的预测可否被干预实验证伪？ |
| 内容映射 | 跨尺度观测；动力学建模；干预检验 |
| 创新映射 | 把零散分子事实收束为可迁移动力学机制 |

### 族P 界面/机器共性原则（纳米-细胞界面、框架核酸机器、人机紧耦合等）
| 环节 | 模板 |
|------|------|
| 病句 | 研究纳米材料与细胞相互作用促进转化应用 |
| 病型 | 口号+过宽 |
| 改写操作 | 界面作用物理量；调控策略的可迁移性 |
| 可检验句 | 〔纳米粒子-细胞膜〕界面力/化学识别的主导通道是什么？调控〔参数〕能否跨细胞类型预测结局？ |
| 内容映射 | 界面物理化学测量；调控；通则边界 |
| 创新映射 | 界面共性规律与调控原理 |

### 族Q 文明-环境等弱约束交叉（海岸带等）
| 环节 | 模板 |
|------|------|
| 病句 | 多学科综合研究人地关系与文明演进 |
| 病型 | 不可证伪宏大叙事 |
| 改写操作 | 限定时空窗口；可代理指标；假说竞争 |
| 可检验句 | 在〔海岸带时段/区域〕，〔环境代理指标〕变化与〔文化遗存指标〕是否存在可检验的耦合型式？主导方向是环境约束还是社会选择？ |
| 内容映射 | 指标重建；年代框架；耦合模型 |
| 创新映射 | 可证伪的耦合机制，而非史诗综述 |

## Mental Models
- Use **同构提问** when 用户只会写“A 领域方法用于 B”：追问守恒的是什么结构
- Use **可迁移测试** when 判断真共性 vs 一次性工程拼盘
- Prefer **一个接口变量** in 摘要：评委应能复述接口名

## Anti-patterns
- **学科名录交叉**：材料+信息+医学+管理…无主轴
- **借用热点方法贴自家数据**却无共性理论诉求
- **系统/复杂/智慧**三词架空动力学

## Worked Example
**病句**：交叉研究物理问题与计算机体系结构以提升性能。  
**接口**：局部性（分而治之）在问题模型与计算模型间错位。  
**科学问题**：如何统一建模两边局部性并在优化计算资源时保持问题本质结构？  
**映射**：内容=对应与调优；创新=统一建模；单应用加速仅为检验。

## Key Takeaways
1. 交叉融通的主语是接口与共性，不是团队花名册。
2. 系统层问题要有状态与反馈，否则仍是还原论拼盘。
3. 共性导向可用“换域是否同问”自检。
