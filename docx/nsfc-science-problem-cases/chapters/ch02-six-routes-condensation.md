# 第2章：六路凝练程序（前言方法论蒸馏）

## Core Idea
书中不承认单一“公式”，但前言提炼出六条可迁移路径；执行时**选一路为主、一路为辅**，把现象压成可检验问句。

## Frameworks Introduced
- **六路凝练法**
  - When to use: 有素材无线索，或申请书问题句像综述标题时
  - How（每路：触发 → 步骤 → 产出句式）：

### 路1 好奇引导
- 触发：奇特现象/生物/材料行为引发持续兴趣（非跟风热点）
- 步骤：现象描摹 → 功能/行为未知点 → 机理假说 → 可测指标
- 句式：`在〔边界条件〕下，〔对象〕为何呈现〔反常/特异行为〕？其控制变量是〔X〕还是〔Y〕？`

### 路2 无穷追问
- 触发：大谜题已公认，但缺可实验的突破口
- 步骤：总问 → 若A则B？→ 若产生则如何存活/探测？→ 钉死**可观测链最弱环**
- 句式：`是否〔可观测事件〕？若是，〔量〕如何测量并用于检验〔理论断言〕？`（允许 3–9 环问号，终稿只保留主问+1–2子问）

### 路3 反常深挖
- 触发：实验“意外成功/失败”、与预期符号相反
- 步骤：冻结意外条件 → 排除假象 → 机制刻画 → 上升为可推广策略
- 句式：`〔意外现象〕是否源于〔候选机制〕？在〔对照〕下该机制可否重复并推广到〔类对象〕？`

### 路4 范式变革
- 触发：两套话语体系/两种计算范式长期并立且互不翻译
- 步骤：指出范式裂缝 → 选可对话的中介表征 → 定义可共享观测
- 句式：`如何用〔中介表征〕统一描述〔范式A概念〕与〔范式B概念〕，并给出可检验的〔标志物/不变量〕？`

### 路5 同行收敛
- 触发：大方向或交叉题目初提后意见发散
- 步骤：双清/专题会多元视角 → 删除不可操作支路 → 收敛为共识主问
- 句式：`在〔交叉接口〕上，制约〔现象〕的共性未知是〔主问〕；分支〔子问〕仅当服务主问时保留。`

### 路6 需求抽象
- 触发：卡脖子技术/重大工程痛点清晰，但本子写成产品清单
- 步骤：痛点 → 拆“保什么/难在哪” → 抽底层原理/模型/算法未知 → **技术目标降为检验场**
- 句式：`〔工程目标〕受阻于〔不可测/不可建模环节〕；关键科学问题是〔原理/规律/算法〕，判据为〔指标〕。`

## Key Concepts
- **突破口**：把不可实验的总谜题改写成当下可做的最关键一环
- **反常之中的正常逻辑**：意外必须能讲成机制，否则只是轶事
- **抽提**：需求→科学问题的升维动作（非把科学问题写成需求复述）

## Mental Models
- Use **无穷追问** when 总问题太神（宇宙/意识/肿瘤耐药“全部机制”）
- Use **需求抽象** when 用户稿充满“研制、突破、国产替代”而缺少未知量
- Prefer **反常深挖** over 编故事：有真实意外数据才走此路

## Anti-patterns
- **六路并行口号**：一段里同时宣称好奇、原创、卡脖子、交叉，主轴失踪
- **追问不停机**：终稿仍有一串无答案优先级的问号
- **假反常**：把文献已解释现象包装成“意外发现”

## Worked Example（需求抽象）
**工程痛点**：深地取芯后测得参数非原位。  
**错误句**：研发深部保真取芯装备与测试系统。  
**抽象**：保什么（压/温/质/湿/光）→ 怎么保 → 如何在保真条件下测。  
**科学问题句**：深部原位条件下岩芯“五保”取芯与保真测试的原理与可实现性是什么？如何获得真正的原位物理力学参数？  
**映射**：内容=原理+密封/相变/重构方法+率定；创新=思想原理/装备/平台三层；装备是载体不是问题本身。

## Key Takeaways
1. 六路是生成器，不是排比修辞。
2. 每路都要落到**可观测/可计算/可证伪**的终句。
3. 需求路径必须完成“抽提”，否则属性应改工程类项目而非基金科学问题。
4. 同行收敛用于删枝，不用于堆人名。
