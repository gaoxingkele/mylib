# 第7章：问题表述病句类型与改写操作（句子级）

## Core Idea
多数本子死于**问题句不可审**；先识别病型，再套改写操作，最后用可检验句式验收。

## 病句类型总表（优先打击）

| 代码 | 病型 | 识别告诉 | 典型残骸 |
|------|------|----------|----------|
| P1 | 技术堆砌 | 方法/平台/材料名词 ≥3 且无未知量 | “基于A+B+C开展……研究” |
| P2 | 口号化 | 面向/赋能/助力/强国/卡脖子密集，缺机制词 | “服务国家战略，突破卡脖子” |
| P3 | 不可证伪 | 全面/系统/深入揭示……规律 | 无失败条件 |
| P4 | 工程冒充科学 | 研制/开发/实现/建成作谓语中心 | 产品目标=问题 |
| P5 | 过宽标签 | “XX机理研究”“多因素影响” | 无边界、无竞争假说 |
| P6 | 已知可答包装 | 文献已有定论仍当创新问题 | 复习题 |
| P7 | 多问并联无主轴 | 一句内三个“和/与/及其”问题 | 评委无法复述主问 |

## 改写操作（可执行）

1. **钉未知量**：把谓语从“开展/研究”改为“是否/如何/在何种条件下”
2. **显式边界**：补〔对象〕〔尺度/环境〕〔约束〕
3. **嵌入可观测量**：截面、相界、期望、标志物、误差预算…
4. **写出对照/竞争**：相对主流路径/相对断言X
5. **工程降维**：研制→载体；指标→检验锚
6. **单主问**：并联问题改编号子问，摘要只留主问
7. **删价值副词**：先删“重大/颠覆/全面”，看句子是否还能站立

## 可检验科学问题句式库（直接套槽）

**机制型**  
`在〔边界〕下，〔现象〕的主导机制是〔H1〕还是〔H2〕？可用〔观测/实验〕区分。`

**存在/可达型**  
`〔曾被认为不可能的状态〕在〔尺度/条件〕是否可实现？判据为〔定量指标〕。`

**表示/计算型**  
`在〔物理约束〕下，如何表示〔高维对象〕使〔精度〕与〔效率〕同时满足〔检验场〕？`

**预测/决策型**  
`〔系统〕中〔量〕的〔偏差来源〕是否导致〔系统性谬误〕？新方法在〔时效×误差〕上可否证伪？`

**接口/共性型**  
`〔域A结构〕与〔域B结构〕通过〔接口量〕如何对应？该对应能否迁移到〔第二应用〕？`

**抽提型（需求）**  
`〔工程失败模式〕根子是〔不可测/不可建模环节〕；科学问题是〔原理〕，工程指标〔I〕仅作验收。`

## Worked Example（同一课题三连改）
1. 原稿：面向新一代信息技术，基于大数据、人工智能与数字孪生，系统深入研究智能制造关键科学问题。  
2. 去堆砌+去口号：智能制造产线中，设备级异常到产线级停机的传播是否存在可计算的网络结构？  
3. 可检验终句：在〔离散事件+资源约束〕下，连锁停机期望是否被现行局部规则系统性低估？提出的传播算法在〔厂级日志〕上误差与时效的可接受域是什么？

## Anti-patterns（AI 常见败笔）
- 用“本研究旨在……”绕开问题句
- 用“填补空白”“国际领先”代替未知量
- 把创新点写成“首次将A用于B”而无科学断言
- 四属性名称堆进一句当修辞

## Key Takeaways
1. 先诊断病型，再改写，禁止直接润色。
2. 可检验 = 允许失败的观测或计算判据。
3. 技术名词最多服务一个未知量。
