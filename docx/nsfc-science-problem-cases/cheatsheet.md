# 决策速查（凝练科学问题）

## 30 秒病句扫描
若命中任一条 → 先改写再扩写：
- 方法名词 ≥3 且无“是否/如何/在何种条件下” → **技术堆砌**
- “赋能/助力/面向/卡脖子”密集 → **口号化**
- 谓语中心是研制/开发/实现/建成 → **工程冒充**
- “全面/系统揭示规律”且无判据 → **不可证伪**
- 一句多个并列大问题 → **无主轴**

## 属性选择树
- 主要在打“不可能/无概念”？ → **鼓励探索·突出原创**
- 热点已在，比的是岔路与检验场？ → **聚焦前沿·独辟蹊径**
- 先有痛点/卡脖子，再抽原理？ → **需求牵引·突破瓶颈**
- 真贡献是跨域接口或统一描述？ → **共性导向·交叉融通**
- 说不清 → 停写；先做 Ch01 属性锚定

## 六路选择（主一路）
| 线索 | 走路 |
|------|------|
| 奇特现象长期吸引 | 好奇引导 |
| 大谜题缺实验环 | 无穷追问 |
| 意外数据 | 反常深挖 |
| 两套话语无法翻译 | 范式变革 |
| 交叉会上意见爆炸 | 同行收敛 |
| 产品/国产替代话术多 | 需求抽象 |

## 需求升维判据
- 保留：不确定结构、规模障碍、不可测原位量、系统性计算谬误  
- 降级为载体：系统、平台、装备、App、产线示范  
- 放到意义/考核：分钟级时效、亿元效益、国产替代率

## 三栏对齐快检
对每个 Qi：能否指出 Ci 与 Ii？Ii 是否专治 Di？删掉应用形容词后 Qi 是否仍在？

## 案例族速查
| 族 | 一句话程序 |
|----|-------------|
| A 尺度突破 | 点名断言 → 改边界 → 问可达+机制 |
| B 追问链 | 总谜 → 最弱可观测环 → 单主问 |
| C 新概念 | 定义+表征判据 → 非性能口号 |
| D 反常 | 意外→机制→可推广策略 |
| F 两难分叉 | 精度×效率困境 → 约束表示 → 严苛检验场 |
| J 需求问题集 | 窘境结构 → ≤3 硬问题 |
| N 统一建模 | 命名接口 → 对应 → 迁移测试 |
