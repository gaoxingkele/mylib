# 凝练科学问题案例（句子级技能）
**来源**: 《凝练科学问题案例》（科学出版社，2023）| **形态**: 81 案方法论蒸馏（非故事复述）| **Generated**: 2026-11-02

## How to Use This Skill

- **无参数** — 加载下方核心框架，直接改写用户课题问题句
- **指定病型/族** — 如 `技术堆砌`、`族J`、`需求抽象` → 读对应 chapter
- **章节** — `ch07` 病句改写；`ch08` 三栏对齐；`ch03–ch06` 分属性案例族
- 回答时输出：**病型 → 改写操作 → 可检验句 → 内容/创新映射**；禁止大段复述书中故事

本技能服务**国自然/科学基金本子**的科学问题凝练与表述；不替代学科前沿判断，不编造用户未提供的实验事实。

## Core Frameworks & Mental Models

### 1. 四类科学问题属性框架
Use **鼓励探索·突出原创** when 挑战“不可能/无概念”并追求知识增量。  
Use **聚焦前沿·独辟蹊径** when 热点拥挤，必须写出相对主流的分叉与检验场。  
Use **需求牵引·突破瓶颈** when 痛点在先，必须完成需求→原理/算法的抽提。  
Use **共性导向·交叉融通** when 主语是跨域接口或统一描述，而非学科名录。  
**硬规则**：勾选属性、问题句、研究内容、创新点必须同轴。

### 2. 六路凝练法（前言方法论）
好奇引导｜无穷追问｜反常深挖｜范式变革｜同行收敛｜需求抽象。  
执行：**主一路 + 辅一路**；终稿只留可检验主问（追问链可在过程用，不可全堆进摘要）。

### 3. 案例陈述四段式
探索过程（末句=问题）→ 困难（可击穿）→ 创新（对困难）→ 意义（先知识增量，后应用）。  
把用户素材压进四段，专治技术路线冒充问题。

### 4. 病句→改写→句式→映射（本案集核心循环）
1. 诊病：技术堆砌 / 口号化 / 不可证伪 / 工程冒充 / 过宽 / 已知包装 / 多问无主轴  
2. 改写：钉未知量、显边界、嵌观测量、写对照、工程降维、单主问  
3. 套句式：是否/如何/在何种条件下 + 判据  
4. 填三栏：问题 ↔ 内容 ↔ 创新（创新必须击穿已写困难）

### 5. 反模式红线（优先删除）
- **技术堆砌**：A+B+C 方法云，无未知量  
- **口号化**：面向/赋能/卡脖子/强国排比  
- **不可证伪**：全面系统揭示……规律  
- **工程冒充科学**：研制平台/突破装备 = 科学问题  
- **交叉空壳**：无接口变量的多学科并列  
- **AI 败笔**：首次将深度学习用于本单位数据；用“旨在/致力于”绕开问题句

### 6. 可直接套用的主句骨架
- `在〔边界〕下，〔现象〕由〔H1〕还是〔H2〕主导？可用〔观测〕区分。`  
- `〔断言S〕在〔尺度〕是否仍成立？定量判据是〔指标〕。`  
- `〔工程失败〕根子是〔不可测/不可建模环节〕；科学问题是〔原理〕。`  
- `相对〔主流路径〕的〔困境〕，〔分叉〕能否在〔检验场〕满足〔约束〕？`  
- `〔域A〕与〔域B〕经〔接口量〕如何对应且可迁移？`
