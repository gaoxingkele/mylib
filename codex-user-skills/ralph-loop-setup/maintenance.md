# Archival Ralph maintenance note

This document applied to the older Claude-oriented Ralph file layout.

In Codex/OMX, maintenance should happen on the actual repo-local artifacts you are using now, typically:
- `.omx/plans/`
- `.omx/state/`
- project-specific verification commands
- repo-local guardrail or progress docs

If you are cleaning up a legacy Claude-era Ralph install, inspect those old files directly and migrate only the parts that still matter.
