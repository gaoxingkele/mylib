# 权利要求分析

## 权利要求 1 (independent)

**类别**: method
**两段式**: 是

### 要素分解

- **C1.E1** (preamble): 一种基于深度学习的设备故障诊断方法，
- **C1.E2** (step): S1，获取设备运行数据，所述运行数据包括振动信号、温度信号、电流信号
- **C1.E3** (step): S2，对所述运行数据进行预处理，包括归一化和降噪
- **C1.E4** (step): S3，将预处理后的数据输入训练好的深度学习模型，得到故障诊断结果
- **C1.E5** (step): S4，所述深度学习模型采用卷积神经网络结构，包括卷积层、池化层、全连接层

## 权利要求 2 (dependent)

**类别**: method
**两段式**: 是

### 要素分解

- **C2.E1** (preamble): 根据权利要求1所述的方法，
- **C2.E2** (limitation): 所述预处理还包括特征提取

## 权利要求 3 (independent)

**类别**: system
**两段式**: 是

### 要素分解

- **C3.E1** (preamble): 一种基于深度学习的设备故障诊断系统，
- **C3.E2** (component): 数据获取模块，用于获取设备运行数据
- **C3.E3** (component): 预处理模块，用于对所述运行数据进行预处理
- **C3.E4** (component): 诊断模块，用于将预处理后的数据输入深度学习模型得到故障诊断结果
