# Disclosure and Application Structure

## Technical Disclosure Sections

1. Invention title.
2. Technical field.
3. Closest prior art and defects.
4. Technical problem.
5. Technical solution.
6. Key modules / steps / data flows.
7. Formulas and symbols, if any.
8. Embodiments and parameter examples.
9. Technical effects.
10. Drawings and reference numerals.
11. Claim preference points.
12. Unconfirmed facts.

## Chinese Patent Application Sections

1. Claims.
2. Specification:
   - technical field;
   - background;
   - summary;
   - drawings description;
   - detailed embodiments.
3. Abstract.
4. Abstract drawing suggestion.
5. Drawings / figure list.

## Drafting Rules

- Draft claims before finalizing the specification, then reconcile terms both ways.
- Use consistent terminology; create a terminology table for long cases.
- Define symbols before formulas.
- Avoid adding business-only effects as core technical effects.
- Keep unconfirmed implementation facts out of claims unless marked and later confirmed.
- For multiple related cases, maintain a portfolio map to avoid self-collision and duplicate claim scopes.
