# 专利授权成功率评分 Skill（AHP+SEM 多专家）

## 架构

```
目标层   P(授权)
潜变量层  S 客体适格(门槛) | N 新颖性 | I 创造性 | D 充分公开 | Q 撰写质量   ← SEM 结构模型
指标层   16 项可观测指标(每潜变量 3-4 项, 带载荷)                        ← SEM 测量模型
专家层   审查员/代理人/无效请求人/数据分析师 4 视角逐指标 1-9 打分        ← AHP 群决策
```

- **AHP**：4 专家各有一个 4×4 判断矩阵（对 N/I/D/Q），特征向量法求权重，每个矩阵 CR<0.1 强制校验，几何平均聚合为组权重（当前组权重 I=0.456, N=0.206, D=0.205, Q=0.133, 组CR=0.002）。
- **SEM**：潜变量分 = Σ(载荷×指标分)；`logit(P)=0.65×(Σwᵢ·ξᵢ − 5.6)`，斜率/截距用 incoPat 实测领域基线校准（软件方法类 2019-2024 授权B占比 20%-30%，折算未决后中位案 P≈0.42）。
- **客体门槛**：S≥6 不惩罚；3<S<6 线性惩罚；S≤3 视为 25 条/2.2 条高危，概率封顶 0.15。
- 等级：A≥0.70 / B+≥0.55 / B≥0.40 / C≥0.25 / D<0.25。

## 用法

1. **先查新**（调 incopat-search skill）：每案跑 `semantic`（技术方案整段, rows≥5）+ 1~2 组 `search` 关键词式；对相似度≥0.85 的 top 命中拉 `claim` 精读，形成区别特征清单——这是 N/I 两个潜变量打分的证据基础。
2. **四专家逐指标打分**（1-9 分）：由 Claude 分别以四种人格独立评分——
   - 审查员：按《审查指南》从严，重点 I1-I4（三步法）、S1-S3（客体）；
   - 代理人：评撰写可修性，Q1-Q3、D1-D3 偏乐观（可通过答辩/修改补救的给分高）；
   - 无效请求人：专挑 N/D 漏洞，对查新命中的近似文件从严解读；
   - 数据分析师：只看客观证据（相似度分值、检索命中量、领域授权基线、效果数据有无定量支撑）。
3. **写入评分 JSON** 并运行：
   ```bash
   D:/Python314/python.exe .claude/skills/patent-grant-scorer/scripts/ahp_sem_scorer.py cases_scores.json
   ```
   JSON 格式（列表，每案一项）：
   ```json
   {"case":"P01-1","title":"...","scores":{
      "examiner":    {"S1":7,"S2":6,"S3":6,"N1":6,"N2":7,"N3":6,"I1":5,"I2":5,"I3":6,"I4":4,"D1":7,"D2":6,"D3":5,"Q1":6,"Q2":6,"Q3":7},
      "attorney":    {...}, "invalidator": {...}, "analyst": {...}}}
   ```

## 16 项指标定义（打分锚点）

| 代码 | 指标 | 1-3 分 | 5 分 | 7-9 分 |
|---|---|---|---|---|
| S1 | 技术问题-手段-效果链 | 纯业务规则 | 有技术手段但效果偏管理 | 完整技术闭环 |
| S2 | 技术特征占比 | 商业方法为主 | 混合 | 技术特征主导 |
| S3 | 算法与场景结合 | 通用算法裸用 | 有场景参数 | 深度绑定内部结构/信号 |
| N1 | 最接近文件相似度反向 | sem≥0.90 | 0.85 | ≤0.80 |
| N2 | 无X文件置信度 | 命中疑似X | 有近似Y | 检索干净 |
| N3 | 特征组合未命中度 | 组合已见 | 部分见 | 组合未见 |
| I1 | 区别特征非显而易见 | 常规选择 | 一般改进 | 反直觉/跨域移植 |
| I2 | 特征协同效应 | 简单拼凑 | 弱协同 | 强耦合互为条件 |
| I3 | 无组合启示 | 两文件可直接拼 | 需一定改造 | 无启示 |
| I4 | 效果可信增益 | 纯定性夸大 | 有定量但未验证 | 定量+可复现 |
| D1 | 参数/公式具体化 | 关键处黑盒 | 主要公式有 | 全部可实现 |
| D2 | 实施例完整度 | 无实施例 | 单一实施例 | 多实施例+边界 |
| D3 | 效果数据可验证 | 有禁词/绝对化 | 中性描述 | 实测口径 |
| Q1 | 独权范围-支撑平衡 | 过宽或过窄 | 基本平衡 | 精准梯度 |
| Q2 | 从权退守布局 | 无梯度 | 部分 | 完整退守链 |
| Q3 | 术语一致清楚 | 多处歧义 | 少量 | 一致 |

## 输出解读

- `grant_probability`：授权概率点估计（不是保证，供排序与决策）
- `p_before_subject_gate`：客体门槛惩罚前的概率——两者差距大说明主要风险在 25 条/客体
- `latent`：五潜变量得分——最低的就是整改优先级
- 建议同时输出每案"最接近对比文件 + 区别特征 + 整改建议"作为评分依据留档

## 校准与免责

- 基线来自 incoPat 实测（TIABC 领域式，PNK=B 占比），随年份漂移应重新标定 `k, x0`；
- 本评分是撰写辅助决策工具，不构成法律意见；终稿前必须人工（代理人）复核。
