# 摘要规范

摘要用于概括发明公开的技术内容，不用于确定专利保护范围，也不是广告文案。

## 必备内容

摘要通常按以下顺序组织：

1. 发明名称；
2. 所属技术领域；
3. 要解决的技术问题；
4. 解决该问题的技术方案要点；
5. 主要用途；
6. 在篇幅允许且有依据时，概括主要技术效果。

技术方案要点原则上以独立权利要求的核心技术特征为中心，不能只写目标和效果。

## 硬性与形式要求

- 摘要文字部分不得超过 300 个汉字；按提交文本审查，标点也应计入控制。
- 有附图时，应指定最能说明主要技术特征的一幅作为摘要附图，并在摘要中说明必要的附图标记。
- 用语应准确、简明，不使用商业宣传、价值判断或未被说明书支持的结论。
- 摘要不得加入说明书和权利要求书中没有公开的新技术特征。

## 推荐模板

> 本发明涉及【技术领域】，公开了一种【主题名称】。针对【具体技术问题】，该方法/装置包括：【核心输入或结构】；【关键处理或连接关系】；以及【输出或作用方式】。通过【核心作用机理】，实现【有依据的主要技术效果】。本发明可用于【主要用途】。

模板应按案件内容改写，不得机械填词。方法、装置或系统的语法要与发明主题一致。

## 常见错误

- 只写“提高效率、降低成本”，未概括技术手段；
- 复制整项独立权利要求，超过 300 字且可读性差；
- 加入“国内领先”“具有重大价值”“效果显著”等宣传性语言；
- 引入未在说明书公开的参数、模型或效果；
- 摘要名称与请求书、说明书、权利要求书不一致；
- 摘要附图不能代表核心方案，或标记与说明书附图不一致；
- 把摘要当作后续修改权利要求的唯一依据。

## 交付前检查

- [ ] 名称与全套文件一致。
- [ ] 包含问题、手段、用途，且手段不是纯结果表述。
- [ ] 技术特征均能在说明书和权利要求中找到依据。
- [ ] 文字不超过 300 个汉字。
- [ ] 无宣传语、无引用文献、无未经证实的绝对效果。
- [ ] 摘要附图及标记正确。
