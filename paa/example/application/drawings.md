## 图1：系统总体架构（Mermaid）

```mermaid
flowchart LR
    U[用户查询] --> QL[查询层增强模块<br/>实体邻居扩展]
    QL --> RE[多路检索引擎]
    RE --> RL[检索层校验模块<br/>路径惩罚]
    RL --> FM[融合排序模块<br/>动态权重RRF + MMR]
    FM --> BX[封箱裁决模块<br/>可用/隔离]
    BX --> MA[元适配门控模块<br/>元策略 + 门控]
    MA --> LM[大语言模型]
    MA --> OT[输出+审计]
```

## 图2：封箱构建与裁决流程（Mermaid）

```mermaid
flowchart TD
    C[候选结果] --> B[构建封箱<br>内容/来源/路径/惩罚标记]
    B --> J{路径匹配?}
    J -->|匹配| OK[可用态封箱] --> P[可用池]
    J -->|不匹配| PE[施加惩罚因子] --> Q[隔离态封箱] --> IP[隔离池<br>不入模型输入]
```

## 图3：元适配层与生成端门控关系（Mermaid）

```mermaid
flowchart LR
    RP[检索层校验结果] --> MA[元适配层]
    QC[查询类型分类] --> MA
    MA --> MS[元策略对象<br>可用集/隔离集/输出schema]
    MS --> G[生成端门控]
    AP[可用池封箱] --> G
    G --> LM[大语言模型生成]
    LM --> CK{引用隔离内容?}
    CK -->|是| BL[拦截/降级]
    CK -->|否| OUT[输出]
```

## 图4：三级安全网降级路径（Mermaid）

```mermaid
flowchart TD
    R[可用池封箱数] --> TH1{≥TH1?}
    TH1 -->|是| OK1[通过]
    TH1 -->|否| TH2{≥TH2?<br>TH2=TH1/2}
    TH2 -->|是| OK2[通过]
    TH2 -->|否| TOP1[返回多路融合排名第一]
```
