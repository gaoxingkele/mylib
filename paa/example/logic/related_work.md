# 相关工作

## 非冲突文献（背景层）

- **BM25** (Robertson et al.) — 经典检索基线；本案的关键词检索通道使用 BM25 + 行业自定义词典（防中文分词切分复合术语）。
- **MMR** (Carbonell & Goldstein, 1998) — 最大边际多样性重排序；本案用作 D04 区别特征。
- **Reciprocal Rank Fusion** (Cormack et al., 2009) — RRF；本案用作动态权重融合基线。
- **IRT** (Item Response Theory) — 用于题目难度评估（仅做背景参照，本案 P06-1 用）。
- **DAG / 拓扑排序** — 用于工作流调度（仅做背景参照，本案 P01-1/P04-1 用）。

## 相关非专利文献

- 大语言模型防幻觉综述 (Maynez et al., 2020; Ji et al., 2023) — 给出幻觉分类与缓解策略；本案的"封箱隔离 + 元门控"是工程化的具体实施。
- RAG 系统综述 (Gao et al., 2024) — 给出标准 RAG 架构；本案在标准 RAG 基础上加入图谱三层增强与 Seal-and-Adapt 生成约束。

## 与本案的边界

上述文献均为方法论参照或公开技术基线，不构成新颖性 / 创造性打击。
