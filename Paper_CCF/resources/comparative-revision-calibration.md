# 范文对照、修订复评与排名追踪 v1.0

适用：跨轮论文评审、已有范文逐段对比、授权改稿与补实验、交叉评审分歧裁决、排名更新。
与[章节评分V3](chapter-journal-scoring-v3.md)及[多尺度语义评审](comparative-multiscale-review.md)配合；不新增评分权重，不建立期刊录用模型。
只问排名时执行第1、6节，不自动展开完整改稿流程。选刊/APC/实时政策仍由目标刊画像和官网处理。

## 1. 分清稿件变化、重评变化和比较集合变化

为每个“论文×期刊”保存当前版本、实际阅读PDF/源/SI的SHA、评分卡与量表、范文集合、评审席及阅读范围。
混合版本逐稿列出，不能把最近改过两篇的版本号套到整批。最高目录版本号不自动等于有效交付稿。

- **同稿重评**：文件未变但换席、改解释或细化评分，只能说评价变化。
- **同尺度修订**：同席冻结旧稿判断，与新稿在同权重/证据锚点下比较，才有可归因的改稿分差。
- **范文/量表/评审席更换**：另列新评估系列与桥接结果，不能混成改稿收益。
- **同分改排名**：范文、同场稿件或它们的分数变化时，名次可以变；本稿没有因此退步。

可桥接时：`新分−历史分 = (新稿同席分−旧稿同席分) + (旧稿同席分−历史分)`。
分别命名“修订差”与“重评差”；没有同席旧稿控制时不要编造这个分解。
保留旧报告；新增当前入口和收据。旧发布收据是原冻结时点快照，排名元数据更新另留收据，不改旧包来伪造一致。

## 2. 范文学习落到段落功能，不落到配额

先固定全体语料名单、时间口径、实际文件版本和可读状态；再按任务、体裁和证据作用选择深入比较篇目。
“每刊10篇”来自具体任务，不是通用最低要求。全体名单/已有章节阅读和本轮深读子集分开记录。
已经发表的缺陷仍是反例，不变成容许标准；不靠挑低分范文抬高本稿位置。

逐项映射需要足以复查的两侧锚点：

|本稿|范文|判断与动作|
|---|---|---|
|版本/SHA、节、源码行或PDF页、段首、段落功能|ID/DOI、实际PDF/SHA、页、节、段首；需要时bbox|范文完成了什么、本稿缺什么、保留/改写/移至SI/补实验、验证结果与残余边界|

按问题→文献缺口→方法/假设→实验设计→结果→解释→结论追踪段落输入输出。
标题不同不等于功能缺失；表、公式、图注与prose分母分开。PDF块可能含多段或跨页续段，不能把块数称为自然段数。
“全部段落已定位”不等于逐段语义核查完毕，“已提取/预检/渲染”也不等于实际读过或复现。
新版本变化后重新绑定页码；原段首/源码地址和历史阅读范围保留。

## 3. 用实验回答缺口，保留不同估计对象

每项补强先列：未知问题、已有结果暴露、固定/改变的对象、实际可用信息、对照、端点、分析单位、失败处理和适用结论。
新增运行前写设计与可判断标准；在旧结果暴露后设计的二次研究如实标明，不能冒充独立未见数据确认或公开预注册。
来源哈希若在启动后补录，称事后来源闭合，不能倒称全部原始输入事前已直接封存。

有用的机制检查包括：

- 公式在实际拟合/状态上是否非平凡；充分条件通过了多少、未判定多少、是否与直接观测不同。
  零充分证书不等于事件从未发生；反例应满足原假设。更紧界也可能仍然没有信息。
- 固定拟合内的算子替换、分别训练的系统、强锚以上的增量、最终运行价值是不同对象。
  方向不同可以合理；逐一解释，不用后来的正结果覆盖旧的未决或失败。
- 共同状态干预固定实际population/archive/信息/RNG及预算，快照取真实执行边界；不能虚构批次中更新时刻的状态。
  相同初始RNG不自动保证后续轨迹或抽样数相同，需核对实现。
- 请求、缓存未命中、独特方案、wall-clock和费用分别记账。近似相同方案数伴随更好结果，不足以识别数量中介；描述属性差异也不足以识别地区因果。
- 数学实数精确性、浮点数值检查、区间算术认证、实际预测收益分开。代码复用范围和独立重建范围分开。
- 种子、重复运行、共享标签的状态×查询行不是新增地区/用户/站点；不把调用数当独立样本量。

新公式、实验次数、完整披露或SHA数量本身不加分。按用户授权和迭代预算停止；没有新证据、无法关闭的问题明确保留，不能为90分/前三不断改尺度。

## 4. 使用功能证据锚点，避免跨稿双重标准

在V3中4表示问题范围内充分支持，5表示具体、强且读者可核验的支持。
原理初等既不自动加分，也不阻止一个闭合并经实际对象验证的任务特定机制获得5。
不因为没有一般新定理、现场部署或未声称的普遍保证，就降低有限诊断的中心有效性；贡献是否值得发表仍另行判断。

比较高分锚点时记录：`所问对象→假设/机制→排除的替代解释→实际验证→仍不推出什么`。
解释为什么相似证据在两稿跨过或未跨过同一等级；不能只用“简单公式”“态度谨慎”“已列全统计族”作理由。
正确统计报告通常是必要支持；若提高D6，应指出实际数量如何阻断错误推论，而非仅有p值、校正或完整表格。
同一根因影响多章时分别说明功能后果，不再加一次全局惩罚。未读覆盖不是作者缺陷；3级须有后果明确的证据缺口。
多尺度0–4与V3的0–5是两种模式，不能直接混算或悄悄换分母。

## 5. 原始判断、修正、裁决与最终稿分层

授权多智能体时，作者席与评审席分开；先冻结各自的显式章节/维度键值，再算分和对照其它席。
知道旧结果或参与过范文对照就如实称知情评审，不自称盲审。子样本双评只支持该子样本的比较，不证明全部版本一致。

保留以下不同事件，不能覆盖原始字节：

1. **转录/标签修正**：证明原意与显式键错位，保留更正前卡、锁定和首轮汇总；汇总后发现就称汇总后修正。
2. **证据裁决**：新理由使等级改变，按单元记录原评、另一席意见、采纳/不采纳、两侧证据和加权影响。
3. **读者文件重绑**：锁后复制编辑/重新排版，保存被评旧稿，核对语义变化，另生成最终输入绑定。文字更清楚不自动涨科学分。

不要用有序数字串代替维度键。不要平均掩盖分歧、挑最高席、反复换席追分或强行保持旧名次。
最终使用“原始卡→更正/裁决→当前读者文件的派生卡”，记录被选文件SHA与所有原始异议。
编辑建议可能有用而不足以降等级；相反高总分不能掩盖中心推理失败。决定需逐证据解释。

## 6. 三种排名必须分开

同一刊中，对分数s及不含该稿的比较列表O：

`best = 1 + count(O > s)`；`worst = 1 + count(O >= s)`；`N = len(O)+1`。

|比较范围|加入对象|用途|
|---|---|---|
|individual|同刊完整范文+这一稿|回答该稿相对固定范文的位置，多篇可以分别第一|
|within_batch|同刊的本批稿件|回答六稿等批次内部顺序，不含范文|
|joint|同刊完整范文+本批全部稿件|回答所有稿件与范文同场位置|

每行同时报告版本、分数、范围、名次区间与分母，绑定精确比较集合ID。
并列2–4占第二至第四三个位置；只有最差名次≤k，才可无条件称该样本内前k。
unknown不置零、不插补、不换有利样本：已评分集合单列N；若同刊未知m篇全部排在本稿之前，最差位置至多后移m，完整名单分母为N+m。
没有完整范文时不能把“1/1”宣传为范文第一或前k。期刊间样本异质、评审分歧和相近分差都应保留。

当用户问“之前不是提高了吗”，先对照同一范围的旧/新分数与名次，再解释集合或其它稿的变化；不能暗示改进被取消。
如果做过同稿校准/分数修正，同时报告，不能把所有变动都归咎于分母。

可执行工具（stdlib，不给科学分、不更新稿件或全局指针）：

```text
python D:/aicoding/mylib/Codex-Academic-Research/tools/journal_rankings.py input.json --out-dir ranking_snapshot
```

输入字段与输出范围见工具`--help`。使用同一量表/可比评审系列的完整分；工具只验证格式与算术，不认证评审、输入哈希所称的科学真实性或期刊规则。
