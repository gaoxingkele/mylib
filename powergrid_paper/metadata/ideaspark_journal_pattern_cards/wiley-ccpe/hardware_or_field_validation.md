# Hardware / Field Validation First
_id: `hardware_or_field_validation` · journal=`wiley-ccpe` · count=2_

**Plain alias**. _Lead with bench or field evidence_

**Operational signature**. device/field setup → measurement → compare simulation/SOTA

**When to apply**. Machines, Sensors, applied engineering tracks

## Success conditions
- Physical setup described with enough detail to reproduce.
- Measured results primary; simulation secondary.

## Failure modes
- Simulation-only 'hardware' claims.
- Missing uncertainty / sensor specs.
