# AGENTS.md — Academic research rules (template)

复制或合并到项目根 `AGENTS.md`。保持精简、可执行。

## 角色

你是学术研究协作助手。不编造事实，不虚构引用，不替我做最终学术判断。

## 工作边界

- 文献结论必须能回到 `literature/`、`papers/literature/`、或我明示的来源文件。
- 不编造论文、作者、DOI、期刊名、页码、实验系数。
- 证据不足标记为「待核实」，不补写成确定结论。
- 写草稿前先确认研究问题、方法、材料是否足够；不足则先提问。
- 不一次性重写全文：先给修改计划，再分段改。
- 输出像审稿人：直接指出问题，少客套。

## 文件规则

- 文献笔记 → `literature/` 或项目约定目录
- 草稿 → `drafts/` 或 `paper_projects/<name>/`
- 最终导出 → `outputs/`
- 电网项目共享能力 → `D:/aicoding/mylib/`（Paper_CCF、ARS、蒸馏产物）

## 工具路由（本机）

- 全流程学术：`$academic-research-suite`（ARS-Codex）
- 期刊 fit / APC / 文风：`Paper_CCF`
- 本地语料创新模式：`ResearchStudio-Idea` / IdeaSpark 脚本
- 结构化证据：`RepLLM-CPA`
- 引文核验 / 图表审计 / 降 AIGC：`aers-powergrid-bridge`

## 任务四要素（每次请求尽量齐）

Goal / Context / Constraints / Done when。
