Five skills, one pipeline

extract once · generate three ways · converge

ResearchStudio-Reel runs as five composable skills inside Claude Code and Codex. A shared extractor reads the paper once; three generators produce editor-ready artifacts from that one bundle; a convergence layer binds them into a single navigable surface.

1
📄

paper2assets

Reads the PDF once into one reusable bundle — body text, cleaned figures, captions, metadata, and a nine-section spec that every generator consumes.

2Generate — in parallel
🖼️

paper2poster

Composes a print-ready poster in four coupled formats — HTML, PDF, PNG, and editable PowerPoint — tuned by a measured fill-loop.

🎬

paper2video

Plans narration and builds a captioned talk video with an editable deck and narration-aligned visual highlights.

✍️

paper2blog

Writes a bilingual editorial package — a Chinese WeChat piece and an English research blog — as editable Word files sharing one evidence base.

3
🎞️

paper2reel

Binds poster regions, video segments, slide thumbnails, captions, and blog passages into one interactive, downloadable viewer.
