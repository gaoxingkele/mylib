pipelines that do not map directly to power-grid CS/AI journals. This bridge keeps
only high-reuse modules for:

- literature tooling orchestration
- citation verification
- figure/table evidence auditing
- language polishing and de-AIGC
- optional post-draft pipeline orchestration
