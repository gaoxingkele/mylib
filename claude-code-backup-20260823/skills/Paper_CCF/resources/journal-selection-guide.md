## 电力×CS 作者的推荐路径(决策口诀)

- **有"保护/控制/故障/稳定"角度 + 想免费、最快、最高 IF** → **PCMP**(限该角度;纯预测/优化无保护角度会被拒)。
- **广义 smart grid / 数据驱动电力 + 想要 Q1 + 中国作者/学会背书** → **CSEE JPES**(注意 2026 起按页收费、~40% 台面拒)。
- **稿件严谨但新意一般 + 想快速 OA** → **IEEE Access** / **MDPI Electronics·Energies·Information·Algorithms** / **CMC**(应用 CS×电网信息化，本地已有 10 篇蒸馏)。
- **储能是对象(BESS/寿命/市场)** → **Journal of Energy Storage**(高 IF)；否则 Energies。
- **IoT 系统贡献 + 要高 IF** → **IEEE IoT Journal**；要快便宜 OA → **Future Internet / Sensors**。
- **AI 应用于能源(预测/优化/需求响应)且想 Q1 能源刊** → **Energy Reports**或 **MDPI Energies**;或 **Frontiers Energy Research** 走 Smart Grids 分区。
- **要 IEEE 品牌的电力 OA、预算充足** → **OAJPE**。
- **EO/气象驱动能源** → Remote Sensing / Atmosphere（对象须对口）。
- **广谱 CS OA 改投** → Discover Computing / PeerJ CS；**IJACSA 声誉需自审**。
- **需要具体子系统对口**:电机/驱动→**Machines**;传感/监测→**Sensors**;可持续/政策→**Sustainability**;数学/优化理论→**Mathematics**。
- **广谱兜底/改投** → **Scientific Reports**(稳定收录但**不快**)。
- **勿投**: Unconventional Resources ← 除非真是非常规油气。

## 三个避坑提示

1. **Heliyon 收录风险**:Web of Science 自 2024-09 起"暂停"(On Hold),2025 大规模撤稿;若你需要 SCI 收录/影响因子用于评职毕业,**投前先在 Clarivate Master Journal List 查当前是否在库**。
2. **Scientific Reports 不是快刊**:官宣 ~20 天是"首个编辑决定",全程常 4–6 个月;要速度就选 IEEE Access/MDPI。
3. **"免费/便宜"≠"随便发"**:PCMP 免费但**只收保护/控制**;CSEE JPES 从 2026 起按页收费;MDPI/IEEE Access 的 APC 都是数千,且部分评审委员会对快 OA/巨刊打折——按目标受众权衡。

## 三档速览

- **最快(≤~4 周首决)**:PCMP、IEEE Access;MDPI 全系(~15–18 天首决)。
- **中(~1–3 月)**:CSEE JPES、Frontiers、Energy Reports(见刊~16 周)、OAJPE。
- **慢(≥~4 月)**:Scientific Reports。

## 电力开放数据语料蒸馏（2026-07 增补）

基于 `powergrid_benchmark` 本地缓存：**49 数据集 × ≥5 篇 OA/arXiv PDF（去重后 90 篇）**，并对照 `dataset_direction_sci_exemplars_curated.csv` 的 OA 目标分布。完整笔记：`powergrid-open-data-corpus-distill.md`。

### 本语料最常指向的 OA 刊（按数据集行计数）

1. **Energies**（46）— 储能/BESS、风光、负荷预测、SimBench/Ausgrid 类应用首选  
2. **IEEE Access**（43）— 学习型 OPF、电池 SOH、ACN/EV、窃电、PMU；编号贡献点 + 公开基准名  
3. **Energy Reports**（11）— AI-for-energy / 预测优化，强调能源决策贡献  
4. **Sustainability**（9）— 仅当可再生并网/DR/规划有可量化可持续影响  
5. **Scientific Data / Scientific Reports** — 数据集论文走 Sci Data（如 SDWPF）；方法稳健但增量走 Sci Rep（如 SGCC 窃电）  
6. **Electronics / Sensors / Applied Sciences** — 分别吃信号/EE、传感测量、现场应用落点  

### 体裁 → 证据口诀（写稿/选刊时直接用）

| 体裁 | 最低证据 | 优先 OA |
|---|---|---|
| 负荷/电价/风光预测 | 公开数据集名 + ≥3 baselines + MAE/RMSE/MAPE | Energies / Energy Reports / Access |
| 学习型 OPF / GNN-OPF | PGLib/IEEE 算例 + 可行性/最优性指标；可无长 DL 表 | Access / Energies / OAJPE |
| 电池 SOH/RUL | NASA/CALCE/Oxford 等 + ≥1 基线类 | Access / Energies / Electronics |
| EV/ACN 充电 | ACN-Data + 调度/灵活性指标 | Energies / Access |
| 窃电/异常 | SGCC 类公开表 + 不平衡处理 + F1/AUC | Sci Rep / Access |
| PMU/事件 | 真实或高保真传感迹线；传感须为核心才投 Sensors | Access / Electronics / Sensors |
| 保护/故障/稳定 | 与既有保护方案对照；AI 须论证可靠性 | **PCMP**（否则勿硬塞） |
| 纯数学 OPF 理论 | 定理/收敛/复杂度 | Mathematics；否则改投 Access/Energies |

### 语料级共性发现

- 公开基准点名（ETT、ACN、NASA PCoE、SDWPF、PGLib、Grid2Op、SimBench）是 OA 审稿里的一等贡献信号。  
- 消融仅约 10% 文前页出现；预测类仍建议补，规划/案例类可靠情景敏感性。  
- 代码可运行 artifact 非刚需；Data Availability + DOI/GitHub 即可。  
- 方法多为组合创新——Access/Energies/Sci Rep 用 **soundness** 叙事，勿吹“首创算法”。
